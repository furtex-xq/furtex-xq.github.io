Создание лотов FunPay из JSON

Закладка-кнопка для браузера. Открываете FunPay, нажимаете её, выбираете файл, и лоты создаются по очереди под вашим аккаунтом.

iPhone и компьютерБез сервераБез golden_keyБез дублей

1. Установить закладку

  1. Нажмите «Скопировать код» ниже.
  2. Добавьте эту страницу в закладки: кнопка «Поделиться» → «Добавить закладку» → назовите FP Tools → «Сохранить».
  3. Откройте закладки (значок книги) → «Изменить» → нажмите на FP Tools.
  4. Сотрите адрес и вставьте скопированный код. Нажмите «Готово».
  1. Включите панель закладок (Ctrl/Cmd + Shift + B).
  2. Перетащите кнопку ниже на панель закладок.

Показать код закладки

2. Создать лоты

  1. Зайдите на funpay.com под своим аккаунтом (любая страница).
  2. Откройте закладки и нажмите FP Tools. Внизу появится панель.
  3. Выберите JSON-файл с лотами, например FunPay_Cardinal_440.json из «Файлов».
  4. Сначала создайте 1 лот для проверки. Если он появился на FunPay, поставьте 0 (все) и запустите снова.

Лоты, которые уже есть в профиле, пропускаются, поэтому при сбое можно просто запустить ещё раз. Пауза между лотами 3 секунды, чтобы FunPay не ограничил запросы. 440 лотов займут примерно полчаса. Экран при этом не выключайте.

Что важно знать

  1. Выдача без бота. В каждом лоте заполнено «Сообщение покупателю после оплаты» со ссылкой на гайд, и FunPay сам отправляет его сразу после оплаты, 24/7.
  2. Безопасность. Код работает только в вашем браузере, на странице FunPay. Никуда, кроме funpay.com, данные не отправляются, а пароль и golden_key не нужны.
  3. Ошибки разделов. В некоторых разделах FunPay есть обязательные поля, например тип услуги. Если панель покажет «Заполните поле», добавьте лоту extra_fields с нужным значением.

Формат JSON

Подходит FunPay_Cardinal_440.json или такой формат:

{ "lots": [ {
  "sku": "AE-BASICS",
  "node_id": 3034,
  "price": 1,
  "summary_ru": "Название лота",
  "summary_en": "Lot title",
  "desc_ru": "Описание…",
  "desc_en": "Description…",
  "payment_msg_ru": "Спасибо! Ссылка: …",
  "payment_msg_en": "Thanks! Link: …",
  "extra_fields": { }
} ] }

Вместо summary_ru и других можно передать fields с полями формы FunPay (fields[summary][ru] и т. д.).
