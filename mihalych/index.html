🔑 Ключ GitHub для удаления видео

Скачать видео можно без ключа. Чтобы кнопка «Выложил» удаляла файл с GitHub, нужен личный ключ — один раз на каждом устройстве.

  1. Открой github.com → Fine-grained token.
  2. Name: mihalych, Expiration: 90 дней (или больше).
  3. Repository access → Only select repositories → furtex-xq.github.io.
  4. Permissions → Repository → Contents: Read and write. Больше ничего не нужно.
  5. Generate token → скопируй и вставь сюда.
Ключ хранится только в этом браузере. Никому его не отправляй и не вставляй в чаты — с ним можно менять твой сайт.
