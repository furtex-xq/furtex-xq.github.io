# Статистика канала «Михалыч»

Сюда загружай выгрузки статистики — Claude прочитает их отсюда.

- **YouTube:** YouTube Studio → Аналитика → «Расширенный режим» → кнопка «Экспорт» → «Значения, разделённые запятыми (.csv)». Из скачанного архива загрузи файл `Таблица данных.csv` (или `Table data.csv`).
- **TikTok и ручные записи:** на странице канала заполни форму и нажми «Скачать CSV».

Называй файлы с датой, например `2026-11-01_youtube.csv` или `2026-11-01_tiktok.csv`.

Загрузить: [Add file → Upload files](https://github.com/furtex-xq/furtex-xq.github.io/upload/main/mihalych/stats)
