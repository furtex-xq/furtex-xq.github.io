# Квінс — демо-сайт

Шаблон: «Готель / міні-готель» (`template/hotel`).

Заповнено з OpenStreetMap: назва, місто, адреса, телефон, email.
Джерело: https://www.openstreetmap.org/way/1157778562

Ще треба заповнити (позначені бурштиновим підкресленням): `[ІМ'Я]`, `[ГОДИНИ]`, `[РІК]`, `[ФОП]`, `[ЦІНА]`.
Відгуки — приклади (`ph-card`), замініть на реальні. Типи номерів і зручності — типові, звірте з готелем.
Фото — зі стоку Unsplash, бажано замінити на фото номерів і рецепції.
