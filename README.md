# Шаблон «СТО / автосервіс» (`template/sto`)

Універсальний односторінковий сайт для СТО, автосервісу чи майстерні в Івано-Франківську (і будь-якому іншому місті). Статичний HTML/CSS/JS без збірки й без сторонніх бібліотек. Після заміни плейсхолдерів сайт можна завантажити на будь-який хостинг.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/sto/index.html

## Дизайн

- **Шрифти:** Play (400/700) для заголовків, кодів робіт і цифр. Roboto Condensed (400/500/700) для тексту, кнопок і підписів. Обидва лежать локально в `fonts/` (кирилиця + латиниця, woff2).
- **Палітра:** графіт `#15171a` / `#1e2125`, бетон `#e2e4e1` / `#eef0ed`, бланк `#fafaf7`, сигнальний жовтий `#f2b705`. Жовто-чорна «аварійна» смуга з'являється лише тричі: на наряді, на формі й у футері.
- **Композиція:** технічний «паспорт» сервісу. Коди робіт (ТО-01, ГМ-02…), креслення авто, лінії-виноски на фото в hero, регламент у вигляді таблиці.
- **Фішка:** калькулятор «Наряд-замовлення». Клієнт обирає клас авто, торкається вузла на схемі машини (двигун, гальма, ходова, електрика, шини, кондиціонер, вихлоп) і позначає роботи. Праворуч збирається попередній наряд: перелік робіт, час у боксі й сума «від … грн». Кнопка «Записатися з цим нарядом» переносить перелік у форму запису.
  Калькулятор бере роботи й ціни **з прейскуранта на сторінці**, тож ціну достатньо змінити в одному місці. Поки в прейскуранті стоїть `[ЦІНА]`, калькулятор показує `від [ЦІНА] грн`. Щойно там з'являється число, він рахує суму сам. Коефіцієнти класу авто задані атрибутами `value` у радіокнопках (`1` / `1.2` / `1.4`) — узгодьте їх із клієнтом.
- Анімації: поява блоків при скролі, виноски в hero, пульсація точок на схемі. Якщо в системі ввімкнено `prefers-reduced-motion`, усе це вимикається.

## Плейсхолдери

Видимі плейсхолдери обгорнуті в `<span class="ph">…</span>` (жовте пунктирне підкреслення). Після заміни обгортку можна лишити (і прибрати стиль `.ph` у CSS) або видалити.

| Токен / сентинел | Що це | Де трапляється |
|---|---|---|
| `[НАЗВА]` | назва СТО | `<title>`, og:site_name, og:title, JSON-LD, лого, наряд-замовлення, «Про нас», футер |
| `[МІСТО]` | місто | title, description, og, JSON-LD, лого, hero (eyebrow + H1), «Про нас», контакти, футер |
| `[АДРЕСА]` | вулиця, номер | JSON-LD, hero eyebrow, контакти, футер |
| `[ТЕЛЕФОН]` | телефон для показу | meta description, JSON-LD, меню (моб.), hero, FAQ, контакти, футер |
| `[EMAIL]` | пошта | JSON-LD, контакти, футер |
| `[ГОДИНИ]` | короткий графік, напр. «Пн–Пт 9–19, Сб 9–15» | JSON-LD `openingHours`, блок «Графік роботи» |
| `[ІНСТАГРАМ]` | @нікнейм | кнопка над галереєю |
| `[ФОП]` | ФОП / ЄДРПОУ | футер, «Реквізити» |
| `[РІК]` | рік заснування | JSON-LD `foundingDate`, «Про нас» («Працюємо з…»), футер |
| `[ЦІНА]` | ціна роботи | прейскурант (25 позицій `від [ЦІНА] грн`), JSON-LD `priceRange`; калькулятор підхоплює ціни автоматично |
| `[ІМ'Я]` | ім'я автора відгуку | 3 картки відгуків (`.ph-card`, мітка «Приклад відгуку — замініть на реальний») |
| `09:00–19:00` у `.ph` + `data-schedule` | години по днях | таблиця «Графік роботи» + JSON в атрибуті `data-schedule` у `#hours` (з нього рахується статус «Зараз відчинено/зачинено» за київським часом; `null` — вихідний) |
| `tel:+380000000000` | дзвінок | меню, hero, FAQ, контакти, футер, мобільна панель |
| `viber://chat?number=%2B380000000000` | Viber | контакти, `js/main.js` (`CONTACT.viber`) |
| `https://t.me/username` | Telegram | контакти, `js/main.js` (`CONTACT.telegram`) |
| `https://wa.me/380000000000` | WhatsApp | контакти |
| `https://www.instagram.com/username/` | Instagram | галерея, контакти, JSON-LD `sameAs` |
| `https://www.facebook.com/username` | Facebook | контакти, JSON-LD `sameAs` |
| `mailto:hello@example.com` | пошта | контакти, футер, `js/main.js` (`CONTACT.mail`) |
| `https://www.google.com/maps?q=%D0%86%D0%B2%D0%B0%D0%BD%D0%BE-%D0%A4%D1%80%D0%B0%D0%BD%D0%BA%D1%96%D0%B2%D1%81%D1%8C%D0%BA&output=embed` | карта | iframe у контактах (замініть `q=` на закодовану адресу або embed-посилання з Google Maps) |
| `https://www.google.com/maps/dir/?api=1&destination=%D0%86%D0%B2…` | маршрут | кнопка «Прокласти маршрут» і «Маршрут» у мобільній панелі |
| `og:url` | адреса сайту | `<head>` (зараз це демо-посилання) |

Прайс, назви робіт, тексти «Про нас», регламент, FAQ і відгуки написані як типовий текст для СТО. Їх можна редагувати як звичайний текст. Час робіт (`data-time` у рядках прейскуранта) — орієнтовний, підправте його разом із клієнтом.

## Фото (замінити на реальні фото клієнта)

Зараз стоять фото з Unsplash (Unsplash License). Вони лежать у `img/photos/`, а на сторінці підключені за абсолютним URL на raw.githubusercontent.com, закріпленим за комітом.

| Файл | Де на сторінці | Що попросити в клієнта |
|---|---|---|
| `hero.jpg` | головний екран (+ og:image) | авто на підйомнику у їхньому боксі, горизонтальне 3:2. Виноски ДВ/ХД/ГМ стоять у відсотках (`.callout--a/b/c` у CSS) — підправте їх під нове фото |
| `workshop.jpg` | «Про нас» | загальний план цеху |
| `hands.jpg` | «Про нас», врізка | руки майстра за роботою |
| `engine.jpg`, `brakes.jpg`, `lift2.jpg`, `diag.jpg`, `tires.jpg`, `tools.jpg` | шапки груп прейскуранта | реальні фото кожного виду робіт |
| `oil.jpg`, `diag.jpg`, `brakes.jpg`, `tools.jpg`, `engine.jpg` | галерея «Як виглядає робота» | 4–5 найкращих фото з їхнього Instagram |

## Як адаптувати під клієнта — 5 кроків

1. **Дані.** Через «знайти й замінити» по всіх файлах замініть токени `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ГОДИНИ]`, `[ІНСТАГРАМ]`, `[ФОП]`, `[РІК]`. Для `[МІСТО]` в `<title>` і description пишіть «Івано-Франківськ» (SEO: «СТО Івано-Франківськ»).
2. **Посилання.** Замініть сентинели `+380000000000` / `380000000000` / `%2B380000000000`, `username`, `hello@example.com` (і в `index.html`, і в `js/main.js`), а також `q=` / `destination=` у карті та маршруті.
3. **Ціни й графік.** У прейскуранті замініть кожне `від [ЦІНА] грн` на число (`від 450 грн`) — калькулятор підхопить. Приберіть або додайте рядки `<li data-code data-time>`. Оновіть таблицю годин і JSON `data-schedule`.
4. **Фото.** Покладіть фото клієнта в `img/photos/` з тими самими іменами (або змініть `src`). Оновіть `alt`, `og:image` і виноски на фото в hero.
5. **Відгуки й перевірка.** Вставте 3 реальні відгуки, приберіть клас `ph-card` і мітку `.ph-label`, видаліть стиль `.ph`. Відкрийте сайт на телефоні й перевірте: дзвінок, Viber, Telegram, форму, карту.
