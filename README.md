# Шаблон «Туристична агенція» (`turahentsiia`)

Універсальний односторінковий сайт для турагенції: тури на море, в гори, автобусні тури Європою, Карпати. Чистий HTML/CSS/JS без бібліотек і без збірки: `index.html`, `css/style.css`, `js/main.js`, шрифти лежать у `fonts/`.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/turahentsiia/index.html

## Дизайн

- **Шрифти:** Vollkorn (заголовки, курсив для акцентів) + Jura (текст, підписи, «квиткові» мітки). Обидва підключено локально (woff2, cyrillic + latin), `font-display: swap`.
- **Палітра «море й пісок»:** глибокий бірюзовий `#0E4441`, морська піна `#D3E6DF`, пісок `#EFE3CC`, папір `#FBF6EC`, корал `#E2603F` (для тексту `#B9442A`), чорнило `#0B2B2A`.
- **Фішка:** маршрут, що прокладається під час гортання. Пунктирна лінія між картками напрямків поступово стає кораловою, по ній летить літачок, і на кожній картці з’являється «паспортний штамп» (EGY, GRC, HRV…). Друга фішка: квіз «Підбір туру» у вигляді посадкового талона (тип відпочинку → бюджет → коли), відповіді переносяться в заявку.
- Інші мотиви: героїчне фото як листівка з поштовою маркою й штемпелем, «квиток» звідки/куди, відгуки як листівки.
- Анімації вимикаються при `prefers-reduced-motion`: маршрут одразу намальований, штампи стоять.
- Мобільна панель знизу: Дзвінок · Підібрати тур · Маршрут.

## Токени та посилання-заглушки

Видимі токени обгорнуті в `<span class="ph">…</span>` (жовтувате пунктирне підкреслення). Після заміни можна прибрати клас `ph` (або залишити: без токена стиль не заважає, але краще прибрати).

| Токен / заглушка | Що це | Де трапляється |
|---|---|---|
| `[НАЗВА]` | назва агенції | `<title>`, OG, JSON-LD, логотип, штемпель у hero (SVG `textPath`), «Про нас», футер |
| `[МІСТО]` | місто | `<title>`, description, JSON-LD, eyebrow у hero, «квиток», штемпель, «Про нас», контакти, футер |
| `[АДРЕСА]` | вулиця й номер | JSON-LD, плашка на фото «Про нас», контакти, футер |
| `[ТЕЛЕФОН]` | телефон для показу | JSON-LD, меню, контакти, футер |
| `[EMAIL]` | пошта для показу | JSON-LD, контакти |
| `[ГОДИНИ]` | короткий графік, напр. «Пн–Пт 10–19, Сб 10–16» | JSON-LD `openingHours`, блок годин роботи |
| `[ІНСТАГРАМ]` | нікнейм без @ | контакти |
| `[ФОП]` | ФОП / ТОВ, ЄДРПОУ | футер |
| `[РІК]` | рік заснування | JSON-LD, «квиток» у hero, «Про нас», футер |
| `[ЦІНА]` | ціни «від … грн» | марка на листівці, картки напрямків (5), прайс (11) |
| `[ІМ'Я]` | імена | цитата засновниці, автори відгуків (3) |
| `tel:+380000000000` | дзвінок | меню, hero, контакти, мобільна панель, футер |
| `viber://chat?number=%2B380000000000` | Viber | кнопки контактів, `data-viber` форми |
| `https://t.me/username` | Telegram | кнопки контактів, `data-tg` форми |
| `https://wa.me/380000000000` | WhatsApp | кнопки контактів |
| `https://www.instagram.com/username/` | Instagram | контакти, JSON-LD `sameAs` |
| `https://www.facebook.com/username` | Facebook | контакти, JSON-LD `sameAs` |
| `mailto:hello@example.com` | пошта | контакти, `data-mail` форми |
| `%D0%86%D0%B2…%D0%BA` (Івано-Франківськ, URL-кодовано) | карта й маршрут | iframe Google Maps, кнопка «Прокласти маршрут», мобільна панель. Замініть на закодовану адресу клієнта |
| `https://example.com/` | домен | `canonical`, JSON-LD `url` |

**Графік роботи** задано в одному місці: атрибут `data-hours` у `#hours` (`"1"` = понеділок … `"0"` = неділя, `null` = вихідний) — за ним рахується «Зараз відчинено/зачинено» за київським часом. Таблицю під ним (рядки `data-day`) оновіть тими самими годинами.

**Відгуки** — три приклади з класом `ph-card` і позначкою «Приклад відгуку — замініть на реальний». Замініть тексти на справжні відгуки клієнта, приберіть клас `ph-card` і `<span class="ph-card__label">`.

**Напрямки** (Єгипет, Греція, Адріатика, Європа автобусом, Карпати), прайс, FAQ і маркетингові тексти — це редагований типовий текст для ніші: підлаштуйте під реальні напрямки агенції.

## Фото

Усі фото з Unsplash (Unsplash License), завантажені в `img/photos/` і підключені абсолютними посиланнями на `raw.githubusercontent.com`, закріпленими за SHA коміту. Список — `tools/chosen.json`, звіт — `img/photos/credits.json`.

| Слот | Що на фото | Замінити на фото клієнта? |
|---|---|---|
| `hero` | бухта з човнами згори (листівка в hero, OG-зображення) | бажано — найкраще фото з турів клієнтів |
| `tropic` | курорт на Червоному морі | можна залишити або замінити |
| `sea` | Санторіні | можна залишити |
| `coast` | бірюзова вода Адріатики | можна залишити |
| `city` | бруківка старого міста | можна залишити |
| `mountains` | Карпати на світанку | можна залишити |
| `plane` | ілюмінатор над хмарами (фон квізу) | можна залишити |
| `about` | карта, фотоапарат, паспорт | **так** — фото офісу або команди |

Щоб замінити фото: змініть URL у `tools/chosen.json` і запуште — GitHub Actions завантажить нові файли, потім оновіть SHA в посиланнях `raw.githubusercontent.com/.../<SHA>/img/photos/...` (`index.html`, `og:image`, JSON-LD).

## Як адаптувати під клієнта (5 кроків)

1. **Пошук і заміна токенів:** `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ГОДИНИ]`, `[ІНСТАГРАМ]`, `[ФОП]`, `[РІК]`, `[ІМ'Я]` — у всьому `index.html` (разом із `<head>` і JSON-LD). Потім приберіть обгортки `<span class="ph">`.
2. **Посилання:** замініть `+380000000000` (у `tel:`, `wa.me`, `viber://…%2B380000000000`), `username` у Telegram/Instagram/Facebook, `hello@example.com`, `example.com`, адресу в URL карти та маршруту.
3. **Ціни й напрямки:** проставте `[ЦІНА]` у картках і прайсі (або приберіть рядки, яких агенція не надає), підправте напрямки, сезони, FAQ.
4. **Графік і відгуки:** оновіть `data-hours` і таблицю годин; вставте 3 реальні відгуки, приберіть `ph-card` і позначки.
5. **Фото й перевірка:** замініть `hero` та `about` на фото клієнта, оновіть SHA у посиланнях, перевірте сайт на телефоні (форма відкриває Telegram/Viber/пошту з готовим текстом).
