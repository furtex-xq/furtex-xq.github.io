# Snoopy dog — демо-сайт

Шаблон: `hrumin-vet` (грумінг-салон, без ветеринарних послуг).

З OpenStreetMap підставлено: назва, місто, адреса, телефон, точка на карті.

Прибрано кнопки й канали, яких у закладу немає (Viber, Telegram, WhatsApp, пошта, Facebook, Instagram).

Ще треба заповнити (позначені жовтим пунктиром):

- `[ІМ'Я]`
- `[ГОДИНИ]`
- `[РІК]`
- `[ФОП]`
- `[ЦІНА]`
- відгуки-приклади (картки з позначкою «Приклад відгуку»)
- фото: зараз стокові з Unsplash — краще замінити на фото салону
