# Форум — демо-сайт

Шаблон: «Фітнес-клуб / спортзал» (`template/fitnes`).

Заповнено з OpenStreetMap: назва, місто, адреса, Instagram, графік роботи (таблиця і статус «відчинено»).
Джерело: https://www.openstreetmap.org/node/4349525389

Ще треба заповнити (позначені бурштиновим підкресленням): `[ІМ'Я]`, `[РІК]`, `[ФОП]`, `[ЦІНА]`.
Розклад групових (`CLASSES` у `js/main.js`) — приклад, узгодьте з клубом.
Відгуки — приклади (`ph-card`), замініть на реальні. Фото — зі стоку Unsplash, бажано замінити на фото залу й тренерів.
