# Стіна — демо-сайт

Персоналізована копія шаблону `mebli-na-zamovlennia` (меблі на замовлення).

**Заповнено з OpenStreetMap:** назва, місто, адреса, телефон.

Джерело: https://www.openstreetmap.org/node/6175361400

**Ще треба заповнити** (позначені бурштиновим підкресленням на сторінці):

- `[ІМ'Я]` — імена авторів відгуків (і самі відгуки — зараз приклади)
- `[ГОДИНИ]` — графік роботи
- `[РІК]` — рік заснування
- `[ФОП]` — ФОП / ЄДРПОУ у футері
- `[ЦІНА]` — ціни «від … грн» у прайсі, hero і конфігураторі
- фото — замінити на реальні роботи майстерні
