# Brow Bar — демо-сайт

Шаблон: **salon-krasy** (салон краси, ар-деко; Poiret One + Didact Gothic).

Заповнено з OpenStreetMap (https://www.openstreetmap.org/node/5314092472): назва, місто, адреса, Facebook, графік роботи (і статус «відчинено/зачинено»), карта й маршрут.

Видалено кнопки й варіанти зв'язку, яких немає в даних (Viber, Telegram, WhatsApp, телефон, email, Instagram).

## Залишилось заповнити

- `[ІМ'Я]`
- `[РІК]`
- `[ФОП]`
- `[ЦІНА]`
- реальні відгуки (картки з позначкою «Приклад відгуку»)
- фото клієнта, зокрема пари «до / після»
- ціни й перелік послуг під салон
