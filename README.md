# Шаблон «Танцювальна студія» (`tantsi`)

Односторінковий сайт для танцювальної студії: хіп-хоп, контемп, pole dance, латина, дитячі групи. Чистий HTML/CSS/JS без бібліотек і збірки, шрифти локально, фото за абсолютними URL, закріпленими за комітом.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/tantsi/index.html

## Дизайн
- **Шрифти:** Seymour One (заголовки, широкий і важкий, лише великими літерами) + Wix Madefor Text (текст, variable 400–800). Кирилиця, включно з і, ї, є, ґ, перевірена.
- **Палітра:** чорний `#0f0d0c`, гарячий корал `#ff5a45`, крем `#f4eadb`, пісочний `#e8dac5`, димчастий `#a69a8e`.
- **Композиція:** секції з діагональними зрізами, що чергують напрямок, косі кнопки й таби, діагональна стрічка з напрямами.
- **Фішка:** заголовок «рухається під біт». Слова H1 по черзі підскакують у темпі, метроном рахує «5-6-7-8-1-2-3-4», стрічка біжить з тією ж швидкістю. Вибір напряму в блоці «Оберіть свій стиль» змінює темп (BPM) і одразу фільтрує розклад. Є кнопка паузи; при `prefers-reduced-motion` ритм вимкнено.
- Блок «Як почати» пронумеровано як танцювальний відлік: 5, 6, 7, 8.

## Плейсхолдери
Видимі токени обгорнуто в `<span class="ph">…</span>` (жовтий пунктир). Після заміни обгортку варто прибрати.

| Токен / сентинел | Де |
|---|---|
| `[НАЗВА]` | title, og:title, JSON-LD, логотип, «Студія», футер, текст заявки в `js/main.js` |
| `[МІСТО]` | title, description, og, JSON-LD, eyebrow героя («у [МІСТО]»), адреса, футер |
| `[АДРЕСА]` | JSON-LD, контакти, футер |
| `[ТЕЛЕФОН]` | JSON-LD, меню, великий номер у контактах, футер, noscript |
| `[EMAIL]` | JSON-LD, кнопка в контактах, футер |
| `[ІНСТАГРАМ]` | кнопка Instagram у контактах (handle) |
| `[ГОДИНИ]` | підсумок графіка над таблицею |
| `[ФОП]` | футер (назва ФОП / ЄДРПОУ) |
| `[РІК]` | «працює з [РІК] року», JSON-LD foundingDate |
| `[ЦІНА]` | прайс (9 позицій «від [ЦІНА] грн»), JSON-LD priceRange |
| `[ІМ'Я]` | викладачі (4), підписи відгуків (3) |
| `tel:+380000000000` | меню, герой, контакти, футер, нижня панель |
| `viber://chat?number=%2B380000000000` | контакти |
| `https://t.me/username` | контакти |
| `https://wa.me/380000000000` | контакти |
| `https://www.instagram.com/username/` | контакти, футер, JSON-LD sameAs |
| `https://www.facebook.com/username` | контакти, футер, JSON-LD sameAs |
| `mailto:hello@example.com` | контакти, футер |
| `var CONTACT = {…}` у `js/main.js` | адреси для форми: telegram, viber, whatsapp, sms, instagram, email. Видаліть ключ — зникне й варіант у формі |
| Мапа `q=Івано-Франківськ` | iframe і посилання «Маршрут» (`destination=`) |

Канали позначено атрибутом `data-ch="tel|viber|telegram|whatsapp|instagram|facebook|email|sms"`: якщо в клієнта немає каналу, видаліть рядки з цим атрибутом.

Також замінити: 3 відгуки (`ph-card`, «Приклад відгуку»), розклад (масив `SCHEDULE` у `js/main.js`, позначка «Приклад розкладу»), графік роботи (рядки `tr data-day data-open data-close`, 0 = неділя), JSON-LD `openingHours`.

## Фото (Unsplash, замінити на фото студії)
`img/photos/`: `hero` (танцівниця на довгій витримці), `hiphop`, `contemp`, `pole`, `latina`, `group` (дитяча група), `alt2` (зал, блок «Студія»). Решта (`kids`, `studio`, `alt1`, `alt3`, `alt4`) — запасні. Найкраще попросити в клієнта: фото залу, групові заняття, кадри зі звітного концерту, фото викладачів.

## Як адаптувати для клієнта
1. Замініть токени `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]` тощо (find-and-replace) і зніміть обгортки `class="ph"`; для «у [МІСТО]» поставте місцевий відмінок.
2. Пропишіть реальні посилання замість сентинелів, оновіть `CONTACT` у `js/main.js`, приберіть рядки `data-ch` для каналів, яких немає.
3. Оновіть графік роботи (таблиця + JSON-LD), розклад `SCHEDULE`, прайс і перелік напрямів під студію.
4. Замініть фото на власні (або нові URL), відгуки на реальні, імена викладачів.
5. Перевірте на телефоні: меню, таби, форму (відкривається потрібний месенджер), статус «відчинено/зачинено», мапу.

Для лідів є генератор: `python3 tools/personalize.py <lead.json> <outdir>`.
