# Шаблон «Меблі на замовлення» (`mebli-na-zamovlennia`)

Універсальний односторінковий сайт для столярної майстерні / виробника корпусних меблів: кухні, шафи-купе, гардеробні, передпокої. Чистий HTML/CSS/JS без бібліотек і збірки, мобільна версія в пріоритеті.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/mebli-na-zamovlennia/index.html

## Дизайн

- **Напрям:** скандинавське дерево + архітектурне креслення. Розмірні лінії над фото, штамп креслення («Виріб / Фасади / Масштаб»), футер у вигляді основного напису креслення з реквізитами.
- **Шрифти:** Piazzolla (заголовки, 400 / 400 italic / 600) + Arsenal (текст, 400 / 400 italic / 700). Локально в `fonts/`, лише `cyrillic` + `latin`, `font-display: swap`.
- **Палітра:** льон `#E7E3DB` (фон), папір `#F2F0EB`, графіт `#262624` (текст і лінії), дуб `#A9773F` (акцент), мох `#4F5B3A` (кнопки дій), бурштин `#D99A1E` (лише для позначення заглушок).
- **Фішка:** конфігуратор кухні. Користувач обирає форму (пряма / кутова / П-подібна), довжини стін і колір фасадів. SVG-план (М 1:50, заштриховані стіни, мийка, плита, холодильник, розмірні лінії) і розгортка стіни А перемальовуються одразу. Кнопка «Надіслати ескіз на прорахунок» підставляє параметри в коментар форми. Друга фішка: таймлайн «замір → монтаж», лінія якого заповнюється під час прокручування.
- Анімації вимикаються при `prefers-reduced-motion`.

## Заглушки (токени)

Видимі заглушки обгорнуті в `<span class="ph">…</span>`. Після заміни тексту клас `ph` можна прибрати (або обнулити стиль `.ph` у CSS).

| Токен | Що підставити | Де трапляється |
|---|---|---|
| `[НАЗВА]` | назва компанії | `<title>`, og:site_name, JSON-LD, логотип, блок «Майстерня», підпис робіт, футер |
| `[МІСТО]` | місто (називний відмінок, напр. «Івано-Франківськ») | title, description, JSON-LD, hero, контакти, футер |
| `[АДРЕСА]` | вулиця, будинок | JSON-LD, контакти, футер |
| `[ТЕЛЕФОН]` | телефон для показу | description, JSON-LD, меню, контакти, успіх форми, футер |
| `[EMAIL]` | пошта | JSON-LD, контакти |
| `[ГОДИНИ]` | короткий графік, напр. «Пн–Пт 9–18, Сб 10–15» | JSON-LD (`openingHours`), блок графіка, футер |
| `[ІНСТАГРАМ]` | @нікнейм | блок «Роботи», контакти |
| `[ФОП]` | ФОП / ТОВ, ЄДРПОУ / ІПН | футер |
| `[РІК]` | рік заснування | JSON-LD, hero, «Майстерня», © у футері |
| `[ЦІНА]` | ціна «від … грн» | hero, прайс-таблиця (6 позицій), доставка, конфігуратор, JSON-LD `priceRange` |
| `[ІМ'Я]` | імена авторів відгуків | 3 картки відгуків |

**Відгуки:** три картки з класом `ph-card` і позначкою «Приклад відгуку — замініть на реальний». Замініть текст на реальні відгуки, видаліть `<span class="ph-label">` і клас `ph-card`.

**Графік із статусом «зараз відчинено / зачинено»:** таблиця `.hours-table` в `index.html`. Атрибут `data-days` містить дні тижня (0 = нд, 1 = пн … 6 = сб), а клітинка — години у форматі `09:00–18:00`. JS рахує статус за київським часом. Вихідний день: будь-який текст без часу.

### Посилання-заглушки (не видно на сторінці)

| Заглушка | Замінити на | Де |
|---|---|---|
| `tel:+380000000000` | `tel:+380XXXXXXXXX` | меню, контакти, нижня мобільна панель, успіх форми, футер |
| `viber://chat?number=%2B380000000000` | номер Viber | контакти, `js/main.js` (`LINK_VIBER`) |
| `https://t.me/username` | Telegram | контакти, `js/main.js` (`LINK_TG`) |
| `https://wa.me/380000000000` | WhatsApp | контакти |
| `https://www.instagram.com/username/` | Instagram | JSON-LD, «Роботи», контакти |
| `https://www.facebook.com/username` | Facebook | JSON-LD, контакти |
| `mailto:hello@example.com` | пошта | контакти, `js/main.js` (`LINK_MAIL`) |
| `https://www.google.com/maps?q=%D0%86…&output=embed` | `?q=<закодована адреса>&output=embed` | iframe карти |
| `https://www.google.com/maps/dir/?api=1&destination=…` | закодована адреса | кнопка «Маршрут» мобільної панелі |

Форма не має бекенду: після перевірки полів вона формує текст заявки, копіює його в буфер і відкриває Telegram, Viber або пошту (вибір користувача).

## Фото

Фото зі Unsplash (Unsplash License) лежать у `img/photos/`, джерела в `tools/chosen.json` і `img/photos/credits.json`. У HTML вони підключені абсолютними URL `raw.githubusercontent.com/.../<SHA>/img/photos/...` (так вони стабільно вантажаться в iPhone Safari). **Усі фото бажано замінити на реальні роботи клієнта:**

| Файл | Що зараз | Чим замінити |
|---|---|---|
| `hero.jpg` | сучасна кухня дуб + чорна стільниця | найкраща кухня клієнта, горизонтальне фото |
| `kitchen.jpg` | кухня під горіх з островом (вертикальне) | кухня клієнта |
| `hero-c.jpg` | пряма кухня з підсвіткою | ще одна кухня |
| `drawer.jpg` | шухляда з тримачами посуду | деталь: фурнітура, наповнення |
| `wardrobe2.jpg` | шафа в спальню під дуб | шафа-купе / розпашна шафа клієнта |
| `closet.jpg` | гардеробна кімната | гардеробна клієнта |
| `living.jpg` | шафи з рифленими фасадами | передпокій / вітальня / інша робота |
| `workshop2.jpg` | руки майстра з олівцем | фото цеху або майстра клієнта |
| `oak.jpg` | текстура дуба | зразки матеріалів клієнта |

Щоб замінити фото: покладіть свої файли в `img/photos/` з тими самими іменами, закомітьте і замініть SHA в усіх URL фото в `index.html` (або перейдіть на відносні шляхи `img/photos/...`, якщо сайт буде на звичайному хостингу).

## Як адаптувати під клієнта (5 кроків)

1. **Тексти-токени:** знайдіть і замініть всі `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ІНСТАГРАМ]`, `[ФОП]`, `[РІК]`, `[ГОДИНИ]` в `index.html` (включно з `<head>` і JSON-LD).
2. **Ціни:** пройдіть по кожному `[ЦІНА]` у прайсі, hero і конфігураторі. Якщо клієнт не дає ціни, напишіть «за прорахунком».
3. **Контакти:** замініть посилання-заглушки (`tel:`, Viber, Telegram, WhatsApp, Instagram, Facebook, mailto) в `index.html` **і** три константи на початку `js/main.js`. Оновіть адресу в iframe карти та в кнопці «Маршрут». Підправте таблицю графіка.
4. **Фото й відгуки:** замініть фото (таблиця вище) на роботи клієнта, впишіть реальні відгуки, приберіть `ph-card` і позначки «Приклад відгуку».
5. **Фініш:** приберіть клас `ph` (або обнуліть `.ph` у `css/style.css`), перевірте `og:image`, title і description, відкрийте сайт на телефоні й перевірте форму та кнопки дзвінка.
