# Попелюшка — демо-сайт (хімчистка і пральня)

Шаблон: **klininh**, варіант **himchystka** (хімчистка і пральня).

Заповнено з OpenStreetMap: назва, місто, адреса, телефон, Facebook, графік роботи.

Залишилося заповнити (на сторінці позначені жовтим пунктиром):

- `[ІМ'Я]` — імена авторів відгуків
- `[РІК]` — рік заснування (підпис до фото в «Про нас»)
- `[ФОП]` — ФОП / ТОВ і ЄДРПОУ у футері
- `[ЦІНА]` — ціни: калькулятор (атрибути data-price / data-rate) і прайс у «Послуги й ціни»
- три відгуки з міткою «Приклад відгуку» — замінити на реальні
- блок «До і після» — замінити на реальну пару фото (і прибрати клас `is-sim`)
- фото (зараз стокові з Unsplash) — замінити на фото закладу й робіт
- перелік послуг і позицій калькулятора — звірити з реальним прайсом
