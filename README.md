# Інтер Атлетика — демо-сайт

Шаблон: «Спорттовари / велосипеди / прокат» (`template/sport-velo`), акцент: спортивний магазин.

Заповнено з OpenStreetMap: назва, місто, адреса (карта й маршрут), телефон, графік роботи (таблиця і статус «відчинено»).
Джерело: https://www.openstreetmap.org/node/6175361395

Ще треба заповнити (позначені бурштиновим підкресленням): `[ІМ'Я]`, `[РІК]`, `[ФОП]`, `[ЦІНА]`.
Тарифи прокату для калькулятора — у `js/main.js` (`RENT`).
Відгуки — приклади (`ph-card`), замініть на реальні. Фото — зі стоку Unsplash, бажано замінити на фото магазину.
