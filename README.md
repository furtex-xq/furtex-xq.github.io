# Шаблон «Агенція нерухомості» (`nerukhomist`)

Універсальний односторінковий демо-сайт для агенції нерухомості чи приватного ріелтора. Статичний HTML/CSS/JS без збірки та без CDN: `index.html`, `css/style.css`, `js/main.js`, шрифти в `fonts/`.

Демо: `https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/nerukhomist/index.html`

## Дизайн

- **Шрифти:** Bona Nova (заголовки, ціни — класична антиква з курсивом) + Roboto Flex (variable, текст, підписи, характеристики). Обидва з кирилицею, локально в `fonts/` (cyrillic + latin), `font-display: swap`.
- **Палітра:** камінь `#e3e0d9`, папір `#f2f0eb`, глибокий лісовий зелений `#1d3a2e` / `#14291f`, латунь `#a6814a` / `#c9a66b`, графіт `#18201b`.
- **Архітектурна сітка:** тонкі колонки на фоні першого екрана, розмірні лінії «6,40 м / 4,15 м» навколо головного фото, міліметрівка в калькуляторі.
- **Фішка:** каталог об'єктів з фільтрами (купівля/оренда, кімнати, район) + кнопка «План» на кожній картці — фото змінюється на креслення планування, яке «домальовується» лініями. Швидкий пошук на першому екрані передає параметри у фільтр.
- Також: іпотечний калькулятор (вартість, внесок, строк, ставка → щомісячний платіж, діаграма внесок/кредит/відсотки, кнопка переносить бюджет у форму), форма «Оцінити мою квартиру» для продавців, статус «зараз відчинено/зачинено» за київським часом, нижня панель дій на мобільному (Подзвонити / На перегляд / Маршрут).
- Анімації: легкі появи при скролі (IntersectionObserver), вимикаються при `prefers-reduced-motion`.

## Плейсхолдери

Видимі токени обгорнуті в `<span class="ph">…</span>` (жовте пунктирне підкреслення). Після заміни можна прибрати обгортку або просто видалити стиль `.ph` у CSS.

| Токен / сентинел | Де зустрічається |
|---|---|
| `[НАЗВА]` | `<title>`, OG, JSON-LD, логотип, «Про агенцію», футер, текст заявки в `js/main.js` |
| `[МІСТО]` | `<title>`, description, keywords, OG, JSON-LD (`addressLocality`, `areaServed`), eyebrow і лід першого екрана, «Про агенцію», адреса в контактах, футер |
| `[АДРЕСА]` | JSON-LD, контакти, футер |
| `[ТЕЛЕФОН]` | JSON-LD, шапка (кнопка й мобільне меню), контакти, футер |
| `[EMAIL]` | JSON-LD, контакти, футер |
| `[ГОДИНИ]` | JSON-LD `openingHours`, підсумок під «Години роботи» |
| `[ІНСТАГРАМ]` | кнопка Instagram у контактах |
| `[ФОП]` | футер («ФОП / ЄДРПОУ: …») |
| `[РІК]` | JSON-LD `foundingDate`, підпис на фото в «Про агенцію» |
| `[ЦІНА]` | ціни об'єктів (`[ЦІНА] грн`, оренда `[ЦІНА] грн / міс`), прайс послуг (`від [ЦІНА] грн`) |
| `[ІМ'Я]` | керівник агенції в «Про агенцію», автори відгуків |
| `ph-card` + «Приклад відгуку — замініть на реальний» | 3 картки відгуків |
| «Приклади об'єктів — замініть на реальні» | заголовок блоку «Об'єкти» (6 карток-прикладів: площа, поверх, район — редагований приклад) |
| `tel:+380000000000` | шапка, меню, контакти, футер, мобільна панель |
| `viber://chat?number=%2B380000000000` | контакти, `js/main.js` (константа `VIBER`) |
| `https://t.me/username` | контакти, FAQ, `js/main.js` (константа `TG`) |
| `https://wa.me/380000000000` | контакти |
| `https://www.instagram.com/username/` | контакти, JSON-LD `sameAs` |
| `https://www.facebook.com/username` | контакти, JSON-LD `sameAs` |
| `mailto:hello@example.com` | контакти, футер, `js/main.js` (константа `MAIL`) |
| `https://www.google.com/maps?q=Івано-Франківськ&output=embed` (URL-encoded) | карта в контактах; `…/maps/dir/?api=1&destination=…` — кнопка «Маршрут» |

Інше, що редагується як звичайний текст: райони у фільтрах (`<select>` у пошуку й фільтрі + `data-district` карток), розклад у `data-hours` блоку `#hours` (ключі 0–6 = неділя–субота, `[год_відкриття, год_закриття]` або `null`) і рядки таблиці годин, планування карток (`data-plan="1|2|3"`, схеми — об'єкт `PLANS` у `js/main.js`), стартові значення калькулятора (атрибути `value` повзунків).

## Фото (Unsplash, замінити на фото клієнта)

Фото лежать у `img/photos/` і підключені абсолютними посиланнями raw.githubusercontent, закріпленими за SHA коміту.

| Файл | Що зараз | Чим замінити |
|---|---|---|
| `hero.jpg` | світла вітальня | найкращий інтер'єр з об'єктів агенції |
| `l1.jpg`–`l6.jpg` | інтер'єри квартир / будинку | реальні об'єкти з бази агенції |
| `building.jpg` | фасад житлового будинку | офіс, команда або впізнаваний будинок міста |
| `keys.jpg` | ключі в руці | передача ключів реальному клієнту |

Ліцензія та джерела — `img/photos/credits.json`.

## Як адаптувати під клієнта (5 кроків)

1. Знайти й замінити токени `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ГОДИНИ]`, `[ІНСТАГРАМ]`, `[ФОП]`, `[РІК]`, `[ІМ'Я]` в `index.html` і `js/main.js`.
2. Замінити сентинели посилань (телефон, Viber, Telegram, WhatsApp, Instagram, Facebook, email) і місто в посиланнях карти та маршруту.
3. Оновити 6 карток об'єктів (назва, район, площа, поверх, ціна, тип угоди, `data-*`) і прайс послуг; прибрати позначку «Приклади об'єктів».
4. Замінити фото в `img/photos/` на фото клієнта і поставити реальні відгуки замість карток `ph-card`.
5. Перевірити графік у `data-hours`, відкрити сайт на телефоні, надіслати тестову заявку з обох форм.
