# EOX Tatoo — демо-сайт

Шаблон: **tatu** (тату-салон; Ruslan Display + Anonymous Pro, флеш-лист із фільтром стилів і калькулятор місце/розмір).

Заповнено з OpenStreetMap (https://www.openstreetmap.org/node/11677447235): назва, місто, адреса, телефон, Instagram, карта й маршрут.

Видалено кнопки й варіанти зв'язку, яких немає в даних: Viber, Telegram, WhatsApp, email, Facebook.

Заявка з форми надсилається через: SMS, Instagram.

## Залишилось заповнити

- `[ІМ'Я]`
- `[ГОДИНИ]`
- `[РІК]`
- `[ФОП]`
- `[ЦІНА]`
- реальні відгуки (картки з позначкою «Приклад відгуку»)
- фото робіт і майстрів студії замість стокових, власний флеш-лист
- ціни (також числа в `PRICE` у `js/main.js` для калькулятора)
- графік роботи (таблицю й статус «відчинено» приховано, доки його немає)
