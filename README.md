# Corassini Grill & Wine — демо-сайт

Шаблон: `restoran` (ресторан). Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/beta/corassini-grill-wine/index.html

Заповнено з OpenStreetMap: назва, місто, адреса, телефон, Instagram, карта і маршрут.

Залишилось заповнити (підсвічено пунктиром на сторінці):

- `[ІМ'Я]` — шеф і автори відгуків
- `[ГОДИНИ]` — години роботи
- `[РІК]` — рік відкриття
- `[ФОП]` — ФОП / ЄДРПОУ у футері
- `[ЦІНА]` — ціни в меню, середній чек, банкет на гостя
- 3 відгуки-приклади (картки «Приклад відгуку») — замінити на реальні
- меню (страви й описи) та фото — типові для ресторану, замінити на реальні
