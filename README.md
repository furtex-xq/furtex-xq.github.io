# Франк — демо-сайт

Персоналізована демо-версія шаблону **«Кав'ярня / кав'ярня-пекарня» (`kavyarnia`)** для «Франк», Крихівці.

**Заповнено з OpenStreetMap:** назва, місто, адреса, instagram, графік роботи.
Джерело: https://www.openstreetmap.org/node/8069751731

**Ще треба заповнити (позначено жовтим на сторінці):**
- `[ІМ'Я]`
- `[РІК]`
- `[ФОП]`
- `[ЦІНА]`
- приклади відгуків (картки з міткою «Приклад відгуку») — замінити на реальні;
- фото з Unsplash — замінити на фото закладу;
- меню й тексти — звірити з реальним асортиментом і умовами.
