# Аравмед — демо-сайт медичного центру

Шаблон: **klinika** (медичний центр / клініка).

Заповнено з OpenStreetMap: назва, місто, адреса, телефон, графік роботи.

Залишилося заповнити (позначені жовтим пунктиром на сторінці):

- `[ІМ'Я]` — імена лікарів і авторів відгуків
- `[РІК]` — рік заснування (блок «Про центр»)
- `[ФОП]` — ФОП / ТОВ і ЄДРПОУ у футері
- `[ЦІНА]` — ціни послуг (табло лікарів, прайс, головний екран)
- три відгуки з міткою «Приклад відгуку» — замінити на реальні
- фото (зараз стокові з Unsplash) — замінити на фото клініки
- перелік лікарів і послуг у табло та прайсі — звірити з реальним
