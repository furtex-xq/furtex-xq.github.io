# Шаблон «Психолог / психотерапевт» (`template/psykholoh`)

Односторінковий сайт для приватного психолога (або невеликого кабінету): консультації очно й онлайн, робота з парами. Чистий HTML/CSS/JS без збірки і без зовнішніх бібліотек: `index.html`, `css/style.css`, `js/main.js`.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/psykholoh/index.html

## Дизайн

- **Шрифти:** Merriweather (змінна вага, заголовки, легкі 300–400) + Shantell Sans (текст: «живий», рукописний, але читабельний). Лежать локально у `fonts/` (cyrillic + latin, woff2).
- **Палітра:** тепле паперове тло `#efeae1`, графіт `#262a31`, шавлія `#3e5a49` / `#7a9480` / `#d8e0d4`, сутінковий синій `#28324b` / `#46557a` / `#d3d9e6`, абрикос `#e3aa7c` для акцентів.
- **Мотив:** арка (вікно, двері кабінету) — у фото, карті, логотипі; м'які «камінці» замість декоративних плям; багато повітря.
- **Фішка:** самоперевірка «Що вас привело?» — три м'які питання (про кого, як зручніше, «внутрішня погода»). Небо панелі змінюється від ясного до грози, а внизу з'являється порада щодо формату (індивідуальна / пара / онлайн) з кнопкою запису, яка підставляє формат у форму. На «грозі» показується блок кризової допомоги (Lifeline Ukraine 7333, 112). Це не тест і не діагноз, відповіді нікуди не надсилаються.
- **Блок конфіденційності** — окремий темний розділ із чіткими правилами і «єдиною межею».
- Плавна поява блоків, `prefers-reduced-motion` вимикає анімації. Нижня панель на мобільному: Дзвінок / Записатися / Маршрут.

## Токени і сентинели

| Токен / рядок | Де |
|---|---|
| `[НАЗВА]` | шапка, «Я — [НАЗВА], психолог», футер, `<title>`, OG, JSON-LD, aria-label логотипа |
| `[МІСТО]` | H1 «Психолог у [МІСТО]», формат «очно в [МІСТО]», адреса, футер, `<title>`, description, OG, JSON-LD |
| `[АДРЕСА]` | контакти, футер, JSON-LD |
| `[ТЕЛЕФОН]` | контакти, картка «Запис — телефоном», meta description, JSON-LD |
| `[EMAIL]` | контакти, JSON-LD |
| `[ІНСТАГРАМ]` | контакти (нік) |
| `[ГОДИНИ]` | «Години прийому» (підсумок текстом) |
| `[ФОП]` | футер |
| `[РІК]` | «Практика з [РІК] року» |
| `[ОСВІТА]`, `[ПІДХІД]` | блок «Про мене» — освіта і метод (КПТ, гештальт тощо). Лише зі слів клієнта, нічого не вигадувати |
| `[ЦІНА]` | 4 формати в прайсі, JSON-LD `priceRange` |
| `[ІМ'Я]` | підписи відгуків |
| `ph-card` | 3 приклади відгуків з позначкою «Приклад відгуку — замініть на реальний» |
| `tel:+380000000000` | кнопки дзвінка (герой, контакти, нижня панель, картка дзвінка) |
| `https://t.me/username`, `viber://chat?number=%2B380000000000`, `https://wa.me/380000000000` | контакти; Telegram/Viber також у формі |
| `https://www.instagram.com/username/`, `https://www.facebook.com/username` | контакти, JSON-LD `sameAs` |
| `mailto:hello@example.com` | контакти; email у формі |
| Google Maps `?q=Івано-Франківськ` | iframe карти, «Прокласти маршрут», «Маршрут» у нижній панелі |

У `js/main.js` на початку: `HOURS` (графік для таблиці й статусу «Зараз приймаю», `null` — сховати) і `CONTACT` (канали для форми: telegram, viber, email, sms, instagram).

Елементи каналів мають `data-ch="tel|tg|viber|wa|ig|fb|mail"` — їх можна прибрати цілком, і верстка не ламається. Якщо форми немає куди надсилати, замість неї показується картка `data-alt="call"` («Запис — телефоном»).

## Фото (Unsplash, замінити на власні)

`hero` — світла кімната з кріслом і рослинами; `room` — два крісла (кабінет); `notes` — квіти, блокнот і чашка; `mug` — чашка на підвіконні; `shore` — двоє на березі (блок конфіденційності); `cozy` — крісла біля арочного вікна (FAQ). Найкраще замінити `hero`, `room` і `notes` на фото реального кабінету та портрет психолога. Посилання на фото закріплені за комітом (`raw.githubusercontent.com/.../<SHA>/img/photos/...`).

## Як адаптувати під клієнта

1. Замініть `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ІНСТАГРАМ]`, `[ФОП]` (пошук-заміна по `index.html`); після «у/в» місто — у місцевому відмінку.
2. Підставте реальні посилання замість сентинелів; приберіть непотрібні канали (`data-ch`); у `js/main.js` заповніть `CONTACT` і `HOURS`.
3. Уточніть у клієнта формати, тривалість сесій і ціни — замініть `[ЦІНА]`; заповніть `[ОСВІТА]`, `[ПІДХІД]`, `[РІК]` лише з його слів.
4. Замініть фото і 3 приклади відгуків (`ph-card`) на реальні або приберіть блок.
5. Оновіть карту (`?q=` і `destination=`), перевірте сайт на телефоні і приберіть клас `ph` з усіх заповнених місць.

Автоматично для лідів: `python3 tools/personalize.py <lead.json> <outdir>`.
