# Шаблон «Магазин автозапчастин» (`avtozapchastyny`)

Універсальний односторінковий сайт для магазину автозапчастин (Івано-Франківськ та інші міста). Чистий HTML/CSS/JS без бібліотек і збирання: `index.html`, `css/style.css`, `js/main.js`, шрифти локально в `fonts/`.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/avtozapchastyny/index.html

## Дизайн
- **Напрям:** «каталожна чіткість» — білий фон, асфальтово-сірий, гоночний червоний; щільна сітка з тонкими лініями, як у паперовому каталозі запчастин.
- **Шрифти:** Sofia Sans Extra Condensed (800/600, заголовки) + Sofia Sans (400/600/700, текст). У кириличних файлах шрифтів «запечено» стандартні (не болгарські) форми літер д, л, в, т тощо — щоб українською читалось звично.
- **Палітра:** `#FFFFFF` білий · `#F2F3F4` бетон · `#D8DBDE` лінія · `#24282D` асфальт · `#5F666E` сірий текст · `#D6261D` гоночний червоний. Бурштиновий `#E39A12` — лише для плейсхолдерів.
- **Фішка:** «Підбір деталі» у 3 кроки (Авто → Деталь → Контакт) з прогресом. VIN вводиться в 17 «клітинок», які заповнюються наживо й підсвічують недопустимі літери I/O/Q. Рядок VIN у першому екрані передає дані у форму (VIN або «марка модель рік»), а плитки каталогу (без логотипів брендів) одним дотиком додають розділ у заявку. Заявка відкривається в Telegram / Viber / пошті з готовим текстом.
- Статус «зараз відчинено/зачинено» за київським часом (з таблиці графіка), липка мобільна панель «Дзвінок / Підбір за VIN / Маршрут», `prefers-reduced-motion` враховано.

## Плейсхолдери (знайти й замінити)
Видимі токени обгорнуті в `<span class="ph">…</span>` (бурштинове підкреслення). Після заміни класи `ph` можна прибрати (або залишити — тоді прибрати стиль `.ph` у CSS).

| Токен / сентинел | Де зустрічається |
|---|---|
| `[НАЗВА]` | `<title>`, OG, JSON-LD, логотип у шапці й футері, «Про магазин», копірайт |
| `[МІСТО]` | `<title>`, description, JSON-LD, перший екран, адреси, футер |
| `[АДРЕСА]` | верхня смуга, «Про магазин», контакти, футер, JSON-LD |
| `[ТЕЛЕФОН]` | верхня смуга, контакти (великий номер), футер, JSON-LD, description |
| `[EMAIL]` | контакти, футер, JSON-LD |
| `[ГОДИНИ]` | верхня смуга, «Про магазин», підпис під графіком, JSON-LD `openingHours` |
| `[ІНСТАГРАМ]` | кнопка Instagram у контактах |
| `[ФОП]` | футер (назва ФОП / ЄДРПОУ) |
| `[РІК]` | «Працюємо з … року», JSON-LD `foundingDate` |
| `[ЦІНА]` | «від [ЦІНА] грн» — плитки каталогу, бирка на фото в першому екрані, таблиця цін (аналог/оригінал), JSON-LD `priceRange` |
| `[ІМ'Я]` | імена авторів відгуків |
| `.ph-card` + «Приклад відгуку — замініть на реальний» | 3 картки відгуків — замінити на реальні відгуки й прибрати мітку |
| `tel:+380000000000` | верхня смуга, контакти, футер, мобільна панель |
| `viber://chat?number=%2B380000000000` | кнопка Viber; JS бере звідси номер для заявки |
| `https://t.me/username` | кнопка Telegram; JS відкриває його із заявкою та зворотним дзвінком |
| `https://wa.me/380000000000` | кнопка WhatsApp |
| `https://www.instagram.com/username/` | кнопка Instagram, JSON-LD `sameAs` |
| `https://www.facebook.com/username` | кнопка Facebook, JSON-LD `sameAs` |
| `mailto:hello@example.com` | кнопка email, футер; JS використовує для заявки поштою |
| `https://www.google.com/maps?q=Івано-Франківськ…` (закодовано) | iframe карти, «Прокласти маршрут», мобільна панель — замінити на точну адресу/посилання з Google Maps |

**Графік роботи:** таблиця в контактах має атрибути `data-open` / `data-close` (типово Пн–Пт 09:00–19:00, Сб 09:00–16:00, Нд вихідний). Змініть і текст, і атрибути — з них рахується статус «відчинено/зачинено».

**Ціни в таблиці:** позиції — типовий набір для магазину; змініть список під асортимент клієнта.

## Фото (Unsplash, замінити на фото клієнта)
Фото лежать у `img/photos/`, на сторінці підключені абсолютними URL raw.githubusercontent.com, закріпленими за комітом (`0791a2d…`). Для клієнта найкраще замінити:
- `hero.jpg` — гальмівний диск і супорт (перший екран, OG-зображення) → фото вітрини/залу магазину або фірмової полиці з деталями;
- `shop.jpg` — стенд із деталями вихлопу («Про магазин») → фасад, торговий зал, склад клієнта;
- `tires.jpg` — гальмівний диск на знятому колесі («Про магазин», мале) → прилавок/команда магазину;
- `mechanic.jpg` — руки майстра з ключем (блок послуг) → фото з партнерського СТО або видачі замовлення;
- `engine.jpg`, `suspension.jpg`, `plugs.jpg`, `lights.jpg` — плитки каталогу → можна лишити або зняти реальні полиці відповідних розділів.
Список і джерела — `tools/chosen.json`, `img/photos/credits.json`.

## Як адаптувати під клієнта (5 кроків)
1. Знайти й замінити всі токени з таблиці (`[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`…) в `index.html`; у `<title>`/description лишити ключ «автозапчастини Івано-Франківськ».
2. Замінити сентинели посилань (телефон, Viber, Telegram, WhatsApp, Instagram, Facebook, email) та URL карти/маршруту на реальні.
3. Оновити графік (`data-open`/`data-close` + текст), ціни `[ЦІНА]` у каталозі й таблиці, перелік позицій під асортимент.
4. Замінити фото на фото клієнта (той самий розмір/пропорції, оновити `width`/`height`), вставити 3 реальні відгуки й прибрати клас `ph-card` з міткою.
5. Прибрати клас `ph` (або стиль `.ph`), вказати `[ФОП]`/ЄДРПОУ у футері, перевірити сайт на телефоні й надіслати форму підбору на кожен канал.
