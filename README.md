# Шаблон «Готель / міні-готель» (`template/hotel`)

Односторінковий сайт для готелю, міні-готелю, апарт-готелю чи садиби. Чистий HTML/CSS/JS без бібліотек і збирання: `index.html`, `css/style.css`, `js/main.js`, шрифти в `fonts/`.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/hotel/index.html

## Дизайн

- **Шрифти:** Forum (заголовки, ціни, цифри на брелоках) + Open Sans variable (текст). Локально, лише cyrillic + latin.
- **Палітра:** соснова зелень `#1e3b30`, теплий камінь `#cfc5b4` / `#e6dfd2`, вершки `#f4eee3`, мідь `#a65a2e` (акцент), чорнило `#1a221e`.
- **Фішка:** підбір номера за датами й гостями. У hero — смужка «Заїзд / Виїзд / Гості», ночі показані місяцями. Картки номерів мають мідний брелок ключа з цифрою «скільки гостей вміщує»; після підбору підходящі номери підсвічуються, а брелоки гойдаються, непідходящі — тьмяніють із підказкою. Кнопка «Запитати» переносить дати, гостей і номер у форму заявки.
- Окремий блок «напряму, а не через агрегатор» (без комісії Booking) у вигляді порівняльної таблиці.
- Композиція: арочне фото в hero, колаж «ключі + дзвоник», прайс із крапковими лініями, кроки бронювання, FAQ, контакти з картою, нижня мобільна панель «Дзвінок / Забронювати / Маршрут».

## Плейсхолдери

Видимі токени обгорнуті в `<span class="ph">…</span>` (бурштинове підкреслення). Після заміни обгортку можна прибрати.

| Токен / заглушка | Де |
|---|---|
| `[НАЗВА]` | title, og:site_name, JSON-LD, шапка, H1, «Про нас», футер |
| `[МІСТО]` | title, description, og:title, JSON-LD, H1 («готель у [МІСТО]» — місцевий відмінок), контакти, футер |
| `[АДРЕСА]` | JSON-LD, контакти, футер |
| `[ТЕЛЕФОН]` | description, JSON-LD, меню (моб.), контакти, блок «по телефону», повідомлення про успіх, футер |
| `[EMAIL]` | JSON-LD, контакти, футер |
| `[ГОДИНИ]` | JSON-LD `openingHours`, блок «Рецепція» |
| `[ІНСТАГРАМ]` | кнопка Instagram у контактах |
| `[ФОП]` | футер |
| `[РІК]` | «Про нас», JSON-LD `foundingDate` |
| `[ЦІНА]` | картки номерів, прайс, JSON-LD `priceRange` (завжди як «від [ЦІНА] грн») |
| `[ІМ'Я]` | підпис власника, відгуки |
| `.ph-card` | 3 приклади відгуків — замінити на реальні |
| `tel:+380000000000` | усі кнопки дзвінка |
| `viber://chat?number=%2B380000000000`, `https://wa.me/380000000000`, `https://t.me/username` | контакти + `CONTACT` у `js/main.js` |
| `https://www.instagram.com/username/`, `https://www.facebook.com/username` | контакти, JSON-LD `sameAs` |
| `mailto:hello@example.com` | контакти, футер, `CONTACT.email` |
| `https://www.google.com/maps?q=Івано-Франківськ&output=embed` | iframe карти; маршрут — `https://www.google.com/maps/dir/?api=1&destination=…` |

Налаштування в `js/main.js`: `HOURS` (графік рецепції; `[0, 24]` = цілодобово, `null` = невідомо → статус ховається) і `CONTACT` (куди форма надсилає заявку: telegram, viber, email, sms, instagram, messenger). Щоб сума «за N ночей» рахувалась сама, додайте картці номера `data-price="1800"`. Номери (назва, `data-cap` = скільки гостей) редагуються прямо в HTML.

Кожен канал зв'язку має атрибут `data-ch` (tel, viber, tg, wa, ig, fb, mail) — непотрібні можна видаляти цілим елементом. Блок `[data-callonly]` — запасний варіант «бронювання по телефону», якщо в клієнта немає жодного месенджера чи email.

## Фото (Unsplash, замінити на фото клієнта)

Лежать у `img/photos/`, підключені абсолютними URL raw.githubusercontent, закріпленими за комітом.

- `hero` — номер із дерев'яним ліжком (головне фото, og:image) → найкращий номер клієнта
- `room-double`, `room-twin`, `room-single`, `room-family`, `room-suite` → реальні номери
- `keys`, `bell`, `reception` → рецепція, хол, фасад
- `breakfast` → сніданок / ресторан готелю
- `city`, `mountains` → місто й Карпати (можна лишити стокові)

Також перевірте з клієнтом список зручностей (душ/ванна, кава в номері, паркування, тварини) і типи номерів.

## Як адаптувати під клієнта

1. Замініть токени `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ІНСТАГРАМ]`, `[ФОП]`, `[РІК]`, `[ГОДИНИ]` (пошук і заміна по всіх файлах) і зніміть обгортку `.ph`.
2. Поставте справжні посилання замість заглушок `tel:`, `mailto:`, Instagram, Facebook; видаліть елементи `data-ch` каналів, яких у клієнта немає; оновіть `CONTACT` і `HOURS` у `js/main.js`.
3. Оновіть карту й маршрут (`maps?q=` та `destination=`) точною адресою.
4. Перепишіть номери (назви, гості, опис) і впишіть ціни `[ЦІНА]` — у картках і прайсі (та `data-price` для автопідрахунку).
5. Замініть фото на фото готелю, відгуки `.ph-card` — на реальні, підписи `[ІМ'Я]` — на справжні; перевірте сайт на телефоні.
