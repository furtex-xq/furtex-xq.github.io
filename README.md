# Шаблон «Клініка» — сайт медичного центру

Універсальний односторінковий сайт для медичного центру / приватної клініки. Чистий HTML + CSS + JS без бібліотек і збірки: `index.html`, `css/style.css`, `js/main.js`. Демо: `https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/klinika/index.html`

Блоки: шапка з телефоном і записом → головний екран (H1, кнопки, «талон на сьогодні» зі статусом відчинено/зачинено) → швидкий підбір за симптомом → **табло спеціалістів** (симптом → лікар) → прайс із вкладками → про центр і переваги → лікарі → як проходить візит → відгуки → FAQ → контакти, графік, форма запису, карта → футер із реквізитами. На телефоні знизу закріплена панель «Подзвонити / Записатися / Маршрут».

## Дизайн

- **Шрифти:** Source Serif 4 (заголовки, ціни, табло) + Noto Sans (текст). Локально у `fonts/` (cyrillic + latin, variable woff2).
- **Палітра:** білий `#FFFFFF`, холодний туман `#F1F4F6`, блакитно-сіра плашка `#E4ECF1`, чорнило `#15232C`, сланцевий текст `#566A78`, клінічний синій `#1F4A63` (кнопки, табло), шавлія `#3B6A54` / `#7FA48E` (відчинено, підсвітка лікаря).
- **Фішка:** «табло спеціалістів» у стилі навігаційних вказівників лікарні — пацієнт обирає симптоми, і відповідні лікарі підсвічуються шавлієвим та піднімаються нагору списку з поясненням, з кого почати; кнопка біля лікаря одразу підставляє його у форму запису. Плюс «талон на сьогодні» на головному екрані з живим статусом за київським часом.

## Плейсхолдери

Видимі дані клієнта позначені `<span class="ph">[ТОКЕН]</span>` (жовте пунктирне підкреслення). Після заміни можна прибрати клас `ph` або залишити — без токена він не помітний, але краще прибрати.

| Токен / sentinel | Де зустрічається |
|---|---|
| `[НАЗВА]` | `<title>`, OG, JSON-LD, логотип у шапці й футері, H1, підпис карти, копірайт |
| `[МІСТО]` | `<title>`, description, OG, JSON-LD, H1, адреса в контактах і футері, текст футера |
| `[АДРЕСА]` | JSON-LD, контакти, футер |
| `[ТЕЛЕФОН]` | description, JSON-LD, шапка, контакти, екран успіху форми, футер |
| `[EMAIL]` | JSON-LD, кнопка email у контактах, футер |
| `[ГОДИНИ]` | JSON-LD (`openingHours`, формат `Mo-Fr 08:00-20:00`), підсумок у графіку, футер |
| `[ІНСТАГРАМ]` | кнопка Instagram у контактах |
| `[ФОП]` | футер (назва ФОП / ТОВ, ЄДРПОУ) |
| `[РІК]` | блок «Про центр» |
| `[ЦІНА]` | `від [ЦІНА] грн`: головний екран, табло (16 рядків), прайс (5 вкладок), JSON-LD `priceRange` |
| `[ІМ'Я]` | 4 картки лікарів, 3 відгуки |
| `.ph-card` + «Приклад відгуку — замініть на реальний» | 3 картки відгуків — замінити текст на реальні відгуки й прибрати клас і мітку |
| `tel:+380000000000` | шапка, кнопки героя, талон, контакти, успіх форми, футер, мобільна панель |
| `viber://chat?number=%2B380000000000` | контакти + `CONTACT.viber` у `js/main.js` |
| `https://t.me/username` | контакти + `CONTACT.telegram` у `js/main.js` |
| `https://wa.me/380000000000` | контакти |
| `https://www.instagram.com/username/` | контакти, JSON-LD `sameAs` |
| `https://www.facebook.com/username` | контакти, JSON-LD `sameAs` |
| `mailto:hello@example.com` | контакти, футер + `CONTACT.email` у `js/main.js` |
| Карта `https://www.google.com/maps?q=Івано-Франківськ&output=embed` (URL-кодовано) | iframe у контактах; посилання «Маршрут» у мобільній панелі (`maps/dir/?api=1&destination=...`) — підставити адресу |

**Графік роботи** для статусу «Зараз відчинено / зачинено» береться з атрибутів `data-hours="08:00-20:00"` у списку `.hours-list` (порожнє значення = вихідний). Змініть і атрибут, і видимий текст рядка.

**Табло:** симптоми — кнопки `.sym` з `data-match="ter lor lab"` (коди лікарів) і `data-note` (підказка). Лікарі — рядки `.spec` з `data-spec="ter"`. Якщо в клініці немає якогось спеціаліста — видаліть рядок і його код із `data-match`. Список у формі запису будується з табло автоматично.

## Фото (Unsplash, замінити на власні фото клієнта)

Лежать у `img/photos/`, на сторінці підключені абсолютними URL raw.githubusercontent, закріпленими на коміті.

| Слот | Що на фото | Чим замінити |
|---|---|---|
| `hero` | лікар заповнює картку, руки пацієнта | **обов'язково** — реальний кабінет / лікар клієнта |
| `corridor` | світлий коридор з лавками | хол або рецепція клініки |
| `usg` | апарат УЗД | власне обладнання |
| `visit` | педіатр із мамою та дитиною | прийом у клініці (за згодою) |
| `lab` | пробірки в штативі | лабораторія / процедурний кабінет |
| `stetho` | стетоскоп на блакитному тлі | можна залишити |

## Як адаптувати під клієнта (5 кроків)

1. Знайти й замінити всі токени з таблиці (`[НАЗВА]`, `[ТЕЛЕФОН]`, `[ЦІНА]`…) і sentinel-посилання (телефон, месенджери, соцмережі, email), включно з `CONTACT` у `js/main.js`.
2. Оновити графік: `data-hours` + текст у `.hours-list`, `[ГОДИНИ]` у JSON-LD у форматі schema.org.
3. Привести табло й прайс до реального переліку лікарів і послуг клініки: видалити зайві рядки, оновити `data-match` у симптомах, вписати ціни.
4. Замінити фото на власні (у `img/photos/` з тими самими іменами або нові URL) і оновити `og:image`; вставити реальних лікарів і відгуки, прибрати `.ph-card` та мітки.
5. Вставити карту з точною адресою (Google Maps → Поділитися → Вбудувати), прописати ФОП/ЄДРПОУ і ліцензію МОЗ, потім прибрати класи `ph` і перевірити сайт на телефоні.
