# Black Valvet Dance Space — демо-сайт

Шаблон: «Танцювальна студія» (`tantsi`, гілка `template/tantsi`).

## Заповнено з OpenStreetMap
- назва (Black Valvet Dance Space)
- місто (Івано-Франківськ)
- адреса (вулиця Героїв Чернігова)
- телефон (+380 50 605 77 68)
- Facebook (https://www.facebook.com/blackvelvetdancespace/)
- мапа й маршрут (вулиця Героїв Чернігова, Івано-Франківськ)

Viber, Telegram і WhatsApp невідомі, тому ці кнопки прибрано. Форма запису надсилає заявку через: SMS, Facebook Messenger.

## Що ще треба заповнити (позначено жовтим пунктиром)
- `[ІМ'Я]`
- `[ГОДИНИ]`
- `[РІК]`
- `[ФОП]`
- `[ЦІНА]`
- 3 приклади відгуків (`ph-card`) — замінити на реальні
- розклад занять (масив `SCHEDULE` у `js/main.js`), напрями й прайс — звірити з реальними
- фото — замінити на фото студії (зараз ілюстративні з Unsplash)
