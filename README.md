# Крок у майбутнє — демо-сайт

Шаблон: «Фітнес-клуб / спортзал» (`template/fitnes`).

Заповнено з OpenStreetMap: назва, місто, адреса, телефон, Instagram, Facebook.
Джерело: https://www.openstreetmap.org/node/11963134571

Ще треба заповнити (позначені бурштиновим підкресленням): `[ІМ'Я]`, `[ГОДИНИ]`, `[РІК]`, `[ФОП]`, `[ЦІНА]`.
Розклад групових (`CLASSES` у `js/main.js`) — приклад, узгодьте з клубом.
Відгуки — приклади (`ph-card`), замініть на реальні. Фото — зі стоку Unsplash, бажано замінити на фото залу й тренерів.
