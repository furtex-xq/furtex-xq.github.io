# Pro Dim — демо-сайт

Персоналізована копія шаблону `budivnytstvo` (ремонт квартир і будівництво).

**Заповнено з OpenStreetMap:** назва, місто, адреса, телефон, Instagram, Facebook.

Джерело: https://www.openstreetmap.org/node/11705102976

**Ще треба заповнити** (на сторінці підкреслено бурштиновим пунктиром):

- `[ІМ'Я]` — імена авторів відгуків (і самі відгуки — зараз приклади)
- `[ГОДИНИ]` — графік роботи
- `[РІК]` — рік заснування
- `[ФОП]` — ФОП / ЄДРПОУ у футері
- `[ЦІНА]` — ціни «від … грн» у прайсі і ставки калькулятора (`js/config.js` → `rates`)
- фото до/після і галерея — замінити на реальні об'єкти бригади
