# Otto Hans — демо-сайт

Шаблон: «Школа іноземних мов» (`movna-shkola`), варіант лише для німецької мови.

Заповнено з OpenStreetMap: назва, адреса, Facebook.
Карта і кнопка «Маршрут» ведуть на: вулиця Академіка Гнатюка, Івано-Франківськ.

Ще потрібно заповнити (підсвічені на сторінці):
- `[ІМ'Я]`
- `[ГОДИНИ]`
- `[РІК]`
- `[ФОП]`
- `[ЦІНА]`
- відгуки з міткою «Приклад відгуку» — замінити на реальні
- розклад груп і тексти про програми — звірити з клієнтом
- фото — зараз стокові (Unsplash), бажано замінити на фото школи
- години роботи невідомі: статус «зараз відчинено» вимкнено
