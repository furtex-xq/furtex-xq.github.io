# Kulyk Medicine — демо нового сайту (бета, v4)

Естетична стоматологія Kulyk Medicine, Івано-Франківськ, вул. Бельведерська, 23. Статичний односторінковий сайт (HTML/CSS/JS), мова українська.

v4 (13.11.2026): дані оновлено з їхнього чинного сайту kulykmedicine.com: позиціювання (естетична стоматологія з 2013), 7 напрямів послуг із реальними цінами з /prices, двоє лікарів (Роман Кулик, Олег Костюк), email, підхід до лікування, FAQ. Прибрано непідтверджене: дитяча стоматологія, «індивідуальні брекети США», гарантія, «85 %», Viber.

Фото:
- `img/site/` — власні фото клініки з kulykmedicine.com (рецепція, зона очікування, кабінет з мікроскопом), завантажені workflow `.github/workflows/site-photos.yml` за списком `tools/site_photos.json`.
- `img/photos/` — стокові фото Unsplash для карток послуг і блоку мікроскопа (замінити на фото робіт клініки).
- На сторінці всі фото підключені абсолютними URL raw.githubusercontent.com з SHA коміту (відносні шляхи ламались на raw.githack в iPhone Safari), CSP img-src містить raw.githubusercontent.com.

Стиль «точний інструмент»: білий з міліметровою сіткою, чорний, сигнальний червоний, IBM Plex Sans + Mono. Фішка: «лінза мікроскопа» ×1 → ×4 → ×25.

Заглушки: ФОП/ЄДРПОУ/ліцензія МОЗ, фото лікарів, фото робіт до/після.
