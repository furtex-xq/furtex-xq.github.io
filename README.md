# Вогник — демо-сайт

Шаблон: «Магазин іграшок і подарунків» (`ihrashky-podarunky`).

Заповнено з OpenStreetMap: назва, місто, адреса, Instagram, графік роботи, точка на карті.

Що лишилось заповнити (позначено бурштиновим підкресленням на сторінці):

- `[ІМ'Я]` — імена авторів відгуків (самі відгуки — приклади з міткою, замінити на реальні)
- `[РІК]` — рік відкриття магазину («Про магазин»)
- `[ФОП]` — ФОП / ЄДРПОУ у футері
- `[ЦІНА]` — ціни «від … грн» у каталозі й у прайсі пакування
- Фото — стокові (Unsplash); краще замінити на фото вітрини, полиць і пакування магазину.
- Асортимент у каталозі й ідеї в підборі подарунка — типові, звірити з реальними.
