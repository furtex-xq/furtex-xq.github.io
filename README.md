# Шаблон «fastfud» — піца, бургерна, фастфуд

Універсальний односторінковий демо-сайт для піцерії, бургерної чи закладу фастфуду з доставкою. Чистий HTML/CSS/JS без бібліотек і збірки, мобільна версія в пріоритеті.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/fastfud/index.html

## Дизайн
- **Шрифти:** Pattaya (рукописні акценти в заголовках) + Overpass (variable, текст і жирні «наліпки» капсом). Локально в `fonts/`, cyrillic + latin + latin-ext.
- **Палітра:** крафт `#E4C99A`, світлий крафт `#F8EDD6`, гірчиця `#F4B41A`, кетчуп `#D62A1E`, чорний `#17110D`, огірковий `#6BAA3A` (лише в конструкторі).
- **Стиль:** вуличний фуд — товсті чорні обводки, «жорсткі» тіні, наліпки під кутом, бігучий рядок, чек із зубчастим краєм у блоці доставки.
- **Фішка:** конструктор «Збери свій» — бургер збирається шар за шаром (булка, котлета, сир, овочі падають згори), піца — інгредієнти «висипаються» на коло; склад одним дотиком переноситься у форму замовлення.
- Блоки: шапка, герой, бігучий рядок, меню з вкладками (піца / бургери / закуски / напої), конструктор, «як замовити» + умови доставки, про нас, відгуки, FAQ, контакти + години з живим статусом за київським часом, форма замовлення, карта, футер, мобільна панель дій.

## Плейсхолдери
Видимі дані — `<span class="ph">[ТОКЕН]</span>` (бурштинове підкреслення). Заміна однією операцією «знайти й замінити».

| Токен / сентинел | Де |
|---|---|
| `[НАЗВА]` | title, meta, OG, JSON-LD, логотип, alt героя, чек доставки, про нас, title карти, футер |
| `[МІСТО]` | title, meta, OG, H1 («у [МІСТО]» — місцевий відмінок), контакти, футер, JSON-LD |
| `[АДРЕСА]` | meta, герой, контакти, футер, JSON-LD |
| `[ТЕЛЕФОН]` | шапка (десктоп), контакти, JSON-LD |
| `[EMAIL]` | контакти, JSON-LD |
| `[ІНСТАГРАМ]` | контакти (handle) |
| `[ГОДИНИ]` | meta, підсумок над таблицею годин, JSON-LD |
| `[ЦІНА]` | наліпка в герої, усі позиції меню, конструктор, умови доставки, JSON-LD priceRange |
| `[РІК]` | про нас |
| `[ІМ'Я]` | автори відгуків |
| `[ФОП]` | футер |
| `tel:+380000000000` | шапка, герой, контакти, кнопки, мобільна панель, форма (`data-tel`) |
| `viber://chat?number=%2B380000000000` | кнопка Viber, форма (`data-viber`) |
| `https://t.me/username` | кнопка Telegram, форма (`data-tg`) |
| `https://wa.me/380000000000` | кнопка WhatsApp |
| `sms:+380000000000` | форма (`data-sms`) |
| `https://www.instagram.com/username/` | контакти, JSON-LD sameAs |
| `https://www.facebook.com/username` | кнопка Facebook, JSON-LD sameAs |
| `mailto:hello@example.com` | контакти, форма (`data-mail`) |
| Google Maps `?q=Івано-Франківськ` | iframe карти, «Прокласти маршрут», мобільна панель |

Відгуки — картки `.ph-card` з позначкою «Приклад відгуку — замініть на реальний».

Години роботи: у `index.html` список `ul[data-hours]`, атрибути `data-open` / `data-close` (HH:MM) для кожного дня; для вихідного приберіть обидва атрибути й напишіть «вихідний». Статус «відчинено / зачинено» рахується автоматично.

Акцент піца / бургери: `<body data-focus="mix">` → `pizza` відкриває меню й конструктор на піці, `burger` — на бургерах. Для піцерії також варто поміняти фото героя на `heropizza.jpg` і перший рядок H1.

Канали форми: радіокнопки `name="via"` (tg, viber, sms, mail, а також ig — для Instagram Direct `https://ig.me/m/<handle>` через `data-ig`). Якщо не лишити жодного каналу — форма покаже «Залишилось подзвонити» з кнопкою дзвінка.

## Фото (Unsplash, замінити на фото закладу)
Фото підключені абсолютними URL, закріпленими за комітом `de5e48a`:
`hero` (бургер, герой), `heropizza` (запасний герой для піцерії), `pizza2`, `burger2`, `wings`, `drink` (вкладки меню), `kitchen` (доставка), `oven`, `fries` (про нас), `table` (FAQ, лише десктоп). Запасні: `pizza1`, `pizza3`.
Найважливіше попросити в клієнта: фото фірмового бургера/піци, інтер’єру або кухні, команди, упаковки з логотипом.

## Як адаптувати під клієнта (5 кроків)
1. Замініть токени `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ІНСТАГРАМ]`, `[ФОП]`, `[РІК]` і зніміть клас `ph`.
2. Поставте реальні посилання замість сентинелів (телефон, месенджери, соцмережі, карта) і приберіть кнопки каналів, яких у закладу немає (у т.ч. варіанти у формі).
3. Оновіть меню під реальний асортимент і ціни `[ЦІНА]`; виставте `data-focus` (pizza / burger / mix).
4. Пропишіть години в `ul[data-hours]` і `[ГОДИНИ]`; замініть приклади відгуків реальними.
5. Замініть стокові фото на фото закладу, перевірте сайт на телефоні та в Google Rich Results (JSON-LD `FastFoodRestaurant`).

Автоматично під ліда: `python3 tools/personalize.py lead.json out/`.
