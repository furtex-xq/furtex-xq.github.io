# 12V вольт — демо-сайт

Шаблон: «Магазин автозапчастин» (`avtozapchastyny`).

Заповнено з OpenStreetMap: назва, місто, адреса, телефон, графік роботи, точка на карті.

Що лишилось заповнити (позначено бурштиновим підкресленням на сторінці):

- `[ІМ'Я]` — імена авторів відгуків (і самі відгуки — зараз це приклади з міткою)
- `[РІК]` — рік заснування магазину
- `[ФОП]` — ФОП / ЄДРПОУ у футері
- `[ЦІНА]` — ціни «від … грн» у каталозі, на бирці першого екрана й у таблиці цін
- Фото — зараз стокові (Unsplash); краще замінити на фото магазину.
