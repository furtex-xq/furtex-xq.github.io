# Шаблон «Барбершоп» (#20, `barbershop`)

Універсальний односторінковий сайт для барбершопу. Статичний HTML/CSS/JS без збирання та без зовнішніх CDN: відкривається з будь-якого хостингу. Усі дані клієнта позначені токенами `[ТОКЕН]` — одна заміна «знайти й замінити» адаптує сайт.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/barbershop/index.html

## Дизайн

- **Напрям:** вінтажний джентльменський клуб — глибокий пляшковий зелений, кремовий, оксблад (бордо), латунь; смуги барберського стовпа як наскрізний мотив (смуга під героєм, позначки над заголовками, лінія таймлайну, футер).
- **Шрифти:** Old Standard TT (заголовки, курсив для акцентів) + Source Sans 3 (текст). Файли лежать у `fonts/` (лише cyrillic + latin).
  Примітка: за брифом мав бути Merriweather Sans, але в ньому немає базової кирилиці (лише cyrillic-ext, українських літер немає), тому замінено на Source Sans 3.
- **Палітра:**

| Назва | HEX |
|---|---|
| Зелений 950 (найтемніший фон) | `#0F1D16` |
| Зелений 900 (герой, прайс, запис) | `#14261D` |
| Кремовий (фон) | `#F1E8D6` |
| Кремовий 2 (секція «Візит») | `#E7DAC0` |
| Оксблад | `#6B1E23` |
| Латунь / світла латунь | `#B38B4D` / `#D2AE6E` |
| Чорнило (текст) | `#1B1915` |

- **Фішка:** барберський стовп — індикатор прокрутки. На ПК справа закріплений стовп із латунними ковпачками: смуги заповнюють скляну трубку пропорційно прокрутці й «обертаються» під час скролу. На телефоні те саме — смугаста лінія прогресу під шапкою.
- **Друга фішка:** «Альбом стрижок» — список назв (Фейд, Кроп, Андеркат, Помпадур, Класика, Борода) перемикає фото, опис, «кому пасує / укладка / як часто оновлювати». Кнопка «Хочу таку стрижку» переносить вибір у форму запису.
- Інше: прайс у вигляді вивіски з крапковими лініями, таймлайн візиту по хвилинах, статус «зараз відчинено/зачинено» за київським часом, нижня панель дій на телефоні (Дзвінок / Записатися / Маршрут). Анімації вимикаються при `prefers-reduced-motion`.

## Токени та посилання-заглушки

| Токен / заглушка | Що це | Де трапляється |
|---|---|---|
| `[НАЗВА]` | назва барбершопу | `<title>`, OG, JSON-LD, логотип, «Про нас», title карти, футер |
| `[МІСТО]` | місто | `<title>`, description, JSON-LD, герой (eyebrow), контакти, футер |
| `[АДРЕСА]` | вулиця й номер | description, JSON-LD, контакти, футер |
| `[ТЕЛЕФОН]` | телефон для показу | description, JSON-LD, шапка (ПК), контакти |
| `[EMAIL]` | пошта для показу | JSON-LD, кнопка в контактах |
| `[ГОДИНИ]` | короткий підсумок годин, напр. «Пн–Пт 10–20, Сб 10–18, Нд 11–16» | JSON-LD (`openingHours`), блок «Години роботи» |
| `[ІНСТАГРАМ]` | нік в Instagram | кнопка в контактах |
| `[ФОП]` | ФОП / ЄДРПОУ | футер |
| `[РІК]` | рік відкриття | логотип, печатка в герої, «Про нас», JSON-LD, футер |
| `[ЦІНА]` | ціна (`від [ЦІНА] грн`) | прайс (13 позицій), альбом стрижок, JSON-LD `priceRange` |
| `[ІМ'Я]` | імена авторів відгуків | 3 картки відгуків |
| `tel:+380000000000` | дзвінок | шапка, герой, контакти, нижня панель |
| `viber://chat?number=%2B380000000000` | Viber | контакти, `js/main.js` (форма) |
| `https://t.me/username` | Telegram | контакти, `js/main.js` (форма) |
| `https://wa.me/380000000000` | WhatsApp | контакти |
| `https://www.instagram.com/username/` | Instagram | контакти, JSON-LD `sameAs` |
| `https://www.facebook.com/username` | Facebook | контакти, JSON-LD `sameAs` |
| `mailto:hello@example.com` | пошта | контакти, `js/main.js` (форма) |
| `q=Івано-Франківськ` (URL-кодовано) | карта і маршрут | iframe Google Maps, кнопка «Маршрут» |

Окремо (не токени, а дані в розмітці):
- **Графік для статусу «відчинено/зачинено»** — таблиця `#hours` в `index.html`: атрибути `data-open` / `data-close` (24-год, порожньо = вихідний) та видимий текст у клітинках.
- **Відгуки** — 3 приклади з класом `ph-card` і позначкою «Приклад відгуку — замініть на реальний». Після заміни приберіть клас `ph-card` і `<span class="ph-label">`.
- **Стилі `.ph`** (жовте пунктирне підкреслення) — після адаптації їх можна залишити: без тексту-токена вони не помітні, але краще прибрати обгортки `<span class="ph">`.

## Фото (Unsplash, ліцензія Unsplash)

Фото лежать у `img/photos/` і підключені абсолютними посиланнями на raw.githubusercontent.com, закріпленими на коміті (так вони гарантовано вантажаться в Safari на iPhone). Список і джерела — `tools/chosen.json`, `img/photos/credits.json`.

| Файл | Де | Замінити на фото клієнта? |
|---|---|---|
| `hero.jpg` | герой (арка) + OG-зображення | **так, обов'язково** — майстер за роботою в їхньому залі |
| `interior.jpg` | «Про нас» | **так** — їхній зал/крісла |
| `tools.jpg` | прайс | бажано — їхні інструменти/косметика |
| `shave.jpg` | «Як проходить візит» | бажано |
| `scissors.jpg` | FAQ | бажано |
| `look-fade.jpg`, `look-crop.jpg`, `look-undercut.jpg`, `look-pompadour.jpg`, `look-classic.jpg`, `look-beard.jpg` | альбом стрижок | **так** — реальні роботи майстрів (найсильніший аргумент для клієнтів) |

Щоб замінити фото: покладіть нові файли з тими ж іменами в `img/photos/` і змініть SHA в посиланнях (`index.html`, `js/main.js` — константа `PHOTO`) або перейдіть на відносні шляхи `img/photos/...` на власному хостингу.

## Як адаптувати під клієнта (5 кроків)

1. **Дані:** знайти й замінити всі токени `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ГОДИНИ]`, `[ІНСТАГРАМ]`, `[ФОП]`, `[РІК]` в `index.html`; у `<head>` і JSON-LD — теж.
2. **Посилання:** замінити заглушки `380000000000`, `username`, `hello@example.com` у `index.html` і `js/main.js`; у карті й «Маршруті» підставити URL-кодовану адресу клієнта замість міста.
3. **Прайс і графік:** вписати ціни замість `[ЦІНА]`, прибрати/додати позиції; оновити таблицю годин (`data-open`/`data-close` + текст).
4. **Фото й відгуки:** замінити фото з таблиці вище на реальні; вставити 3 справжні відгуки з іменами, прибрати `ph-card`/`ph-label`.
5. **Перевірка:** відкрити сайт на телефоні — дзвінок, Viber, Telegram, форма (усі три канали), меню, карта; перевірити прев'ю посилання в Telegram/Facebook (OG-зображення).
