# Шаблон «Школа іноземних мов» (`movna-shkola`)

Універсальний односторінковий сайт для мовної школи / курсів іноземних мов. Статичний HTML + CSS + JS без бібліотек і без збірки, mobile-first. Демо: `https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/movna-shkola/index.html`

Блоки: шапка з меню → головний екран (H1 + «Записатися на пробне заняття» + «Тест рівня») → мови (картки-словникові статті без прапорів) → **тест рівня** → для кого (діти / підлітки / дорослі / онлайн) → формати й ціни → як почати (4 кроки) → розклад груп з фільтром → про нас → відгуки → FAQ → контакти, години роботи «зараз відчинено/зачинено» (за київським часом), кнопки месенджерів, форма запису → карта → футер з ФОП. На телефоні — липка панель «Дзвінок / Записатися / Маршрут».

## Дизайн
- **Шрифти:** Kelly Slab (заголовки, «рукописні» нотатки на полях) + Ubuntu 400/500/700 (текст). Локально в `fonts/`, лише cyrillic + latin, `font-display: swap`.
- **Палітра — «шкільний зошит»:** папір `#fbfbf8`, лінійки `#dbe4f1`, чорнило `#1f3a8a`, текст `#16244a`, червоне поле `#e0605a`, маркер-виділювач `#f6e04b`.
- **Композиція:** вся сторінка — аркуш у лінійку з червоним полем зліва; на полях (ПК) — нотатки-закладки розділів; фото «приклеєні» скотчем; ключові слова в заголовках підкреслюються маркером під час прокрутки.
- **Фішка:** міні-тест рівня англійської (5 питань, варіант «Не знаю»), результат — оцінка, обведена червоною ручкою (A1…C1), і рекомендована група з розкладу; кнопка «Записатися в цю групу» підставляє рівень і групу у форму.

## Плейсхолдери (знайти й замінити)
| Токен / посилання | Що це | Де трапляється |
|---|---|---|
| `[НАЗВА]` | назва школи | `<title>`, OG, JSON-LD, логотип, «Про нас», карта (title), футер |
| `[МІСТО]` | місто | `<title>`, description, OG, JSON-LD, hero, контакти, футер |
| `[АДРЕСА]` | вулиця, будинок | JSON-LD, контакти, футер |
| `[ТЕЛЕФОН]` | телефон для показу | JSON-LD, контакти, футер |
| `[EMAIL]` | email для показу | JSON-LD, контакти, футер |
| `[ГОДИНИ]` | короткий графік текстом | JSON-LD `openingHours`, блок годин, футер |
| `[ІНСТАГРАМ]` | нікнейм Instagram | контакти |
| `[ФОП]` | ФОП / ЄДРПОУ | футер |
| `[РІК]` | рік заснування | JSON-LD, «Про нас», футер |
| `[ЦІНА]` | ціни (`від [ЦІНА] грн`) | JSON-LD `priceRange`, картки мов (6), таблиця форматів (6) |
| `[ІМ'Я]` | імена людей | цитата засновниці, підписи відгуків (3) |
| `tel:+380000000000` | телефон-посилання | контакти, футер, мобільна панель |
| `viber://chat?number=%2B380000000000` | Viber | контакти, варіант форми (`data-url`) |
| `https://t.me/username` | Telegram | контакти, варіант форми (`data-url`) |
| `https://wa.me/380000000000` | WhatsApp | контакти |
| `https://www.instagram.com/username/` | Instagram | контакти, JSON-LD `sameAs` |
| `https://www.facebook.com/username` | Facebook | контакти, JSON-LD `sameAs` |
| `mailto:hello@example.com` | email-посилання | контакти, футер, варіант форми (`data-url`) |
| `maps?q=Івано-Франківськ` (URL-кодовано) | карта і «Маршрут» | iframe карти, мобільна панель — замінити на точну адресу |

Також перевірити: години в таблиці `#hoursTable` (атрибути `data-days`, `data-open`, `data-close` — від них рахується «зараз відчинено»), розклад груп (`#rozklad`, атрибут `data-l` = мова для фільтра), список мов і рівнів, групи в результатах тесту (`LEVEL_SETS` у `js/main.js`). Відгуки (`.ph-card`) — приклади, замінити на реальні й прибрати мітку «Приклад відгуку».

## Фото (Unsplash, замінити на фото клієнта)
Файли в `img/photos/`, на сторінці підключені абсолютним посиланням raw.githubusercontent.com, закріпленим на коміті (SHA) — після заміни фото оновити SHA в `index.html`.
- `hero.jpg` — заняття / студенти в класі школи (головний екран, OG-картинка)
- `kids.jpg`, `teens.jpg`, `adults.jpg`, `online.jpg` — реальні групи дітей, підлітків, дорослих, онлайн-урок
- `notebook.jpg` — інтер'єр або атмосфера заняття («Про нас»)
- `team.jpg` — фото засновниці / викладача (кругле, біля цитати)
- `tiles.jpg` — декоративне біля прайсу (можна залишити)
- `dictionary.jpg` — запасне, на сторінці не використовується

## Автоматична персоналізація
`python3 tools/personalize.py <lead.json> <outdir>` — створює копію сайту для конкретного ліда: підставляє назву, місто (з правильним відмінком після «у»), адресу, телефон, email, Instagram/Facebook, карту й маршрут, години; прибирає невідомі канали (Viber, Telegram, WhatsApp тощо) і відповідні варіанти у формі; для шкіл лише з німецькою вмикає німецький варіант (мови, тест, розклад). Розмітка блоків для скрипта — коментарі `<!--dict-->`, `<!--week-->`, `<!--questions-->`, `<!--status-->`, `<!--hourstable-->`, `<!--channels-->`, `<!--notes-->` і атрибути `data-ch` — не видаляйте їх.

## Як адаптувати для клієнта (5 кроків)
1. Знайти й замінити всі токени з таблиці (`[НАЗВА]`, `[МІСТО]`, `[ТЕЛЕФОН]`…) і посилання-заглушки; у формі — атрибути `data-url` варіантів відправки.
2. Залишити лише мови, які школа реально викладає (картки в `#movy`, опції у формі, фільтр розкладу), вписати ціни.
3. Оновити розклад груп, години роботи (`#hoursTable`) і рекомендовані групи в `LEVEL_SETS`.
4. Замінити фото на фото школи (див. вище), оновити адресу на карті й у кнопці «Маршрут».
5. Вставити 3 реальні відгуки, прибрати клас `ph-card` і мітки, перевірити сайт на телефоні; за бажання прибрати жовте підсвічування `.ph` (коли токенів не лишилось — правило можна видалити з `css/style.css`).
