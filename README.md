# Оптика 1st — демо нового сайту (бета)

Статичний односторінковий сайт (HTML/CSS/JS) для мережі оптик «Оптика 1st». Мова: українська.

- `index.html`, `css/style.css`, `js/main.js`
- `js/vendor/` — GSAP 3.15 + ScrollTrigger, Lenis 1.3 (локально, без CDN)
- `fonts/` — Onest (variable) і Cormorant Garamond Italic, кирилиця + латиниця, self-hosted
- `img/` — логотип (векторна копія, замінити оригіналом), OG-зображення

Фішка: таблиця перевірки зору, рядки якої наводяться на різкість під час скролу (з лічильником діоптрій). Також: «автофокус» першого екрана, слайдер до/після з типами покриттів лінз, горизонтальна полиця товарів, бігучий рядок, що прискорюється від скролу. Повага до `prefers-reduced-motion`.

Заглушки (позначені на сайті): номер будинку й місто, ФОП/ЄДРПОУ, демо-товари й ціни, демо-відгуки, фото з Unsplash, Viber/WhatsApp на номері (уточнити). Форма у демо відкриває WhatsApp з готовим текстом; після запуску — Telegram-бот/email.
