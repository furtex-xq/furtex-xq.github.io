# Кульки від Юльки — демо-сайт студії кульок і декору

Шаблон: `kulky-dekor` (повітряні кульки / декор свят): вибір події з готовими сетами, прайс, заявка.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/beta/kulky-vid-iulky/index.html

## Заповнено з OpenStreetMap

- назва
- місто
- адреса
- телефон
- графік роботи (таблиця й живий статус «відчинено/зачинено» за київським часом)
- карта й «Маршрут» за запитом «вулиця Шевченка, Івано-Франківськ»

## Ще треба заповнити (позначені жовтим пунктиром)

- `[ІМ'Я]`
- `[РІК]`
- `[ФОП]`
- `[ЦІНА]`
- приклади відгуків (картки «Приклад відгуку») — замінити на реальні
- фото — зараз стокові з Unsplash; бажано реальні роботи студії

Viber / Telegram / WhatsApp у джерелі не вказані — кнопки прибрано. Форма надсилає заявку через: SMS.
