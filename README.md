# Шаблон «Автошкола» (`template/avtoshkola`)

Універсальний односторінковий сайт для автошколи: категорії A / B / C, прайс, шлях до посвідчення, інструктори, відгуки, FAQ, контакти з графіком «зараз відчинено/зачинено» за київським часом, форма запису (Telegram / Viber / email) і мапа. Чистий HTML/CSS/JS без збірки та без CDN.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/avtoshkola/index.html

## Дизайн

- **Шрифти:** Rubik Mono One (заголовки, літери категорій, ціни) + Cuprum 400/600/700 (текст). Лише кирилиця + латиниця, локально в `fonts/`.
- **Палітра («дорожні знаки»):** асфальт `#1d2024` / `#2a2e33`, біла розмітка `#f3f2ee`, синій інформаційний знак `#0a5bb0`, жовтий попереджувальний `#ffc20e`, червоний `#d3262d` (лише в знаку «У»), світлий фон `#e9e8e3`.
- **Фішка:** у блоці «Шлях до посвідчення» вертикальна дорога з переривчастою розміткою; навчальне авто зі знаком «У» на даху їде вниз разом зі скролом, пройдений шлях стає жовтою суцільною лінією, а зупинки 01–08 «вмикаються», коли авто їх проїжджає. На ПК дорога йде по центру, зупинки чергуються ліворуч і праворуч, на телефоні дорога йде лівим краєм.
- Також: логотип і бейдж у вигляді знака «У» (навчальний транспорт), смуга «зебри» під героєм, факти в героєві оформлені як синій дорожній вказівник, а великі літери A/B/C на картках категорій нагадують таблички.
- Анімації вимикаються при `prefers-reduced-motion`.

## Плейсхолдери

Видимі дані клієнта позначені як `<span class="ph">[ТОКЕН]</span>` (жовте пунктирне підкреслення). Заміна одним find-and-replace.

| Токен | Що це | Де трапляється |
|---|---|---|
| `[НАЗВА]` | назва автошколи | `<title>`, OG, JSON-LD, шапка, герой, «Про нас», підпис мапи, футер |
| `[МІСТО]` | місто | `<title>`, description, OG, JSON-LD, герой, «Про нас», адреса, футер |
| `[АДРЕСА]` | вулиця, будинок | JSON-LD, контакти, футер |
| `[ТЕЛЕФОН]` | телефон для показу | description, JSON-LD, шапка, контакти, футер |
| `[EMAIL]` | пошта | JSON-LD, контакти, футер |
| `[ГОДИНИ]` | короткий підсумок графіка | JSON-LD (`openingHours`), блок графіка |
| `[ІНСТАГРАМ]` | нікнейм Instagram | кнопка Instagram у контактах |
| `[ФОП]` | ФОП / ЄДРПОУ | футер |
| `[РІК]` | рік заснування | JSON-LD, табличка в героєві, «Про нас» |
| `[ЦІНА]` | будь-яка ціна (`від [ЦІНА] грн`) | JSON-LD `priceRange`, картки A/B/C, увесь прайс (8 рядків) |
| `[ІМ'Я]` | імена інструкторів і авторів відгуків | «Інструктори» (3), відгуки (3) |

Відгуки — приклади: картки мають клас `ph-card` і мітку «Приклад відгуку — замініть на реальний». Після заміни приберіть клас і мітку.

**Посилання-сентинели** (невидимі, замінюються так само):

| Рядок | Де |
|---|---|
| `tel:+380000000000` | шапка, герой, контакти, футер, нижня панель |
| `viber://chat?number=%2B380000000000` | контакти; номер для форми — константа `PHONE` у `js/main.js` |
| `https://wa.me/380000000000` | контакти |
| `https://t.me/username` | контакти; константа `TG` у `js/main.js` |
| `https://www.instagram.com/username/` | контакти, JSON-LD `sameAs` |
| `https://www.facebook.com/username` | контакти, JSON-LD `sameAs` |
| `mailto:hello@example.com` | контакти, футер; константа `MAIL` у `js/main.js` |
| `https://www.google.com/maps?q=%D0%86...&output=embed` | iframe мапи, кнопка «Прокласти маршрут», «Маршрут» у нижній панелі (замініть `q=` на закодовану адресу) |

**Графік роботи:** таблиця в розмітці + атрибут `data-hours` на `#hours` (`{"1":[9,19], …, "0":null}`, 0 = неділя, години десятковими, наприклад `[9.5,18]`). Змінюйте обидва місця — статус «зараз відчинено/зачинено» рахується з `data-hours` за часом Києва.

## Як адаптувати для клієнта (5 кроків)

1. Зробіть гілку з цього шаблону й замініть усі токени `[...]` (пошук `\[[А-ЯІЇЄҐA-Z'’]+\]`) і посилання-сентинели, зокрема константи `PHONE`, `TG`, `MAIL` у `js/main.js`.
2. Приберіть категорії чи рядки прайсу, яких у школи немає (наприклад, C або A), впишіть реальні ціни й тексти карток.
3. Оновіть графік у таблиці та в `data-hours`, адресу в `q=` для мапи й маршруту.
4. Замініть фото: оновіть `tools/chosen.json` або покладіть свої файли в `img/photos/`, після коміту фото оновіть `<SHA>` в URL у `index.html`.
5. Замініть відгуки на реальні (приберіть `ph-card` і мітку), впишіть імена інструкторів, перевірте сайт на телефоні й надішліть посилання.

## Персоналізація під ліда

`python3 tools/personalize.py <lead.json> <outdir>` — створює копію сайту з даними ліда (назва, місто з правильним відмінком, адреса, телефон, соцмережі, графік, мапа), прибирає невідомі канали зв'язку й залишає позначеними лише невідомі дані.
