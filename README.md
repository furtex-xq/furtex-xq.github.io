# Kale — демо-сайт

Шаблон: **bar** (бар / паб) від Ansaro.

Заповнено з OpenStreetMap: назва, місто, адреса, телефон, Instagram, Facebook, карта й маршрут.
Viber, Telegram і WhatsApp прибрано (невідомі); форма бронювання надсилає заявку через: SMS, Instagram.

Ще треба заповнити (позначені бурштиновим підкресленням): [ІМ'Я], [ГОДИНИ], [РІК], [ФОП], [ЦІНА].
Відгуки — приклади (картки з позначкою «Приклад відгуку»), замініть на реальні. Меню, афіша й фото — типові для пабу, уточніть у закладу.
