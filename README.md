# Шаблон «Кав'ярня / кав'ярня-пекарня» (`kavyarnia`)

Універсальний односторінковий сайт для кав'ярні або кав'ярні-пекарні. Чистий HTML/CSS/JS без збірки й без CDN, мобільна версія в пріоритеті. Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/kavyarnia/index.html

## Дизайн
- **Шрифти:** Alegreya (заголовки, курсив для акцентів) + Alegreya Sans (текст). Локально в `fonts/`, лише cyrillic + latin, `font-display: swap`.
- **Палітра:** крафт-папір `#dcc6a3` / темний крафт `#cbb08a`, еспресо `#2b1a12`, молочна піна `#fbf6ee`, крема `#8c5b3a`, теракотовий акцент `#bf5636`. Легка «волокниста» текстура паперу (SVG-шум), мальовані від руки SVG-дудли: пара над чашкою, кавове зерно, іконки процесу.
- **Фішка — «brew meter»:** у блоці «Що в чашці» обираєте напій (еспресо, американо, капучино, флет вайт, лате, раф), і склянка наповнюється шарами (еспресо → молоко → піна) у міру прокручування; поруч рецепт із мілілітрами, лічильник об'єму, ціна і кнопка «Замовити …», яка підставляє напій у форму. Коли склянка повна — з'являється пара. Для `prefers-reduced-motion` склянка одразу повна, без анімацій.
- **Інше:** статус «Зараз відчинено / зачинено» за київським часом, графік із підсвіткою сьогоднішнього дня, меню-прайс як друкований лист, нижня панель на телефоні (Дзвінок / Замовити / Маршрут).

## Плейсхолдери (знайти й замінити)
Видимі дані клієнта позначені `<span class="ph">[ТОКЕН]</span>` (жовте підкреслення). Після заміни можна прибрати клас `ph` або видалити стиль `.ph` у CSS.

| Токен / сентинел | Де зустрічається |
|---|---|
| `[НАЗВА]` | title, meta, OG, JSON-LD, логотип, цитата власниці, iframe title, футер, текст заявки (`CONTACT.business` у `js/main.js`) |
| `[МІСТО]` | title, description, JSON-LD, eyebrow героя, адреса, футер |
| `[АДРЕСА]` | meta description, JSON-LD, контакти, футер |
| `[ТЕЛЕФОН]` | meta description, JSON-LD, кнопка в героя, контакти, футер |
| `[EMAIL]` | JSON-LD, контакти, футер |
| `[ГОДИНИ]` | JSON-LD (`openingHours`, формат `Mo-Fr 08:00-21:00`), футер, запасний текст статусу |
| `[ІНСТАГРАМ]` | кнопка Instagram у контактах |
| `[ФОП]` | футер (ФОП / ЄДРПОУ) |
| `[РІК]` | «Про нас» (рік відкриття) |
| `[ЦІНА]` | усе меню (`від [ЦІНА] грн`), ціна в brew meter |
| `[ІМ'Я]` | власниця в цитаті, автори відгуків |
| `tel:+380000000000` | хедер (мобільне меню), герой, контакти, футер, нижня панель |
| `viber://chat?number=%2B380000000000` | контакти + `CONTACT.viber` у `js/main.js` |
| `https://wa.me/380000000000` | контакти |
| `https://t.me/username` | контакти + `CONTACT.telegram` у `js/main.js` |
| `https://www.instagram.com/username/` | контакти, JSON-LD `sameAs` |
| `https://www.facebook.com/username` | контакти, JSON-LD `sameAs` |
| `mailto:hello@example.com` | контакти, футер + `CONTACT.email` у `js/main.js` |
| Карта `https://www.google.com/maps?q=Івано-Франківськ&output=embed` (місто URL-кодоване) | iframe у контактах; посилання «Маршрут» у нижній панелі (`maps/dir/?api=1&destination=...`) — замінити на точну адресу |
| `data-hours='{"1":["08:00","21:00"],...}'` | графік у контактах (0 = неділя). Від нього рахується «зараз відчинено/зачинено». Видаліть день, якщо вихідний |

Відгуки — приклади (`.ph-card` з міткою «Приклад відгуку — замініть на реальний»); графік має таку саму мітку. Після заміни видаліть `<span class="ph-label">`.
Також перевірте з клієнтом маркетингові твердження: рослинне молоко без доплати, коробки від 6 шт., торти за 2–3 дні, Wi-Fi/розетки, можна з собакою, «власниця» (рід).

## Як адаптувати під клієнта (5 кроків)
1. Знайти й замінити всі токени `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ГОДИНИ]`, `[ІНСТАГРАМ]`, `[ФОП]`, `[РІК]`, `[ІМ'Я]` в `index.html` і `js/main.js`.
2. Замінити сентинели посилань (телефон, Viber, WhatsApp, Telegram, Instagram, Facebook, email) і об'єкт `CONTACT` у `js/main.js`; оновити карту й «Маршрут» на точну адресу.
3. Заповнити меню реальними позиціями та цінами (`[ЦІНА]`), за потреби поправити напої в `DRINKS` у `js/main.js` (назви, мл, ціна в brew meter).
4. Вписати графік у `data-hours` і `[ГОДИНИ]` (JSON-LD), замінити відгуки на реальні, прибрати мітки-приклади.
5. Замінити фото на фото клієнта, оновити SHA, прибрати клас `.ph` і перевірити сайт на телефоні.
