# ЄВА Алта Мода — демо-сайт

Шаблон: `butik-odyagu` (бутик одягу, стиль модного журналу), варіант: бутик одягу.

Заповнено з OpenStreetMap: назва, місто, адреса, телефон, email, години роботи.

Viber, Telegram і WhatsApp прибрано, бо вони невідомі. Форма надсилає заявку через: —.

Ще треба заповнити (плейсхолдери на сайті позначені бурштиновим підкресленням):

- `[ІМ'Я]`
- `[РІК]`
- `[ФОП]`
- `[ЦІНА]`
- приклади відгуків (картки «Приклад відгуку — замініть на реальний»)
- фото: демо-фото з Unsplash, бажано замінити на фото бутика
