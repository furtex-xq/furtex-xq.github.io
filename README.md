# Шаблон «Магазин іграшок і подарунків» (`ihrashky-podarunky`)

Універсальний односторінковий сайт для магазину іграшок, подарунків, сувенірів чи подарункових боксів. Чистий HTML/CSS/JS без бібліотек і без збірки.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/ihrashky-podarunky/index.html

## Дизайн
- **Шрифти:** Pangolin (заголовки, «рукописний» але охайний) + M PLUS Rounded 1c (текст, кнопки). Обидва локально в `fonts/` (кирилиця + латиниця). Заплановану Bellota Text замінено: у неї немає українських і/ї/є/ґ.
- **Палітра:** ягідний `#B5235B`, бірюзовий `#0D7570`, сонячний жовтий `#FFC93C`, чорнильний `#241F35`, світлий папір `#FFFDF8`, рожевий `#FCE8EF` і м'ятний `#E1F1EC` відтінки.
- **Фішка:** фото на першому екрані «загорнуте» в подарунковий папір зі стрічкою й бантом. Під час прокручування стрічка розв'язується, бант злітає, а папір розходиться й відкриває фото (бант можна натиснути). Друга фішка — **підбір подарунка**: кому (дитина / дівчина / чоловік / колега) → вік → бюджет → три ідеї-бирки й кнопка, що підставляє вибір у заявку.
- Візерунок пакувального паперу (SVG) повторюється в мітках розділів, на фоні підбору, у формі й у футері.
- Блоки: перший екран, каталог (6 категорій із цінами «від»), підбір подарунка, пакування й послуги (прайс), про магазин, як замовити (4 кроки), відгуки, питання, контакти + графік + форма + карта, футер, нижня панель на телефоні (Дзвінок / Підібрати / Маршрут).

## Плейсхолдери
Видимі токени обгорнуті в `<span class="ph">…</span>` (бурштинове підкреслення). Після заміни обгортку можна прибрати.

| Токен / маркер | Де |
|---|---|
| `[НАЗВА]` | `<title>`, og:title, JSON-LD, логотип у шапці й футері, бирка на фото першого екрана, «Про магазин», копірайт, `data-shop` форми (підпис у тексті заявки) |
| `[МІСТО]` | title, meta description («у [МІСТО]»), og:title, JSON-LD, плашка першого екрана, «Про магазин» («у [МІСТО]»), контакти, футер |
| `[АДРЕСА]` | перший екран, контакти, футер, JSON-LD |
| `[ТЕЛЕФОН]` | картка «Телефон» у контактах, JSON-LD |
| `[EMAIL]` | картка Email, JSON-LD |
| `[ІНСТАГРАМ]` | картка Instagram (наприклад `@shop.if`) |
| `[ГОДИНИ]` | перший екран, примітка під таблицею графіка, JSON-LD `openingHours` |
| `[ЦІНА]` | бирки «від [ЦІНА] грн» у каталозі й прайс пакування, JSON-LD `priceRange` |
| `[РІК]` | «Про магазин» — рік відкриття |
| `[ФОП]` | футер — ФОП / ЄДРПОУ |
| `[ІМ'Я]` | автори відгуків |
| `.ph-card` | три приклади відгуків з міткою «Приклад відгуку — замініть на реальний» |
| `tel:+380000000000` | шапка, перший екран, контакти, нижня панель |
| `viber://chat?number=%2B380000000000`, `https://t.me/username`, `https://wa.me/380000000000` | картки месенджерів у контактах |
| `https://www.instagram.com/username/`, `https://www.facebook.com/username` | картки соцмереж, JSON-LD `sameAs` |
| `mailto:hello@example.com` | картка Email |
| `maps?q=Івано-Франківськ&output=embed` / `maps/dir/?api=1&destination=…` | iframe карти, «Прокласти маршрут», «Маршрут» на панелі |
| Таблиця графіка (`data-hours`, `data-open`/`data-close`) | контакти; за нею рахується «Зараз відчинено/зачинено» за київським часом. Видаліть рядок (або `data-open`), щоб день став вихідним |

**Форма працює від контактів.** Варіанти «Куди надіслати заявку» скрипт збирає з карток `[data-ch]` у контактах: SMS (лише коли телефон мобільний), Telegram, Viber, WhatsApp, Instagram Direct (`ig.me/m/<нік>`), Email; Facebook — лише якщо інших каналів немає. Прибрали картку — зник і варіант у формі. Якщо каналів немає взагалі, форма копіює текст заявки й пропонує зателефонувати.

## Фото (Unsplash, замінити на фото клієнта)
Усі фото підключені абсолютними посиланнями на коміт `05e63a2` (`img/photos/`): `hero` (вітрина з іграшками — **головне, що варто замінити на вітрину/зал клієнта**), `teddy`, `lego`, `wooden`, `games`, `cars`, `candle` (категорії каталогу — бажано фото реальних полиць), `wrap`, `boxes` (пакування — ідеально фото їхнього пакування), `plush` («Про магазин» — фото залу). `giftpink`, `meeples` — запасні.

## Як адаптувати під клієнта (5 кроків)
1. Знайдіть і замініть токени `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ІНСТАГРАМ]`, `[ГОДИНИ]` (а після «у» — місто в місцевому відмінку: «у Івано-Франківську»).
2. Замініть посилання-заглушки (`tel:`, Viber, Telegram, WhatsApp, Instagram, Facebook, `mailto:`), картки без даних видаліть цілим `<li>`; оновіть запит карти та маршруту.
3. Заповніть таблицю графіка (`data-open`/`data-close` + текст) і JSON-LD.
4. Поставте ціни `[ЦІНА]`, рік, ФОП; відредагуйте категорії каталогу під реальний асортимент; замініть відгуки на справжні й приберіть `ph-card`.
5. Замініть фото на фото клієнта (вітрина, полиці, пакування) й перевірте сайт на телефоні.

Для автоматичного заповнення з картки ліда: `python3 tools/personalize.py lead.json out/`.
