# La Пєц — демо-сайт

Шаблон: **fastfud** (піца / бургери / фастфуд) від Ansaro. Акцент: піца (герой, меню й конструктор відкриваються на піці).

Заповнено з OpenStreetMap: назва, місто, адреса, телефон, карта й маршрут.
Viber, Telegram і WhatsApp прибрано (невідомі). Форма замовлення надсилає заявку через: SMS.

Ще треба заповнити (позначені бурштиновим підкресленням): [ІМ'Я], [ГОДИНИ], [РІК], [ФОП], [ЦІНА].
Відгуки — приклади (картки з позначкою «Приклад відгуку»), замініть на реальні. Меню, умови доставки й фото — типові, уточніть у закладу.
