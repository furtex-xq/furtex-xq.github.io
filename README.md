# Інжектор — демо-сайт СТО

Персоналізована копія шаблону **«СТО / автосервіс»** (`template/sto`).

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/beta/inzhektor/index.html

## Заповнено з OpenStreetMap

- назва
- місто
- адреса
- телефон
- графік роботи
- точка на карті

Канали, яких немає в OSM (Viber, Telegram, WhatsApp, email, Instagram), прибрані з кнопок і форми.

## Що ще заповнити

- `[ІМ'Я]` (позначено жовтим пунктиром)
- `[РІК]` (позначено жовтим пунктиром)
- `[ФОП]` (позначено жовтим пунктиром)
- `[ЦІНА]` (позначено жовтим пунктиром)
- 3 відгуки-приклади (картки `ph-card`) — замінити на реальні
- фото — зараз стокові з Unsplash, краще замінити на фото сервісу
- коефіцієнти класу авто в калькуляторі (×1 / ×1,2 / ×1,4) — узгодити з власником
