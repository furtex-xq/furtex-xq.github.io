# Українська Вишиванка — демо-сайт

Шаблон: `butik-odyagu` (бутик одягу, стиль модного журналу), варіант: магазин вишиванок.

Заповнено з OpenStreetMap: назва, місто, адреса, телефон.

Viber, Telegram і WhatsApp прибрано, бо вони невідомі. Форма надсилає заявку через: SMS.

Ще треба заповнити (плейсхолдери на сайті позначені бурштиновим підкресленням):

- `[ІМ'Я]`
- `[ГОДИНИ]`
- `[РІК]`
- `[ФОП]`
- `[ЦІНА]`
- приклади відгуків (картки «Приклад відгуку — замініть на реальний»)
- фото: демо-фото з Unsplash, бажано замінити на фото бутика
