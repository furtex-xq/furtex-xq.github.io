# Шаблон «Тату-салон» (tatu)

Універсальний односторінковий сайт для тату-салону / тату-студії. Чистий HTML/CSS/JS без збірки й без CDN: `index.html`, `css/style.css`, `js/main.js`, шрифти в `fonts/`.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/tatu/index.html

## Дизайн

- **Шрифти:** Ruslan Display (заголовки, номери ескізів) + Anonymous Pro (текст, моноширинний «машинописний» ритм). Обидва з кирилицею, підключені локально (`font-display: swap`).
- **Палітра:** кістяний папір `#E8E0CF`, світлий аркуш `#F4EEE2`, тату-чорнило `#151211`, кров'яно-червоний акцент `#A8191E`, фіолетовий термо-трансфер `#4D468F` (лише пунктирні «трафаретні» обведення й фокус).
- **Фішка:** флеш-лист — сітка ескізів, як на справжньому аркуші в студії, з номерами, фільтром за стилем (лайн, графіка, реалізм, мінімалізм) і кнопкою «Хочу цей», що підставляє ескіз у заявку. Поруч — «трансфер»-калькулятор: стиль + місце на тілі + розмір → формат, час роботи, чутливість місця й «від [ЦІНА] грн», з кнопкою запису з цими параметрами.
- Липка мобільна панель: Дзвінок / Записатися / Маршрут. Статус «зараз відчинено/зачинено» за київським часом.

## Токени та сентинели

| Токен / сентинел | Де |
|---|---|
| `[НАЗВА]` | title, OG, JSON-LD, логотип, H1, «Студія», футер, текст заявки (`data-biz` форми) |
| `[МІСТО]` | title, OG, JSON-LD, eyebrow героя («у [МІСТО]»), адреса («, [МІСТО]»), футер («у [МІСТО]») |
| `[АДРЕСА]` | JSON-LD, блок «Адреса», футер |
| `[ТЕЛЕФОН]` | OG, JSON-LD, шапка, контакти, блок «Зателефонуйте нам» |
| `[EMAIL]` | JSON-LD, контакти |
| `[ГОДИНИ]` | JSON-LD, підсумок годин у контактах |
| `[ІНСТАГРАМ]` | контакти (`@handle`) |
| `[ФОП]` | футер (ПІБ ФОП / ЄДРПОУ) |
| `[РІК]` | JSON-LD, «працює з [РІК] року» |
| `[ЦІНА]` | прайс, ціни у флеш-листі, калькулятор (`PRICE` у `js/main.js` — впишіть числа), JSON-LD priceRange |
| `[ІМ'Я]` | майстри, підписи відгуків |
| `ph-card` | 3 приклади відгуків — замініть реальними |
| `tel:+380000000000` | шапка, контакти, мобільна панель, «Зателефонуйте нам» |
| `viber://chat?number=%2B380000000000`, `https://wa.me/380000000000`, `https://t.me/username` | контакти й варіанти відправки форми |
| `https://www.instagram.com/username/`, `https://www.facebook.com/username` | контакти, JSON-LD sameAs |
| `mailto:hello@example.com` | контакти, форма |
| Google Maps `?q=Івано-Франківськ` | iframe карти + «Прокласти маршрут» (контакти й мобільна панель) |
| `data-hours` на `#hours` | графік для таблиці й статусу «відчинено» (зараз — приклад, позначений пунктиром) |

Кожен контакт — рядок `<li data-ch="...">` у `#ct`: зайвий канал видаляється цілим рядком. Варіанти відправки заявки — радіокнопки `name="via"` з `data-href` (підтримуються telegram, viber, whatsapp, email, sms, instagram).

## Фото (Unsplash, замінити на роботи студії)

`hero` (процес набивання), `work3` (студія), `master`, `work2` (майстри), а також роботи у флеш-листі: `lion`, `angel` (реалізм), `floral`, `sleeve` (графіка), `grey`, `hand` (лайн), `mountain` (мінімалізм). SVG-ескізи (кинджал, місяць, змія, серце «мама», хвиля) можна лишити або замінити власним флешем. Фото підключені абсолютними URL raw.githubusercontent із прив'язкою до коміту.

## Як адаптувати під клієнта

1. Знайдіть і замініть токени `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ІНСТАГРАМ]`, `[ФОП]`, `[РІК]`, приберіть обгортку `<span class="ph">`.
2. Замініть сентинели посилань; видаліть рядки контактів (`li[data-ch]`) і варіанти форми, яких у клієнта немає.
3. Впишіть ціни в прайс і флеш-лист, числа — в `PRICE` у `js/main.js`.
4. Оновіть `data-hours` і `[ГОДИНИ]`, карту й маршрут (адреса в `?q=` / `destination=`), зніміть клас `ph-box` з таблиці годин.
5. Замініть фото на роботи майстрів, імена `[ІМ'Я]`, відгуки (`ph-card`) — на реальні.

Автоматично для ліда: `python3 tools/personalize.py <lead.json> <outdir>`.
