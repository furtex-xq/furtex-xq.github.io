# Шаблон «Спорттовари / велосипеди / прокат» (`template/sport-velo`)

Односторінковий сайт для веломагазину, спортивного магазину або прокату велосипедів в Івано-Франківську. Чистий HTML/CSS/JS без бібліотек і без збірки: `index.html`, `css/style.css`, `js/main.js`, шрифти в `fonts/`.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/sport-velo/index.html

## Дизайн

- **Шрифти:** Handjet (змінний: вага + вісь ELSH — форма «пікселів») для заголовків і цифр, PT Sans Caption для тексту. Обидва з кирилицею, лежать локально (cyrillic + latin).
- **Палітра:** крейдяний сірий `#e3e4de`, лісовий зелений `#1d3a2d` / `#12261d`, помаранчевий «маркування стежки» `#e2611b`, чорнило `#151a16`. Фон hero, блоку калькулятора й підвалу — топографічні горизонталі (`img/topo.svg`, `img/topo-light.svg`).
- **Фішка:** «Велокомп'ютер» — пристрій із РК-екраном: режим «Розмір рами» (тип велосипеда + зріст → розмір, рама, колеса) і режим «Прокат» (тип, погодинно/подобово, тривалість, кількість велосипедів → сума). Кнопки на екрані заповнюють форму заявки. Позначки розділів — як маркування туристичних стежок (біла — помаранчева — біла смуга). Заголовки «збираються» з пікселів (анімація осі ELSH) при появі.
- Живий статус «Зараз відчинено / Зачинено» за київським часом — у hero і біля графіка.
- Мобільна панель дій: Дзвінок / Заявка / Маршрут.

## Токени та посилання-заглушки

| Токен / заглушка | Де зустрічається |
|---|---|
| `[НАЗВА]` | `<title>`, meta description, OG, JSON-LD, логотип, лід hero, «Про нас», підвал, title карти |
| `[МІСТО]` | `<title>`, meta, JSON-LD, рядок над H1 («у [МІСТО]»), адреса в контактах і підвалі |
| `[АДРЕСА]` | meta description, JSON-LD, контакти, підвал |
| `[ТЕЛЕФОН]` | meta description, JSON-LD, шапка, меню, контакти, підвал |
| `[EMAIL]` | JSON-LD, контакти, підвал |
| `[ІНСТАГРАМ]` | картка Instagram у контактах (нік з @) |
| `[ГОДИНИ]` | JSON-LD `openingHours`, підсумок над таблицею графіка |
| `[ФОП]` | підвал (ФОП / ЄДРПОУ) |
| `[РІК]` | «Про нас» («працює з [РІК] року») |
| `[ЦІНА]` | прайс у всіх вкладках каталогу (`від [ЦІНА] грн`), екран прокату |
| `[ІМ'Я]` | автори відгуків |
| `tel:+380000000000` | шапка, меню, hero, контакти, підвал, мобільна панель; `CONTACT.tel` у `js/main.js` |
| `viber://chat?number=%2B380000000000` | контакти; `CONTACT.viber` |
| `https://t.me/username` | контакти; `CONTACT.telegram` |
| `https://wa.me/380000000000` | контакти; `CONTACT.whatsapp` |
| `https://www.instagram.com/username/` | контакти, JSON-LD `sameAs`; для форми — `CONTACT.instagram` (нік) |
| `https://www.facebook.com/username` | контакти, JSON-LD `sameAs` |
| `mailto:hello@example.com` | контакти, підвал; `CONTACT.email` |
| Google Maps `?q=Івано-Франківськ` | iframe карти, кнопка «Прокласти маршрут», мобільна панель (`maps/dir/?api=1&destination=`) |

Відгуки — приклади (`ph-card` з позначкою «Приклад відгуку — замініть на реальний»).

У `js/main.js`, блок **НАЛАШТУВАННЯ**:
- `HOURS` — графік для таблиці та живого статусу (`null` — сховати статус і таблицю, лишити текст `[ГОДИНИ]`);
- `RENT` — тарифи прокату в гривнях (`hour`, `day` для міського, гірського, дитячого); поки `null`, калькулятор показує `[ЦІНА]`;
- `CONTACT` — куди надсилає форма (Telegram, Viber, WhatsApp, SMS, Instagram Direct, email).

Акцент сторінки: атрибут `<body data-focus="velo|sport|rent">` — відкриває відповідну вкладку каталогу (і режим «Прокат» у велокомп'ютері для `rent`). `tools/personalize.py` також міняє тексти hero під тип бізнесу.

## Фото (Unsplash, замінити на фото клієнта)

Посилання закріплені на коміт `5b3c11d` (`raw.githubusercontent.com/.../img/photos/<slot>.jpg`), список — `tools/chosen.json`, ліцензії — `img/photos/credits.json`.

- `hero` — райдер у лісі (бажано: фото з покатушки клієнта або вітрини);
- `shop` — зал із велосипедами під стелею (обов'язково замінити на реальний магазин);
- `service`, `wheel`, `drivetrain` — майстерня (замінити на майстра клієнта);
- `rent` — велосипеди на парковці (замінити на парк прокату клієнта);
- `trail`, `balls`, `fitness`, `run`, `helmet` — атмосферні/категорійні, можна лишити.

## Як адаптувати під клієнта — 5 кроків

1. Знайти й замінити токени (`[НАЗВА]`, `[ТЕЛЕФОН]`, `[АДРЕСА]`…) і зняти обгортку `<span class="ph">`; після «у/в» місто ставити в місцевому відмінку («у Калуші»).
2. Замінити посилання-заглушки (`tel:`, `mailto:`, Instagram, Facebook, Viber/Telegram/WhatsApp) або видалити кнопки каналів, яких немає (елементи з `data-ch="…"`), і оновити `CONTACT` у `js/main.js`.
3. Вписати графік у `HOURS` і текст `[ГОДИНИ]`; ціни — у прайс (`[ЦІНА]`) і тарифи в `RENT`.
4. Оновити карту й маршрут (адреса в `q=` і `destination=`), JSON-LD, `[ФОП]` у підвалі, обрати `data-focus`.
5. Замінити фото на реальні, відгуки — на справжні (прибрати `ph-card` і позначку), перевірити на телефоні.

Автоматично для ліда з OpenStreetMap: `python3 tools/personalize.py lead.json out/`.
