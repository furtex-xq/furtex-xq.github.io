# Шаблон «Фітнес-клуб / спортзал» (`template/fitnes`)

Універсальний односторінковий сайт для фітнес-клубу, тренажерного залу чи студії групових тренувань. Статичний HTML/CSS/JS без збірки і без бібліотек, мобільна версія в пріоритеті.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/fitnes/index.html

## Дизайн
- **Шрифти:** Days One (заголовки, великі цифри) + Roboto 400/500/700 (текст). Локально в `fonts/`, кирилиця + латиниця.
- **Палітра:** світлий бетон `#dcdbd6`, світлі плити `#eceae5`, чорний `#121212`, графіт `#3b3b39`, сталь `#a9a7a0`, сигнальний помаранчевий `#ff5a14`.
- **Фішка:** конструктор абонемента у вигляді штанги — кожен вибір (термін, час, групові, тренер) додає «млинці» на гриф, а табло показує дні доступу, тренування з тренером і підсумок; кнопка переносить вибір у форму. Плюс тижневий розклад групових із фільтром за типом (сила / кардіо / гнучкість), сьогоднішній день підсвічено, а в героі — найближчі заняття «сьогодні в розкладі».
- Живий статус «Зараз відчинено / зачинено» за київським часом.

## Блоки
Герой → Напрямки (4 формати з цінами) → Конструктор абонемента + прайс → Розклад → Як почати (4 кроки) → Про клуб і тренери → Відгуки (приклади) → FAQ → Контакти, години, форма, карта → Футер → мобільна панель (Дзвінок / Записатися / Маршрут).

## Токени і заглушки
| Токен / заглушка | Де |
|---|---|
| `[НАЗВА]` | `<title>`, og:title, JSON-LD, логотип, H1, «Напрямки», «Про клуб», підпис карти, футер, `CONFIG.name` у `js/main.js` (текст заявки) |
| `[МІСТО]` | `<title>`, description, og:title, JSON-LD, H1 («спортзал у [МІСТО]»), адреса в контактах, футер («у [МІСТО]») — скрізь після «у», тобто місцевий відмінок |
| `[АДРЕСА]` | JSON-LD, контакти, футер |
| `[ТЕЛЕФОН]` | шапка, контакти, JSON-LD |
| `[EMAIL]` | контакти, JSON-LD |
| `[ІНСТАГРАМ]` | кнопка Instagram у контактах |
| `[ГОДИНИ]` | блок «Години роботи», JSON-LD; таблиця днів і статус будуються з `HOURS` у `js/main.js` |
| `[ФОП]` | футер (ФОП / ЄДРПОУ) |
| `[РІК]` | плашка «з [РІК]» на фото в «Про клуб» |
| `[ЦІНА]` | ціни напрямків, конструктор, прайс (`від [ЦІНА] грн`), JSON-LD priceRange |
| `[ІМ'Я]` | тренери, автори відгуків |
| `ph-card` | 3 приклади відгуків з позначкою «Приклад відгуку — замініть на реальний» |
| `tel:+380000000000` | шапка, контакти, мобільна панель |
| `viber://chat?number=%2B380000000000` | контакти, `CONFIG.viber` |
| `https://t.me/username` | контакти, `CONFIG.telegram` |
| `https://wa.me/380000000000` | контакти, `CONFIG.whatsapp` |
| `https://www.instagram.com/username/` | контакти, JSON-LD sameAs, `CONFIG.instagram` |
| `https://www.facebook.com/username` | контакти, JSON-LD sameAs |

Кожна кнопка зв'язку і варіант «Куди надіслати заявку» має атрибут `data-ch` (`tel`, `viber`, `tg`, `wa`, `ig`, `fb`, `mail`) — невідомі канали прибираються цілим елементом. Розклад групових — масив `CLASSES` у `js/main.js`.

## Фото (Unsplash, замінити на фото клубу)
Усі фото — абсолютні URL на raw.githubusercontent.com, закріплені на коміті `f836de7` (`img/photos/`):
`hero` (світлий зал з доріжками), `gym` (тренажерний зал), `functional` (штанга в групі), `stretch` (групове з гантелями), `trainer` (тренер і клієнтка), `rack` (стіна з інвентарем, «Про клуб»). Запасні: `group`, `kettlebell`, `yoga`, `cardio`. Найважливіше замінити: героя, тренажерний зал і фото тренерів.

## Як адаптувати під клієнта (5 кроків)
1. `python3 tools/personalize.py lead.json out/` — підставить назву, контакти, години, карту й прибере невідомі канали (або замініть токени вручну пошуком `[`).
2. Впишіть ціни замість `[ЦІНА]` у напрямках, конструкторі і прайсі; приберіть позиції, яких у клубі немає.
3. Оновіть `CLASSES` (розклад) і `HOURS` у `js/main.js`; перевірте, які напрямки реально є.
4. Замініть фото на справжні фото залу і тренерів, впишіть імена тренерів, рік, ФОП.
5. Замініть приклади відгуків на реальні (з Google Maps / Instagram) і приберіть клас `ph-card`.
