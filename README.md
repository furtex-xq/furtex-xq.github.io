# 3/7 coffee boutique — демо-сайт

Персоналізована демо-версія шаблону **«Кав'ярня / кав'ярня-пекарня» (`kavyarnia`)** для «3/7 coffee boutique», Івано-Франківськ.

**Заповнено з OpenStreetMap:** назва, місто, адреса, телефон, instagram, facebook, графік роботи.
Джерело: https://www.openstreetmap.org/node/11705102975

**Ще треба заповнити (позначено жовтим на сторінці):**
- `[ІМ'Я]`
- `[РІК]`
- `[ФОП]`
- `[ЦІНА]`
- приклади відгуків (картки з міткою «Приклад відгуку») — замінити на реальні;
- фото з Unsplash — замінити на фото закладу;
- меню й тексти — звірити з реальним асортиментом і умовами.
