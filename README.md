# Зір — демо-сайт оптики

Шаблон: **optyka** (оптика / перевірка зору).

Заповнено з OpenStreetMap: назва, місто, адреса, телефон, графік роботи.

Залишилося заповнити (на сторінці позначено жовтим пунктиром):

- `[ІМ'Я]` — ім'я фахівця та авторів відгуків
- `[РІК]` — рік заснування (блок «Про нас»)
- `[ФОП]` — ФОП / ТОВ і ЄДРПОУ у футері
- `[ЦІНА]` — ціни в прайсі, на етикетці головного екрана й у блоці «Про нас»
- три відгуки з міткою «Приклад відгуку» — замінити на реальні
- фото (зараз стокові з Unsplash) — замінити на фото оптики
- перелік послуг і прайс — звірити з реальним (діти, контактні лінзи, ремонт)
