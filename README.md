# GRAND-GRANIT — демо нового сайту (бета)

Статичний сайт (HTML/CSS/JS) для GRAND-GRANIT, Калуш: пам'ятники та вироби з граніту й мармуру.

- `index.html` — односторінковий сайт українською
- `css/style.css`, `js/main.js`
- `img/` — текстури каменю (SVG), favicon, OG-зображення

Відкрити локально: просто відкрити `index.html` у браузері.

Демо-версія: фото робіт, відгуки, години роботи та ФОП/ЄДРПОУ — заглушки, замінити даними клієнта.
