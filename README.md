# Backstage — демо-сайт

Шаблон: «Фотостудія / фотограф» (`template/fotostudiia`).

Заповнено з OpenStreetMap: назва, місто, адреса, телефон, Instagram, графік роботи (текстом).
Джерело: https://www.openstreetmap.org/node/10965262899

Ще треба заповнити (позначені бурштиновим підкресленням): `[ІМ'Я]`, `[РІК]`, `[ФОП]`, `[ЦІНА]`.
Відгуки — приклади (`ph-card`), замініть на реальні. Фото — зі стоку Unsplash, замініть на портфоліо і фото залу студії.
