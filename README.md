# Шаблон «Клінінг / хімчистка» (klininh)

Односторінковий сайт для клінінгової компанії — і, в окремому варіанті, для хімчистки чи пральні. Чистий HTML/CSS/JS без бібліотек і без збирання, спершу під мобільні.

- Демо (клінінг): `https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/klininh/index.html`
- Демо (хімчистка і пральня): `https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/klininh/himchystka.html`

## Дизайн

- **Шрифти:** Advent Pro 500/600/700 (заголовки, цифри калькулятора) + Istok Web 400/700 (текст). Обидва з кирилицею, лежать локально в `fonts/`.
- **Палітра:** свіжий білий `#f9fcfc`, аква-туман `#e4f5f3`, аква `#19b8b2` (текст `#0b7672`), лимон `#f2de3a` (кнопки), морський графіт `#10272b`.
- **Фішка:** «скребок». Фото на головному екрані спочатку запітніле, а потім скребок протирає його до чистоти, і з'являються іскорки. У блоці «До і після» повзунок теж зроблено як лезо скребка. При `prefers-reduced-motion` анімацію вимкнено.
- **Калькулятор:** тип прибирання × площа + вікна, хімчистка дивана й додаткові послуги. Показує орієнтовну ціну, розбивку й тривалість роботи бригади. У варіанті «хімчистка» рахує за речами. Кнопка «Замовити з цим розрахунком» переносить розрахунок у форму.
- **Інше:** прайс у 4 картках, вкладки «що входить» (по кімнатах або по тканинах), 4 кроки процесу, відгуки-приклади, FAQ, форма з надсиланням через SMS, Viber, Telegram, WhatsApp, Instagram Direct чи email, графік роботи зі статусом «зараз відчинено» за київським часом, карта Google і нижня панель на мобільному (дзвінок, замовлення, маршрут).

## Два варіанти тексту

`index.html` — клінінг. Блоки, що залежать від ніші, позначені коментарями `<!--v:ID-->…<!--/v:ID-->`. Файл `tools/variants/himchystka.html` містить такі самі блоки для хімчистки й пральні: назву, SEO, JSON-LD `DryCleaningOrLaundry`, головний екран, калькулятор, прайс, тканини, процес, «Про нас», відгуки, FAQ і форму.

- Переглянути варіант: `himchystka.html` (оновлюється командою `python3 tools/personalize.py --preview himchystka`).
- Для ліда: `python3 tools/personalize.py lead.json out/ [--variant himchystka|klininh]`. Без прапорця варіант обирається автоматично: за назвою, Instagram чи Facebook (хімчистка, пральня, himchistka…), за полем `variant` або за списком `VARIANT_BY_SLUG`.

## Токени та сентинели

| Токен / сентинел | Де на сторінці |
|---|---|
| `[НАЗВА]` | `<title>`, OG, JSON-LD, логотип, «Про нас», футер, карта (title) |
| `[МІСТО]` | title/description, надзаголовок на головному екрані («у [МІСТО]» → місцевий відмінок), «Про нас», адреса, футер, JSON-LD |
| `[АДРЕСА]` | контакти, футер, JSON-LD |
| `[ТЕЛЕФОН]` | меню, «Швидше голосом?», великий номер у контактах, JSON-LD |
| `[EMAIL]` | кнопка в контактах, JSON-LD |
| `[ІНСТАГРАМ]` | кнопка Instagram у контактах |
| `[ГОДИНИ]` | короткий графік над таблицею |
| `[ФОП]` | футер |
| `[РІК]` | підпис до фото в «Про нас», JSON-LD `foundingDate` |
| `[ЦІНА]` | прайс (`від [ЦІНА] грн`), картки типів прибирання, атрибути калькулятора `data-rate` / `data-price` (впишіть число, і калькулятор почне рахувати) |
| `[ІМ'Я]` | автори відгуків (картки `ph-card` з міткою «Приклад відгуку») |
| `tel:+380000000000` | меню, головний екран, контакти, нижня панель |
| `sms:+380000000000` | форма (канал SMS) |
| `viber://chat?number=%2B380000000000` | контакти, форма |
| `https://t.me/username` | контакти, форма |
| `https://wa.me/380000000000` | контакти, форма |
| `https://www.instagram.com/username/`, `https://ig.me/m/username` | контакти, JSON-LD; форма (Instagram Direct) |
| `https://www.facebook.com/username` | контакти, JSON-LD |
| `mailto:hello@example.com` | контакти, форма |
| `maps?q=Івано-Франківськ` / `maps/dir/?api=1&destination=…` | карта, кнопка «Прокласти маршрут», нижня панель |
| Графік `data-hours="08:00-20:00"` | таблиця в контактах (`""` означає вихідний, `data-day` 0 — неділя) |

Кожна кнопка зв'язку має атрибут `data-ch="phone|sms|viber|telegram|whatsapp|instagram|facebook|email"`, тож невідомий канал можна прибрати разом з елементом. Сітка кнопок сама підлаштовується під їхню кількість.

## Фото (Unsplash, замінити на фото клієнта)

`img/photos/`: `hero` (світла вітальня з вікнами), `kitchen` (кухня; також використана в «До і після»), `windows`, `sofa`, `floor`, `team` (у «Про нас»), `wipe` (запасне); для хімчистки: `d-suits` (головний екран), `d-knit` («До і після»), `d-press`, `d-washers`, `d-hero` («Про нас»). На сторінці фото підключені абсолютними URL raw.githubusercontent із прив'язкою до коміту.

Найважливіше отримати від клієнта: реальну пару фото «до/після» (і прибрати клас `is-sim`, який імітує бруд), фото команди чи приймального пункту, логотип.

## Як адаптувати під клієнта

1. Оберіть варіант (клінінг чи хімчистка) і запустіть `tools/personalize.py` з даними ліда або замініть токени пошуком.
2. Впишіть ціни: у прайсі замініть `[ЦІНА]`, а в калькуляторі заповніть `data-rate` / `data-price` числами.
3. Замініть фото на фото клієнта, а «До і після» — на реальну пару фото.
4. Перевірте графік (`data-hours`), канали зв'язку й адресу для карти та маршруту.
5. Замініть три відгуки-приклади на справжні, впишіть `[ФОП]` і `[РІК]`, а потім перевірте сторінку на телефоні.
