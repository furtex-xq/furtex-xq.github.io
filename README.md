# Шаблон «Ремонт телефонів і техніки» (`remont-telefoniv`)

Універсальний односторінковий демо-сайт для сервісного центру / майстерні з ремонту смартфонів, планшетів, ноутбуків і гаджетів. Чистий HTML/CSS/JS без бібліотек і без збірки: `index.html`, `css/style.css`, `js/main.js`.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/remont-telefoniv/index.html

## Дизайн
- **Шрифти:** Wix Madefor Display (заголовки й текст, variable 400–800) + Victor Mono (характеристики, ціни, мітки, variable). Локально в `fonts/` (cyrillic + latin, woff2, `font-display: swap`).
- **Палітра:** off-black `#0d0f0b`, панелі `#181b14`, лінії `#2a2f24`, текст `#e8ecdf`, приглушений `#8e9685`, акцент electric lime `#c6f03a`. Плейсхолдери підсвічені бурштиновим `#f2b440`.
- **Фішка:** «рентген» телефона — ізометричний SVG-телефон, що під час прокручування розкладається на шари (скло → дисплей → рамка → акумулятор → плата → кришка); активний шар підсвічується лаймом, поруч — що в ньому ремонтуємо і від якої ціни. Плюс калькулятор ремонту (пристрій → бренд → клас моделі → проблема → орієнтовний час, «від [ЦІНА] грн», порада щодо запчастини) з кнопкою, що переносить вибір у форму заявки.
- Також: доріжки плати в hero, «трасування» процесу ремонту, статус «зараз відчинено/зачинено» за київським часом, нижня панель дій на мобільному (Дзвінок / Записатися / Маршрут). `prefers-reduced-motion` враховано.

## Плейсхолдери та «сентинели»
| Токен / рядок | Де зустрічається |
|---|---|
| `[НАЗВА]` | `<title>`, OG, JSON-LD, логотип у шапці, футер |
| `[МІСТО]` | `<title>`, description, OG, JSON-LD, H1, eyebrow hero, «Про нас», контакти, футер |
| `[АДРЕСА]` | description, JSON-LD, підпис фото hero, контакти, футер |
| `[ТЕЛЕФОН]` | JSON-LD, контакти, футер |
| `[EMAIL]` | JSON-LD, кнопка email у контактах, футер |
| `[ГОДИНИ]` | JSON-LD `openingHours` (формат `Mo-Fr 09:00-19:00`), підпис графіка в контактах |
| `[ІНСТАГРАМ]` | кнопка Instagram у контактах |
| `[ФОП]` | футер (ПІБ ФОП / ЄДРПОУ) |
| `[РІК]` | JSON-LD `foundingDate`, «Про нас» (текст і штамп «з [РІК]») |
| `[ЦІНА]` | JSON-LD `priceRange`, hero, шари «рентгена», калькулятор, увесь прайс (`від [ЦІНА] грн`) |
| `[ІМ'Я]` | майстер у «Про нас», автори відгуків |
| `tel:+380000000000` | шапка, hero, контакти, футер, мобільна панель |
| `viber://chat?number=%2B380000000000` | контакти; `js/main.js` → `CONTACT.viber` (форма) |
| `https://t.me/username` | контакти; `js/main.js` → `CONTACT.tg` (форма) |
| `https://wa.me/380000000000` | контакти |
| `https://www.instagram.com/username/` | контакти, JSON-LD `sameAs` |
| `https://www.facebook.com/username` | контакти, JSON-LD `sameAs` |
| `mailto:hello@example.com` | контакти, футер; `js/main.js` → `CONTACT.email` (форма) |
| `https://www.google.com/maps?q=Івано-Франківськ&output=embed` (URL-кодовано) | iframe карти; також посилання «Маршрут» / «Прокласти маршрут» (`maps/dir/?api=1&destination=…`) |

Відгуки — приклади: картки мають клас `ph-card` і мітку «Приклад відгуку — замініть на реальний». Перед здачею клієнту приберіть мітку та клас.

**Графік роботи** для статусу «відчинено/зачинено» і таблиці задається в `js/main.js` → `HOURS` (за замовчуванням Пн–Пт 9–19, Сб 10–17, Нд вихідний). Час у калькуляторі — `PROBLEMS` у `js/main.js`.

## Фото (Unsplash, замінити на фото клієнта)
Лежать у `img/photos/`, у HTML підключені абсолютними URL raw.githubusercontent.com, закріпленими на SHA коміту. Джерела — `tools/chosen.json`, `img/photos/credits.json`.
- `hero` — майстер за роботою → **найважливіше замінити**: реальний майстер / робоче місце клієнта.
- `solder`, `fixing` — «Про нас» → фото майстерні, стійки приймання, майстра.
- `screen`, `laptop`, `inside`, `gloves` — стрічка «з майстерні» → реальні ремонти клієнта (до/після, розібрані телефони).
- `board`, `tester`, `battery` — запасні, на сторінці не використані.

## Як адаптувати під клієнта (5 кроків)
1. Знайти й замінити всі токени `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ГОДИНИ]`, `[ІНСТАГРАМ]`, `[ФОП]`, `[РІК]`, `[ІМ'Я]`, а потім прибрати обгортки `<span class="ph">…</span>`.
2. Замінити сентинели посилань (телефон, Viber, Telegram, WhatsApp, Instagram, Facebook, email) у `index.html` і `CONTACT` у `js/main.js`; у карті й «Маршруті» поставити точну адресу.
3. Проставити ціни замість `[ЦІНА]` у прайсі, шарах «рентгена» й hero; за потреби поправити час і проблеми в `PROBLEMS` та графік `HOURS` у `js/main.js`.
4. Замінити фото на фото клієнта (той самий розмір/пропорції, `alt` оновити) і вставити справжні відгуки замість прикладів (прибрати `ph-card` і мітку).
5. Перевірити `<title>`, description, OG і JSON-LD, відкрити сайт на телефоні: меню, калькулятор, форма (відкриває Telegram/Viber/пошту), статус «відчинено».
