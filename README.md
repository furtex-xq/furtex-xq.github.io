# Шаблон «Адвокат» (advokat)

Універсальний односторінковий сайт для адвоката, адвокатського бюро чи юридичної компанії. Статичний HTML/CSS/JS без збірки й без CDN: `index.html`, `css/style.css`, `js/main.js`, шрифти в `fonts/`.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/advokat/index.html

## Дизайн
- **Шрифти:** PT Serif (заголовки, 400/400 italic/700) + Arimo (текст, variable 400–700). Лише кирилиця й латиниця, `font-display: swap`.
- **Палітра:** слонова кістка `#F4EFE4`, папір `#FBF8F2`, чорнило `#1E1B1F`, бордо (oxblood) `#6E1F24`, лінії `#D3C8B5`, темна секція `#211B1D`.
- **Стиль:** «юридичний документ» — шапка героя як службова записка (Від / Де / Коли), тонкі лінії, подвійна бордова лінія поля на десктопі з номерами розділів «§ 1 … § 7», виноска з посиланням на закон.
- **Фішка:** «Навігатор справи» — оберіть ситуацію (сімейна, трудова, ДТП, нерухомість, кримінальна, бізнес) → що зробить адвокат, чек-лист документів (можна відмічати, є лічильник) і перші кроки. Кнопка «Обговорити мою ситуацію» переносить тип справи та відмічені документи у форму.
- Живий статус «Зараз відчинено/зачинено» за київським часом, липка панель дій на мобільному (Подзвонити / Записатися / Маршрут).

## Плейсхолдери
Видимі токени обгорнуті в `<span class="ph">…</span>` (жовтий пунктир). Відгуки — картки `ph-card` з міткою «Приклад відгуку».

| Токен / сентинел | Де |
|---|---|
| `[НАЗВА]` | title, OG, JSON-LD, шапка, записка в героїв, «Про практику», футер, текст заявки в `js/main.js` (`BIZ_NAME`) |
| `[МІСТО]` | title/description, JSON-LD, герой (H1 «у [МІСТО]»), «Про практику», контакти, футер. Завжди або після «у», або в називному відмінку |
| `[АДРЕСА]` | description, JSON-LD, записка в героїв, контакти, футер |
| `[ТЕЛЕФОН]` | JSON-LD, шапка (десктоп), великий номер у контактах, футер |
| `[EMAIL]` | JSON-LD, кнопка в контактах, футер |
| `[ГОДИНИ]` | записка в героїв, під таблицею графіка |
| `[ІНСТАГРАМ]` | кнопка Instagram у контактах |
| `[ЦІНА]` | прайс (15 позицій), герой, FAQ, JSON-LD priceRange |
| `[РІК]` | «Про практику» |
| `[ІМ'Я]` | автори відгуків |
| `[ФОП]` | футер (ФОП / РНОКПП або назва юрособи й ЄДРПОУ) |
| `tel:+380000000000` | шапка, герой, контакти, футер, мобільна панель |
| `sms:+380000000000` | `js/main.js` → `CONTACT.sms` |
| `viber://chat?number=%2B380000000000` | контакти, `CONTACT.viber` |
| `https://t.me/username` | контакти, `CONTACT.telegram` |
| `https://wa.me/380000000000` | контакти |
| `https://www.instagram.com/username/`, `https://www.facebook.com/username` | контакти, JSON-LD `sameAs` |
| `mailto:hello@example.com` | контакти, футер, `CONTACT.email` |
| Карта `https://www.google.com/maps?q=…&output=embed`, маршрут `…/maps/dir/?api=1&destination=…` | секція контактів, мобільна панель |
| Графік `<ul data-hours>`: `data-day` (0 = неділя) + `data-hours="09:00-18:00"` | контакти; JSON-LD `openingHours` |

Кожен контакт має атрибут `data-ch="phone|viber|telegram|whatsapp|email|instagram|facebook|sms"` — непотрібний канал можна видалити разом з елементом.

## Фото (Unsplash, замінити на власні)
Посилання закріплені на коміт з фото (`raw.githubusercontent.com/.../<SHA>/img/photos/...`).
- `hero.jpg` — рука з ручкою над документом → **фото адвоката за роботою або кабінету**
- `consult.jpg` — консультація → **портрет адвоката / команда**
- `oldbooks.jpg` — книжкова полиця → фото бібліотеки/кабінету (можна залишити)
- `notebook.jpg` — книги та записник → можна залишити
Решта в `img/photos/` — запасні варіанти (credits у `img/photos/credits.json`).

## Як адаптувати під клієнта (5 кроків)
1. Замініть токени `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ІНСТАГРАМ]`, `[ФОП]` пошуком-заміною (для лідів є `python3 tools/personalize.py lead.json out/`).
2. Замініть сентинели посилань і `CONTACT` у `js/main.js`; видаліть канали, яких у клієнта немає (`data-ch`).
3. Оновіть графік у `<ul data-hours>` і `openingHours` у JSON-LD, а також карту/маршрут.
4. Узгодьте з клієнтом напрями практики (картки навігатора й прайс), ціни `[ЦІНА]`, рік `[РІК]`; замініть приклади відгуків на реальні.
5. Замініть фото героя й «Про практику» на справжні, перевірте сайт на телефоні та що в коді не лишилось `[` … `]`.
