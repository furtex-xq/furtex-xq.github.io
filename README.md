# Smile — демо-сайт стоматології

Шаблон: **stomatolohiia** (стоматологія; фішка — «таймлайн посмішки»).

Заповнено з OpenStreetMap: назва, місто, адреса, телефон.

Форма запису надсилає заявку через: SMS.

Залишилося заповнити (позначені жовтим пунктиром на сторінці):

- `[ІМ'Я]` — ім'я головного лікаря й авторів відгуків
- `[ГОДИНИ]` — графік роботи
- `[РІК]` — рік заснування (блок «Про нас»)
- `[ФОП]` — ФОП / ТОВ і ЄДРПОУ у футері
- `[ЦІНА]` — ціни: головний екран, плани в таймлайні, прайс
- три відгуки з міткою «Приклад відгуку» — замінити на реальні
- фото (зараз стокові з Unsplash) — замінити на фото лікаря й кабінету
- кроки й тривалості в «таймлайні посмішки» та перелік послуг у прайсі — звірити з лікарем
- точний графік по днях (тоді на сайті з'явиться статус «Зараз відчинено/зачинено»)
