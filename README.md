# Шаблон «Бутик одягу» (`butik-odyagu`)

Універсальний односторінковий сайт для бутика одягу в стилі модного журналу. Чистий HTML/CSS/JS без бібліотек і без збирання: `index.html`, `css/style.css`, `js/main.js`, шрифти локально в `fonts/`.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/butik-odyagu/index.html

## Дизайн

- **Шрифти:** Tenor Sans (заголовки, навігація, підписи; великі літери й розрядка) + Spectral 300/400/500 і курсив (основний текст, цитати). Підмножини cyrillic + latin, `font-display: swap`.
- **Палітра:** папір `#efeee9`, другий шар `#e4e2db`, фарба `#131312`, текст `#3a3935`, підписи `#7d7b73`, єдиний акцент — приглушена оливка `#5f613f` (на темному `#a4a37f`). Бурштиновий `#c08317` використовується лише для плейсхолдерів.
- **Композиція:** сайт зверстаний як журнал. Обкладинка з номером випуску й анонсами розділів зі сторінками («с. 02», «с. 03»…). Сітка на 12 колонок асиметрична, заголовки дуже великі.
- **Фішка:** лукбук «Колекція № 01» з горизонтальним скролом. Секція закріплюється на екрані, і при прокрутці вниз образи їдуть убік; великі номери образів і лічильник `01 / 07` з лінією прогресу. Остання картка — «Відкладемо ваш розмір до візиту». Також є стрічка «Нові надходження». На ПК заголовок обкладинки накладається на фото з `mix-blend-mode: difference`: над чорним жакетом літери світлішають.
- **Анімації:** поява обкладинки, м’яка поява блоків при скролі. Якщо в системі ввімкнено `prefers-reduced-motion`, лукбук стає звичайною горизонтальною стрічкою зі snap, а анімації вимикаються.
- **Інше:** статус «Зараз відчинено / зачинено» за київським часом, нижня панель на мобільному (Дзвінок / Примірка / Маршрут), форма запису, яка відкриває Telegram, Viber або email.

## Плейсхолдери й посилання

Видимі дані клієнта позначені як `<span class="ph">[ТОКЕН]</span>` (бурштинове пунктирне підкреслення). Щоб адаптувати сайт, замініть токени пошуком і заміною в усіх файлах (`index.html`, `js/main.js`).

| Токен / посилання | Що це | Де трапляється |
|---|---|---|
| `[НАЗВА]` | назва бутика | title, meta, OG, JSON-LD, шапка, H1, «Про нас», текст заявки з форми (`js/main.js`), карта (title), футер |
| `[МІСТО]` | місто (за замовчуванням Івано-Франківськ) | title, description, JSON-LD, обкладинка, контакти, футер |
| `[АДРЕСА]` | вулиця й номер | description, JSON-LD, контакти, футер |
| `[ТЕЛЕФОН]` | телефон для показу | description, JSON-LD, шапка, меню, контакти, екран «Дякуємо», футер |
| `[EMAIL]` | пошта | JSON-LD, кнопки контактів, футер |
| `[ГОДИНИ]` | короткий графік, напр. «Пн–Сб 10:00–20:00» | JSON-LD `openingHours`, статус до завантаження JS, футер |
| `[ІНСТАГРАМ]` | нік в Instagram | кнопка Instagram у контактах |
| `[ФОП]` | ФОП / ЄДРПОУ | футер |
| `[РІК]` | рік заснування | JSON-LD, «Про нас» |
| `[ЦІНА]` | ціна, завжди у вигляді `від [ЦІНА] грн` | лукбук (7 образів), каталог (8 категорій + 4 послуги), JSON-LD `priceRange` |
| `[ІМ'Я]` | імена (засновниця, автори відгуків) | «Про нас», 3 відгуки |
| `tel:+380000000000` | телефон | шапка, меню, обкладинка, контакти, футер, мобільна панель |
| `viber://chat?number=%2B380000000000` | Viber | контакти, `js/main.js` (форма) |
| `https://wa.me/380000000000` | WhatsApp | контакти |
| `https://t.me/username` | Telegram | контакти, `js/main.js` (форма) |
| `https://www.instagram.com/username/` | Instagram | контакти, JSON-LD `sameAs` |
| `https://www.facebook.com/username` | Facebook | контакти, JSON-LD `sameAs` |
| `mailto:hello@example.com` | email | контакти, футер, `js/main.js` (форма) |
| `https://www.google.com/maps?q=Івано-Франківськ&output=embed` (закодоване) | карта | iframe у контактах; маршрут `google.com/maps/dir/?api=1&destination=…` у мобільній панелі |

Детальний графік — у таблиці в контактах: атрибути `data-days` (0 = неділя … 6 = субота), `data-open`, `data-close` на кожному рядку `<tr>`. Статус «відчинено / зачинено» рахується саме з них, тому видимий текст у клітинках треба змінювати разом з атрибутами.

Відгуки — це **приклади**: картки мають клас `ph-card` і мітку «Приклад відгуку — замініть на реальний». Після заміни на справжні приберіть клас `ph-card` і мітку `.ph-card__label`.

Коли всі токени замінено, обгортки `<span class="ph">…</span>` можна прибрати, а можна просто видалити правило `.ph` у CSS.

## Фото

Демо-фото з Unsplash (Unsplash License). Вони лежать у `img/photos/` і підключені абсолютними URL raw.githubusercontent, закріпленими за комітом. Список фото — у `tools/chosen.json`, автори — в `img/photos/credits.json`.

| Слот | Що на фото | Чим замінити |
|---|---|---|
| `hero` | модель у чорному жакеті оверсайз, біле тло | **обов’язково:** найкраще фото образу бутика (вертикальне) |
| `look1`…`look7` | образи лукбука | **обов’язково:** фото реальних образів, моделей чи манекенів бутика |
| `rack` | вішаки зі світлим одягом | фото вішаків або вітрини бутика |
| `interior` | зал бутика | **обов’язково:** фото залу клієнта |
| `about` | відвідувачка біля вішаків | фото примірювальної чи власниці |
| `detail` | пальто на вішаку, деталь | деталь: тканина, бирка, пакування |

Нові фото: впишіть URL у `tools/chosen.json` і запуште. GitHub Actions завантажить їх у `img/photos/`, після чого оновіть SHA в URL у `index.html`. Інший варіант — покласти файли поруч і вказати відносні шляхи, якщо хостинг звичайний, а не raw.githack.

## Як адаптувати для клієнта — 5 кроків

1. **Дані.** Пошуком і заміною замініть усі токени `[…]` і посилання-заглушки з таблиці вище, зокрема в `js/main.js` (константи `TG`, `VIBER`, `MAIL` і рядок «Заявка з сайту [НАЗВА]»).
2. **Графік і карта.** Виправте рядки таблиці годин (`data-days/open/close` разом із текстом) і `[ГОДИНИ]`. У `src` карти й у посиланні «Маршрут» поставте закодовану адресу бутика.
3. **Фото.** Замініть hero, сім образів лукбука й фото залу на фото клієнта. Перепишіть підписи образів і `alt`.
4. **Асортимент і ціни.** Відредагуйте категорії каталогу, послуги й ціни `від [ЦІНА] грн`. Якщо бутик чоловічий чи змішаний — перепишіть «жіночий одяг» у `<title>`, тексти лукбука й варіанти розміру у формі.
5. **Перевірка.** Замініть приклади відгуків на справжні (приберіть `ph-card`), перевірте сайт на телефоні: дзвінок, Viber, Telegram, форма, карта. Оновіть `og:image`, якщо змінили hero.
