# Шаблон «Масажний кабінет / SPA» (`template/masazh`)

Універсальний односторінковий демо-сайт для масажного кабінету, SPA-кімнати чи приватного масажиста в Івано-Франківську (або будь-якому місті). Чистий HTML/CSS/JS без збірки й без бібліотек, мобільна версія в пріоритеті.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/masazh/index.html

## Дизайн

- **Шрифти:** Alice (заголовки, м'яка «книжкова» антиква) + Ysabeau Office (текст, ціни, кнопки; змінна товщина). Файли woff2 (cyrillic + latin) лежать у `fonts/`.
- **Палітра:** льон `#ece6db`, світлий льон `#f5f1ea`, теплий камінь `#e2d9cb` / `#7a6d5f`, евкаліпт `#5d7b6c`, світлий евкаліпт `#a7beb0`, глибокий евкаліпт `#2f4239`, чорнило `#27231f`. Бурштин `#c4882a` — тільки для плейсхолдерів.
- **Фішка 1 — «дихальне коло»** на головному екрані: фото в колі повільно «дихає» в ритмі 4 с вдих / 6 с видих, кільця розходяться, підпис змінюється «вдих / видих». Цей самий ритм (`--breath: 10s`) повторюють логотип, активна зона на карті тіла і пульс-маркер.
- **Фішка 2 — «карта тіла»:** вигляд зі спини, 8 зон (голова, шия і плечі, спина, поперек, руки, стегна, ноги, стопи). Торкнулися зони — праворуч рекомендовані масажі з часом і ціною; кнопка «Записатися з цією зоною» підставляє масаж і зону у форму.
- Фото обрізані у форму «гальки» (нерівний border-radius). `prefers-reduced-motion` вимикає всі анімації.

## Плейсхолдери

Видимі дані клієнта — у `<span class="ph">[ТОКЕН]</span>` (бурштинове підкреслення). Замініть пошуком-заміною по `index.html` (і `README`, якщо треба).

| Токен / сентинел | Що це | Де трапляється |
|---|---|---|
| `[НАЗВА]` | назва кабінету | `<title>`, og:title, og:site_name, JSON-LD, шапка, футер |
| `[МІСТО]` | місто | eyebrow у hero, «Про кабінет», адреса, футер, JSON-LD |
| `[АДРЕСА]` | вулиця, будинок | контакти, футер, JSON-LD |
| `[ТЕЛЕФОН]` | телефон для показу | шапка, контакти, успіх форми, футер, meta description, JSON-LD |
| `[EMAIL]` | пошта для показу | контакти, футер, JSON-LD |
| `[ГОДИНИ]` | короткий графік текстом (напр. «Пн–Пт 10–21, Сб 10–19») | блок «Графік роботи», JSON-LD `openingHours` |
| `[ІНСТАГРАМ]` | нік в Instagram | кнопка Instagram у контактах |
| `[ФОП]` | ФОП / ЄДРПОУ | футер |
| `[РІК]` | рік початку роботи | «Про кабінет» (текст і факт), JSON-LD |
| `[ЦІНА]` | ціни, завжди як `від [ЦІНА] грн` | прайс (14 позицій + курс), карта тіла (генерується в `js/main.js`), сертифікат, JSON-LD |
| `[ІМ'Я]` | ім'я майстра, авторів відгуків | «Про кабінет», 3 відгуки |
| `.ph-card` + «Приклад відгуку — замініть на реальний» | 3 приклади відгуків | блок «Відгуки» — замінити на реальні або видалити клас і мітку |
| `tel:+380000000000` | номер для дзвінка | шапка, hero, контакти, форма, футер, нижня панель |
| `viber://chat?number=%2B380000000000` | Viber | контакти; `CONTACT.viber` у `js/main.js` |
| `https://t.me/username` | Telegram | контакти; `CONTACT.telegram` у `js/main.js` |
| `https://wa.me/380000000000` | WhatsApp | контакти |
| `https://www.instagram.com/username/` | Instagram | контакти, JSON-LD `sameAs` |
| `https://www.facebook.com/username` | Facebook | контакти, JSON-LD `sameAs` |
| `mailto:hello@example.com` | пошта | контакти, футер; `CONTACT.email` у `js/main.js` |
| `maps?q=Івано-Франківськ` (URL-кодовано) | карта і кнопка «Маршрут» | iframe у контактах, нижня мобільна панель — замінити на адресу клієнта |

**Графік по днях** і статус «Зараз відчинено / зачинено» (за київським часом) беруться з об'єкта `HOURS` на початку `js/main.js` — поправте години там.

## Фото (Unsplash, замінити на фото клієнта)

Фото лежать у `img/photos/` і підключені абсолютними URL raw.githubusercontent.com, закріпленими за комітом (для iPhone Safari). Список і джерела — `tools/chosen.json`, `img/photos/credits.json`.

| Слот | Що на фото | Де | Замінити на |
|---|---|---|---|
| `hero` | каміння на спині | hero-коло, og:image | фірмове фото кабінету / процедури |
| `back` | масаж спини | прайс | фото майстра за роботою |
| `hands` | масаж передпліччя | «Про кабінет» | портрет майстра або руки майстра |
| `stones` | гаряче каміння | «Дрібниці» | кушетка в кабінеті |
| `oil` | олія | «Дрібниці» | олії, якими працюють |
| `candles` | рушник і свічки | «Дрібниці» | рушники/душ кабінету |
| `eucalyptus` | евкаліпт у вазі | «Дрібниці» | куточок з чаєм |
| `herbal` | трав'яні мішечки | сертифікат | фото сертифіката/конверта |
| `face`, `relax`, `therapist` | запасні | не використано | — |

Щоб оновити фото: змінити `tools/chosen.json`, запушити — GitHub Actions завантажить їх у `img/photos/`; потім оновити SHA в URL у `index.html`.

## Як адаптувати під клієнта (5 кроків)

1. Пошук-заміна токенів `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ІНСТАГРАМ]`, `[ФОП]`, `[РІК]`, `[ІМ'Я]`, `[ГОДИНИ]` і сентинелів посилань (телефон, Viber, Telegram, WhatsApp, Instagram, Facebook, email, карта). Оновіть `CONTACT` і `HOURS` у `js/main.js`.
2. Прайс: залиште масажі, які клієнт справді робить, вкажіть тривалість і ціни замість `[ЦІНА]` (також у `ZONES` у `js/main.js` для карти тіла і в `<select>` форми).
3. Замініть фото клієнтськими (див. таблицю), оновіть `og:image`.
4. Відгуки: вставте 3 реальні відгуки, приберіть `ph-card` і мітку «Приклад відгуку». Перевірте тексти «Про кабінет» (30 хв між клієнтами, чай, душ — лише якщо це правда).
5. Видаліть клас `ph` (або стиль `.ph` у `css/style.css`), перевірте на телефоні: форма відкриває месенджер, статус «відчинено» правильний, карта показує адресу.
