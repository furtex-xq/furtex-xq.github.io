# Срібний час — демо-сайт ювелірного магазину й майстерні

Шаблон: **yuveliry** (ювелірний магазин / майстерня).

Заповнено з OpenStreetMap: назва, місто, адреса, Instagram, графік роботи.

Залишилося заповнити (позначено жовтим пунктиром на сторінці):

- `[ІМ'Я]` — ім’я майстра й авторів відгуків
- `[РІК]` — рік заснування (бейдж на головному екрані, підпис фото майстра)
- `[ФОП]` — ФОП / ЄДРПОУ у футері
- `[ЦІНА]` — ціни у вітрині та прайсі майстерні («від … грн»)
- три відгуки з міткою «Приклад відгуку» — замінити на реальні
- фото (зараз стокові з Unsplash) — замінити на фото виробів і майстерні
- категорії вітрини й перелік послуг майстерні — звірити з реальними
