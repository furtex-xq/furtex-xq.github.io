# Шаблон «Грумінг / ветеринарний кабінет» (`hrumin-vet`)

Універсальний односторінковий сайт для грумінг-салону, ветеринарного кабінету або закладу, що поєднує обидва напрями. Чистий HTML/CSS/JS без збірки та бібліотек: `index.html`, `css/style.css`, `js/main.js`, шрифти локально в `fonts/`.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/hrumin-vet/index.html

## Дизайн

- **Шрифти:** Gabriela (заголовки, м'яка «дружня» антиква) + Nunito (текст, variable). Лише файли cyrillic + latin, `font-display: swap`.
- **Палітра:** теплий крем `#F7EEE2`, глибокий бірюзовий `#124A46` / `#1E6F68`, персиковий `#F2A27F` (кнопки, акценти), світлий персик `#FCDCCB`, м'ята `#D5E8E3`, чорнильний текст `#173634`.
- **Фішка:** «Підбір пакета» — власник обирає вид (собака / кіт), розмір і тип шерсті, за бажанням додає огляд ветеринара; праворуч лінійний малюнок тварини змінюється (пес/кіт, розмір), виляє хвостом, і показується пакет: склад, тривалість, «від [ЦІНА] грн». Кнопка «Записатися на цей пакет» заповнює форму запису.
- **Мікроанімація:** хвіст лінійного песика/кота виляє (на головному екрані й у підборі, швидше — коли щось змінили). Фото головного екрана — у формі «адресника» на нашийник. Анімації вимикаються при `prefers-reduced-motion`.
- Статус «Зараз відчинено / зачинено» рахується за київським часом із таблиці годин роботи.

## Токени та посилання

Видимі дані клієнта — у `<span class="ph">[ТОКЕН]</span>` (підсвічені жовтим пунктиром). Після заміни можна прибрати клас `ph` (або просто стиль `.ph` у CSS).

| Токен / посилання | Де зустрічається |
|---|---|
| `[НАЗВА]` | `<title>`, OG, JSON-LD, логотип у шапці й футері, головний екран, «Про нас», копірайт |
| `[МІСТО]` | `<title>`, description, OG, JSON-LD, надзаголовок головного екрана, адреса в контактах і футері |
| `[АДРЕСА]` | JSON-LD, контакти, футер |
| `[ТЕЛЕФОН]` | description, JSON-LD, шапка, блок запису, кнопка «Подзвонити», футер |
| `[EMAIL]` | JSON-LD, контакти, футер |
| `[ГОДИНИ]` | JSON-LD (`openingHours`, напр. `Mo-Fr 09:00-19:00`), статус на головному екрані (до запуску JS) |
| `[ІНСТАГРАМ]` | кнопка Instagram у контактах |
| `[ФОП]` | футер (ФОП / ЄДРПОУ) |
| `[РІК]` | JSON-LD `foundingDate`, головний екран, наліпка «з [РІК]» у «Про нас», копірайт |
| `[ЦІНА]` | прейскурант (грумінг і ветеринарія), факти на головному екрані, підбір пакета, JSON-LD `priceRange` |
| `[ІМ'Я]` | команда в «Про нас», автори відгуків |
| `tel:+380000000000` | шапка, запис, контакти, футер, мобільна панель |
| `viber://chat?number=%2B380000000000` | контакти; атрибут `data-href` каналу Viber у формі |
| `https://t.me/username` | контакти; атрибут `data-href` каналу Telegram у формі |
| `https://wa.me/380000000000` | контакти |
| `https://www.instagram.com/username/` | контакти, JSON-LD `sameAs` |
| `https://www.facebook.com/username` | контакти, JSON-LD `sameAs` |
| `mailto:hello@example.com` | контакти, футер; атрибут `data-href` каналу «Пошта» у формі |
| `https://www.google.com/maps?q=Івано-Франківськ&output=embed` (закодовано) | iframe карти; та сама адреса в кнопках «Маршрут» (`maps/dir/?api=1&destination=…`) |

Також:
- **Години роботи** — таблиця в розділі «Контакти»: змініть текст і атрибути `data-open` / `data-close` (порожні = вихідний). Статус «відчинено/зачинено» читає саме їх.
- **Відгуки** — три приклади з класом `ph-card` і позначкою «Приклад відгуку — замініть на реальний». Замініть текст, ім'я та породу, потім приберіть клас і позначку.
- **Пакети в підборі** — тексти й тривалість у `js/main.js` (об'єкти `SIZES`, `COATS`, `PACKS`).
- Фото підключені абсолютними URL з raw.githubusercontent.com, закріпленими на коміт.

## Як адаптувати під клієнта (5 кроків)

1. Знайти й замінити всі токени `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ГОДИНИ]`, `[ІНСТАГРАМ]`, `[ФОП]`, `[РІК]`, `[ІМ'Я]` в `index.html`.
2. Замінити посилання-заглушки (телефон, Viber, Telegram, WhatsApp, Instagram, Facebook, пошта) і адресу в iframe карти та кнопках «Маршрут» (URL-кодування).
3. Проставити ціни `[ЦІНА]` у прейскуранті, на головному екрані й у підборі; за потреби прибрати непотрібні послуги (напр., ветеринарію, якщо це лише грумінг) і підправити пакети в `js/main.js`.
4. Оновити таблицю годин роботи (`data-open` / `data-close`) і `openingHours` у JSON-LD; замінити три відгуки на реальні, прибрати `ph-card`.
5. Замінити фото на фото клієнта (ті самі пропорції, ~1100–1800 px по ширині), оновити `og:image`, перевірити сайт на телефоні та прибрати стилі `.ph`.
