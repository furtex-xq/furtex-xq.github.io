# Шаблон «Поліграфія / друк» (`polihrafiia`)

Універсальний односторінковий сайт для друкарні, копіцентру чи студії поліграфії: візитки, флаєри, банери, наклейки, друк документів, текстиль і сувеніри. Чистий HTML/CSS/JS, без бібліотек і збірки, мобільна версія в пріоритеті.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/polihrafiia/index.html

## Дизайн

- **Шрифти:** Podkova (заголовки — слеб, як дерев'яний друкарський шрифт, змінна вага 400–800) + Cousine (основний текст — моноширинний, як технологічна карта). Обидва з кирилицею, файли лежать у `fonts/`.
  Початково в брифі був Stick + Cousine: у Stick кирилиця моноширинна з японською шириною і «с» схожа на «е», а запасний Science Gothic має «л» у формі Λ — тому заголовки на Podkova.
- **Палітра:** офсетний білий `#f7f8f6`, чорний K `#121315`, тріада CMYK — cyan `#00a0dc`, magenta `#e5007d`, yellow `#ffe600` — лише як акценти (шкала кольоропроби, тіні кнопок, мітки).
- **Фішка:** «приводка». Заголовок H1 складається з чотирьох шарів C/M/Y/K: на старті вони розʼїхались, а після завантаження шрифту сходяться в одну чорну літеру; коли гортаєте вниз, шари знову трохи розходяться. Мітки приводки біля кожного розділу сходяться при появі на екрані, а мітка в логотипі показує прогрес прокручування.
- **Калькулятор «Порахуйте друк»:** виріб (візитки, флаєри, наклейки, банер) × формат × тираж × 4+0/4+4 → технологічна карта з розкладкою на аркуші SRA3 (реальний розрахунок, скільки виробів уміщається з вильотами 2 мм) або схема банера з люверсами, та ціна «від [ЦІНА] грн». Кнопка переносить параметри в заявку.
- Мітки під обріз довкола «аркушів» (hero, форма), шкала кольоропроби під першим екраном і у футері.

## Плейсхолдери

На сторінці вони позначені пунктиром (`<span class="ph">…</span>`). Одна заміна «знайти й замінити» по `index.html` адаптує сайт.

| Токен / сентинел | Де |
|---|---|
| `[НАЗВА]` | title, OG, JSON-LD, шапка, «Про друкарню», футер, `CONFIG.brand` у `js/main.js` (заголовок повідомлення з форми) |
| `[МІСТО]` | title, description, OG, JSON-LD, H1 («Друк у [МІСТО]»), адреса, футер. Усі входження після «у» — місцевий відмінок (у Івано-Франківську) |
| `[АДРЕСА]` | JSON-LD, hero, контакти, футер |
| `[ТЕЛЕФОН]` | JSON-LD, кнопка в шапці, контакти, повідомлення про успіх форми |
| `[EMAIL]` | JSON-LD, контакти, повідомлення про успіх |
| `[ІНСТАГРАМ]` | контакти (handle з @) |
| `[ГОДИНИ]` | JSON-LD, hero, контакти (до відпрацювання JS), футер |
| `[ФОП]` | футер (ФОП / ЄДРПОУ) |
| `[РІК]` | «Працюємо з [РІК] року», JSON-LD `foundingDate` |
| `[ЦІНА]` | картки продукції, прайс-лист, калькулятор, JSON-LD `priceRange` |
| `[ІМ'Я]` | автори відгуків |
| `tel:+380000000000` | шапка, hero, контакти, мобільна панель, повідомлення форми |
| `viber://chat?number=%2B380000000000` | контакти, `CONFIG.viber` |
| `https://t.me/username` | контакти, `CONFIG.telegram` |
| `https://wa.me/380000000000` | контакти |
| `https://www.instagram.com/username/` | контакти, JSON-LD `sameAs` |
| `https://www.facebook.com/username` | контакти, JSON-LD `sameAs` |
| `mailto:hello@example.com` | контакти, повідомлення форми, `CONFIG.email` |
| `https://example.com/` | canonical, og:url, JSON-LD `url` |
| карта `maps?q=Івано-Франківськ` | iframe Google Maps, посилання «Маршрут» (`maps/dir/?api=1&destination=…`) |

Відгуки — три картки з класом `ph-card` і позначкою «Приклад відгуку — замініть на реальний».

### Дані в `js/main.js` → `CONFIG`
- `hours` — графік по днях (`"0"` неділя … `"6"` субота, `null` — вихідний). З нього будується таблиця й живий статус «Відчинено до 18:00 / Зачинено» за київським часом. `hours: null` — статус і таблиця не показуються, лишається текст `[ГОДИНИ]`.
- `prices` — ціни для калькулятора: `{"vizytky": {"100": 350, "200": 520, …}, "flyery": {…}, "naklejky": {…}, "baner": {…}}` — ціна за базовий формат і односторонній друк; інші формати множаться на коефіцієнт `k`, двосторонній ×1.6. Поки `null` — показується «від [ЦІНА] грн».
- `telegram`, `viber`, `email`, `sms`, `instagramDm` — куди форма відкриває готове повідомлення (порожній рядок — канал вимкнено). Канали у формі — блок `<!--channels-->` в `index.html`.

## Фото (Unsplash, замінити на фото клієнта)

Завантажені в `img/photos/` (через GitHub Actions, `tools/chosen.json`), на сторінці — абсолютні URL raw.githubusercontent, закріплені на коміті.

| Слот | Що зараз | Чим краще замінити |
|---|---|---|
| `hero` | лупа на шкалі кольоропроби CMYK | фото цеху / друкарської машини клієнта або їхньої продукції крупно |
| `cards` | візитки на мармурі | візитки, надруковані клієнтом |
| `flyers` | буклети на чорному тлі | флаєри / буклети клієнта |
| `wide` | широкоформатний принтер із банером | їхній плотер або готовий банер |
| `stickers` | наклейки на жовтому тлі | їхні наклейки / етикетки |
| `screen` | верстат шовкодруку | друк на футболках / чашках клієнта |
| `paper` | стелаж із кольоровим папером | склад паперу, приймальня, вітрина |
| `swatches` | віяло колірних зразків | можна лишити |
| `press`, `cutter` | запасні кадри (на сторінці не використані) | — |

## Як адаптувати під клієнта (5 кроків)

1. Замініть токени `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ІНСТАГРАМ]`, `[ГОДИНИ]`, `[ФОП]`, `[РІК]` в `index.html` (і `CONFIG.brand` у `js/main.js`); після заміни приберіть обгортку `<span class="ph">`.
2. Замініть сентинели посилань (таблиця вище), карту й «Маршрут» — на адресу клієнта; кнопки каналів, яких немає, видаліть разом із блоком `<!--ch:…-->`.
3. Заповніть `CONFIG.hours` за реальним графіком і, якщо клієнт дав ціни, — `CONFIG.prices` та `[ЦІНА]` у картках і прайс-листі (зайві рядки прайсу видаліть).
4. Підставте фото клієнта (слоти вище) і реальні відгуки замість карток `ph-card`.
5. Перевірте на телефоні: форма відкриває повідомлення в потрібному каналі, статус «відчинено» правильний, немає жовтих пунктирів.

Автоматично для лідів: `python3 tools/personalize.py <lead.json> <outdir>`.
