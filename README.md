# Спортарена — демо-сайт

Шаблон: «Спорттовари / велосипеди / прокат» (`template/sport-velo`), акцент: спортивний магазин.

Заповнено з OpenStreetMap: назва, місто, адреса (карта й маршрут), телефон.
Джерело: https://www.openstreetmap.org/node/2753762017

Ще треба заповнити (позначені бурштиновим підкресленням): `[ІМ'Я]`, `[ГОДИНИ]`, `[РІК]`, `[ФОП]`, `[ЦІНА]`.
Тарифи прокату для калькулятора — у `js/main.js` (`RENT`).
Відгуки — приклади (`ph-card`), замініть на реальні. Фото — зі стоку Unsplash, бажано замінити на фото магазину.
