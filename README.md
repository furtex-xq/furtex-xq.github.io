# Шаблон «Оптика» (optyka)

Універсальний односторінковий сайт для оптики / кабінету перевірки зору: перевірка зору, окуляри за рецептом, контактні лінзи, сонцезахисні окуляри, ремонт оправ. Чистий HTML/CSS/JS без бібліотек і збірки.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/optyka/index.html

## Дизайн
- **Шрифти:** Lora (заголовки, курсивні акценти) + Montserrat (текст, підписи). Локально у `fonts/` (cyrillic + latin, variable woff2).
- **Палітра:** музейний білий `#FAFAF8`, холодна сіра панель `#EEF0F3`, глибокий синій `#0F1E3D`, латунь `#A7824A` / `#D6C29A`, лінії `#DDDFE3`.
- **Фішка:** таблиця Сівцева з українськими літерами (Ш Б, М Н К, І М Б Ш…), яка на скролі «наводиться на різкість» рядок за рядком — паралельно змінюються показники пробної лінзи (D) і гостроти зору та підсвічуються кроки перевірки. Друга інтерактивна частина — «Підбір оправи»: форма обличчя → SVG-схема з рекомендованою оправою й порадами.
- Латунні тонкі рамки всередині фото (як у музейній експозиції), кругла «лінза» на головному екрані з табличкою-етикеткою.
- `prefers-reduced-motion`: таблиця показується статично й різко, анімації вимкнено.

## Токени та сентинели
| Токен / сентинел | Де |
|---|---|
| `[НАЗВА]` | `<title>`, OG, JSON-LD, логотип (шапка, футер), `data-biz` у `<body>` (префікс заявки), aria-label логотипа, копірайт |
| `[МІСТО]` | title / description / OG («у [МІСТО]»), JSON-LD, eyebrow на головному, контакти, футер |
| `[АДРЕСА]` | головний екран, контакти, футер, JSON-LD |
| `[ТЕЛЕФОН]` | шапка, контакти (великий номер), футер, JSON-LD |
| `[EMAIL]` | контакти, футер, JSON-LD |
| `[ІНСТАГРАМ]` | контакти (handle) |
| `[ГОДИНИ]` | підсумок графіка, JSON-LD `openingHours` |
| `[ЦІНА]` | прайс (усі вкладки), етикетка на головному, «Про нас», JSON-LD `priceRange` |
| `[РІК]` | «Про нас» |
| `[ІМ'Я]` | фахівець у «Про нас», автори відгуків |
| `[ФОП]` | футер |
| `.ph-card` | 3 приклади відгуків з міткою «Приклад відгуку — замініть на реальний» |
| `tel:+380000000000` | шапка, кнопки дзвінка, контакти, футер, моб. панель |
| `sms:+380000000000` | форма: канал SMS |
| `viber://chat?number=%2B380000000000` | контакти, форма |
| `https://wa.me/380000000000` | контакти |
| `https://t.me/username` | контакти, форма |
| `https://www.instagram.com/username/` | контакти, форма (Instagram Direct: текст копіюється в буфер), JSON-LD |
| `https://www.facebook.com/username` | контакти, JSON-LD |
| `mailto:hello@example.com` | контакти, футер, форма |
| Google Maps `?q=Івано-Франківськ` | iframe карти, кнопка «Прокласти маршрут», моб. панель «Маршрут» |
| графік `data-hours` у `<ul data-hours-list>` | таблиця годин + статус «Зараз відчинено/зачинено» (за київським часом) |

Елементи каналів зв'язку мають `data-ch="phone|viber|telegram|whatsapp|instagram|facebook|email|sms"` — їх легко прибрати, якщо каналу немає.

## Фото (Unsplash, замінити на фото клієнта)
Усі фото — абсолютні URL на `raw.githubusercontent.com`, закріплені за комітом. Варто замінити: `hero` (вітрина оптики — найважливіше), `device` (перевірка зору, блок «Про нас»), `exam` (форма запису), `store` (інтер'єр), `frames`, `sun`, `contacts`, `book` (вітрина). Список: `tools/chosen.json`, ліцензії: `img/photos/credits.json`.

## Як адаптувати для клієнта (5 кроків)
1. Замініть токени `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ІНСТАГРАМ]`, `[ФОП]` пошуком-заміною та приберіть обгортки `<span class="ph">`.
2. Підставте реальні посилання замість сентинелів; канали, яких немає, видаліть разом з елементом `data-ch` (і відповідний пункт у формі).
3. Оновіть графік у `<ul data-hours-list>` (`data-hours="10:00-19:00"`, порожньо = вихідний), `[ГОДИНИ]` і JSON-LD `openingHours`; карта й маршрут — на адресу клієнта.
4. Заповніть прайс (`[ЦІНА]`), рік, ім'я фахівця; звірте перелік послуг (діти, контактні лінзи, ремонт) з реальним.
5. Замініть фото на власні фото оптики, відгуки — на реальні (приберіть `ph-card` і мітку), перевірте сайт на телефоні.

Для лідів є генератор: `python3 tools/personalize.py <lead.json> <outdir>`.
