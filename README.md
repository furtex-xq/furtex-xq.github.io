# I.F. you dance — демо нового сайту (бета)

Танцювальна студія I.F. you dance, с. Вовчинець (Івано-Франківськ), вул. Європейська, 1. Односторінковий статичний сайт (HTML/CSS/JS), мова українська.

- `index.html`, `css/style.css`, `js/main.js`
- `js/vendor/` — GSAP 3.12.5 + ScrollTrigger, Lenis (локально, без CDN)
- `fonts/` — Oswald, Playfair Display Italic, Rubik (кирилиця + латиниця)
- `img/photos/` — тимчасові фото з Unsplash (Unsplash License), список у `credits.json`
- `tools/` + `.github/workflows/ifyoudance-photos.yml` — завантаження фото через GitHub Actions

Фішка: закріплений блок «вісімка» (рахунок 1–8 під час скролу, на кожен рахунок новий напрямок), метроном 5-6-7-8 на першому екрані, підбір напрямку за 3 кліки з автозаповненням форми, фільтр розкладу, мотив розмітки-хрестиків з танцзали.

Заглушки (жовта крапка або «демо»): розклад, ціни, години роботи, Viber, ФОП/ЄДРПОУ, усі фото; форма поки без відправки (після запуску — Telegram/email).
