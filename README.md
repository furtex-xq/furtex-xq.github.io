# Перукарня Христина — демо-сайт

Шаблон: **salon-krasy** (салон краси, ар-деко; Poiret One + Didact Gothic), з вкладкою «Волосся».

Заповнено з OpenStreetMap (https://www.openstreetmap.org/node/6216158386): назва, місто, адреса, телефон, графік роботи (і статус «відчинено/зачинено»), карта й маршрут.

Видалено кнопки й варіанти зв'язку, яких немає в даних (Viber, Telegram, WhatsApp, email, Instagram, Facebook).

## Залишилось заповнити

- `[ІМ'Я]`
- `[РІК]`
- `[ФОП]`
- `[ЦІНА]`
- реальні відгуки (картки з позначкою «Приклад відгуку»)
- фото клієнта, зокрема пари «до / після»
- ціни й перелік послуг під салон
