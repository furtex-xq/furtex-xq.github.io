# Шаблон «Фотостудія / фотограф» (`template/fotostudiia`)

Односторінковий сайт для фотостудії чи приватного фотографа: портрет, сімейна зйомка, love story, фото на документи, оренда залу. Чистий HTML/CSS/JS без збірки і без бібліотек.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/fotostudiia/index.html

## Дизайн
- **Напрям:** «фотолабораторія» — майже чорна темна кімната, червоне світло, фотопапір, рамки плівки з жовтогарячим маркуванням кадрів.
- **Шрифти:** Prosto One (заголовки) + Roboto Mono (текст), локально у `fonts/` (кирилиця + латиниця).
- **Палітра:** `#121011` темна кімната · `#c22b1f` / `#e5452f` червоне світло · `#ebe5d9` фотопапір · `#d79a3c` маркування плівки · `#1d1a19` чорнило на папері.
- **Фішка:** «Аркуш контактів» — 12 кадрів на смугах плівки з перфорацією, улюблені обведені «червоним олівцем», а лупа збільшує кадр під курсором (на телефоні — торкніться кадру і ведіть пальцем). Додатково: головне фото «проявляється» під червоним світлом під час завантаження, а лампа біля логотипа світиться, коли студія відчинена (за київським часом).
- **Пакети:** вкладки Портрет / Сімейна / Love story / Документи / Оренда залу — кнопка «Обрати…» підставляє зйомку у форму запису.

## Токени та посилання-заглушки
| Токен / заглушка | Де |
|---|---|
| `[НАЗВА]` | `<title>`, OG, JSON-LD, логотип, «Про студію», футер, `CONFIG.name` у `js/main.js` |
| `[МІСТО]` | title, description, OG, JSON-LD, hero, «Про студію», адреса, футер (завжди після «у» або в називному відмінку) |
| `[АДРЕСА]` | JSON-LD, блок адреси біля мапи, футер |
| `[ТЕЛЕФОН]` | description, JSON-LD, шапка, контакти |
| `[EMAIL]` | JSON-LD, контакти |
| `[ІНСТАГРАМ]` | контакти (handle) |
| `[ГОДИНИ]` | JSON-LD `openingHours`, підсумок годин роботи |
| `[ФОП]` | футер |
| `[РІК]` | «Про студію» |
| `[ЦІНА]` | ціни всіх пакетів (`від [ЦІНА] грн`), JSON-LD `priceRange` |
| `[ІМ'Я]` | фотограф у «Про студію», автори відгуків |
| `tel:+380000000000` | шапка, hero, контакти, мобільна панель |
| `viber://chat?number=%2B380000000000`, `https://wa.me/380000000000`, `https://t.me/username` | контакти; у формі — `CONFIG` у `js/main.js` |
| `https://www.instagram.com/username/`, `https://www.facebook.com/username` | контакти, JSON-LD `sameAs`; `CONFIG.instagram` для Direct |
| `mailto:hello@example.com` | контакти; `CONFIG.email` |
| `maps?q=Івано-Франківськ&output=embed`, `maps/dir/?api=1&destination=…` | мапа, кнопка «Прокласти маршрут», мобільна панель |

Графік: `HOURS` у `js/main.js` (`0` = неділя, `[10, 20]` = 10:00–20:00, `null` = вихідний). `HOURS = null` ховає таблицю і статус «відчинено».
Канали в розмітці мають `data-ch="tel|tg|viber|wa|sms|ig|fb|mail"` — непотрібні можна просто видалити (у формі теж).
Відгуки — приклади з класом `ph-card` і позначкою «Приклад відгуку — замініть на реальний».

## Фото (Unsplash, замінити на фото клієнта)
`img/photos/*.jpg`, на сторінці — абсолютні посилання на raw.githubusercontent із закріпленим комітом.
- `hero` — головне фото (найкраще — зал студії або бекстейдж);
- `studio`, `studio2` — фото залу для «Про студію» і пакета «Оренда залу»;
- `portrait1–4`, `family1–2`, `love1–2`, `session`, `camera` — портфоліо для «Аркуша контактів» і пакетів.
Найважливіше попросити в клієнта: 12 найкращих робіт, 2–3 фото залу, фото фотографа.

## Як адаптувати для клієнта
1. Замініть токени `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ІНСТАГРАМ]`, `[ГОДИНИ]`, `[ФОП]`, `[РІК]`, `[ІМ'Я]` і зніміть обгортку `<span class="ph">`.
2. Замініть посилання-заглушки (tel, месенджери, соцмережі, email, мапа) і `CONFIG` у `js/main.js`; видаліть елементи з `data-ch` для каналів, яких у клієнта немає.
3. Впишіть реальний графік у `HOURS` і ціни замість `[ЦІНА]`; поправте склад пакетів (тривалість, що входить).
4. Замініть фото на роботи й зал клієнта (той самий розмір/пропорції — верстка не зламається), оновіть `alt`.
5. Вставте реальні відгуки замість карток `ph-card`, перевірте сайт на телефоні та в `og:image`.

Для лідів є генератор: `python3 tools/personalize.py lead.json outdir/`.
