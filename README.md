# Гармонія — демо-сайт

Шаблон: «Масажний кабінет / SPA» (`template/masazh`).

Заповнено з OpenStreetMap: назва, місто, адреса, телефон, графік роботи (таблиця і статус «відчинено»).
Джерело: https://www.openstreetmap.org/node/5872317011

Ще треба заповнити (позначені бурштиновим підкресленням): `[ІМ'Я]`, `[РІК]`, `[ФОП]`, `[ЦІНА]`.
Відгуки — приклади (`ph-card`), замініть на реальні. Фото — зі стоку Unsplash, бажано замінити на фото кабінету.
