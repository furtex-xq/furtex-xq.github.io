# Шаблон «Салон краси» (salon-krasy)

Універсальний односторінковий демо-сайт для салону краси: косметологія, манікюр і педикюр, брови й вії, догляд за тілом. Чистий HTML/CSS/JS без збирання й без CDN, усе локально (крім фото, див. нижче).

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/salon-krasy/index.html

## Дизайн

- **Напрям:** ар-деко для б'юті-салону — шампань, глибокий чорний, лінії кольору рожевого золота. Арки (фото в арочних рамках), ромби як маркери, віяло променів у hero.
- **Шрифти:** Poiret One (заголовки, ар-деко) + Didact Gothic (текст). Обидва з кирилицею, файли `fonts/*.woff2` (cyrillic, cyrillic-ext, latin, latin-ext).
- **Палітра:** `#141112` чорний · `#f3e9df` шампань · `#e8d8c6` глибока шампань · `#ecdcd3` пудровий · `#b67b63` рожеве золото · `#d9a690` світле рожеве золото · `#8f5a45` темне рожеве золото.
- **Фішка:** слайдер «до / після» в арочній рамці з ромбоподібною ручкою (перетягування пальцем/мишею, клавіатура, перемикач прикладів: манікюр / чистка обличчя / вії) + меню послуг за категоріями (Обличчя, Нігті, Брови й вії, Тіло) з прайсом у стилі «карти» з крапковими лідерами.
- Статус «Зараз відчинено / зачинено» за київським часом, липка мобільна панель (Дзвінок / Записатися / Маршрут), м'які появи при скролі (вимикаються при `prefers-reduced-motion`).

## Токени та сентинели

Видимі токени обгорнуті в `<span class="ph">…</span>` (жовте пунктирне підкреслення). Після заміни можна прибрати клас `ph` або видалити стиль `.ph` у `css/style.css`.

| Токен / сентинел | Де зустрічається |
|---|---|
| `[НАЗВА]` | `<title>`, OG, JSON-LD, лого в шапці, «Про салон», футер |
| `[МІСТО]` | `<title>`, description, H1 (кікер), JSON-LD, контакти, футер |
| `[АДРЕСА]` | hero (факти), контакти, футер, JSON-LD |
| `[ТЕЛЕФОН]` | шапка (≥1180px), контакти, екран успіху форми, OG description, JSON-LD |
| `[EMAIL]` | контакти, JSON-LD |
| `[ГОДИНИ]` | hero (факти), контакти, JSON-LD `openingHours` |
| `[ІНСТАГРАМ]` | кнопка Instagram у контактах |
| `[ФОП]` | футер (ФОП / ЄДРПОУ) |
| `[РІК]` | hero (факти), «Про салон», JSON-LD |
| `[ЦІНА]` | усі рядки прайсу (`від [ЦІНА] грн`), JSON-LD `priceRange` |
| `[ІМ'Я]` | список майстрів, підписи відгуків |
| `.ph-card` + «Приклад відгуку — замініть на реальний» | 3 картки відгуків |
| `.ph-note` «Демонстрація…» | блок «до / після» |
| `tel:+380000000000` | шапка, hero, контакти, екран успіху, мобільна панель |
| `viber://chat?number=%2B380000000000` | FAQ, контакти, форма (`data-viber`) |
| `https://t.me/username` | FAQ, контакти, форма (`data-tg`) |
| `https://wa.me/380000000000` | контакти |
| `https://www.instagram.com/username/` | контакти, JSON-LD `sameAs` |
| `https://www.facebook.com/username` | контакти, JSON-LD `sameAs` |
| `mailto:hello@example.com` | контакти, форма (`data-mail`) |
| `https://www.google.com/maps?q=Івано-Франківськ&output=embed` (URL-кодовано) | iframe карти; той самий запит у кнопці «Маршрут» (`maps/dir/?api=1&destination=…`) |

**Графік для статусу «відчинено/зачинено»** — атрибут `data-hours` у `#status` (контакти): ключі 0–6 = Нд–Сб, значення `["09:00","20:00"]` або `null` (вихідний).

## Фото (замінити на фото клієнта)

Фото з Unsplash (Unsplash License), лежать у `img/photos/`, у HTML підключені абсолютними URL raw.githubusercontent, закріпленими на коміті `89839cf…`. Список — `tools/chosen.json`, авторство/розміри — `img/photos/credits.json`.

| Слот | Де | Що попросити в клієнта |
|---|---|---|
| `hero` | hero-арка, og:image | процедура в салоні (косметолог за роботою), горизонтальне |
| `face2` | вкладка «Обличчя» | догляд за обличчям, вертикальне |
| `nails2` | вкладка «Нігті» | роботи майстра манікюру |
| `lashes` | вкладка «Брови й вії»; «до/після» (Вії) | брови/вії крупним планом |
| `body` | вкладка «Тіло» | засоби або процедура для тіла |
| `nails3`, `face` | «до / після» | **реальні пари фото до і після** (зараз демонстрація: «до» = те саме фото з фільтром) |
| `interior`, `serum` | «Про салон» | інтер'єр салону, деталь (косметика, робоче місце) |
| `brows`, `nails`, `interior2` | запасні | — |

Пари «до / після» задаються в `js/main.js` (масив `sets`): для реальних пар додайте окремі файли «до» і «після» та приберіть CSS-фільтр `.ba__img--before`.

## Як адаптувати під клієнта (5 кроків)

1. Знайти й замінити всі токени `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ГОДИНИ]`, `[ІНСТАГРАМ]`, `[ФОП]`, `[РІК]`, `[ІМ'Я]` (у т. ч. в `<head>` і JSON-LD).
2. Замінити сентинели посилань (телефон, Viber, Telegram, WhatsApp, Instagram, Facebook, email) і місто в URL карти та «Маршруту»; оновити `data-hours`.
3. Вписати ціни замість `[ЦІНА]`, прибрати/додати рядки прайсу під реальні послуги.
4. Завантажити фото клієнта в `img/photos/` (ті самі імена) або змінити URL; підставити реальні пари «до / після»; замінити відгуки реальними й прибрати `ph-card` та мітки.
5. Видалити стилі `.ph`, `.ph-card`, `.ph-label`, `.ph-note`, перевірити сайт на телефоні й ПК.
