# Шаблон «Бар / паб» — Ansaro

Універсальний односторінковий сайт для пабу, пивного бару чи крафтового бару. Статичний HTML/CSS/JS без бібліотек і без збирання: `index.html`, `css/style.css`, `js/main.js`, шрифти локально в `fonts/`.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/bar/index.html

## Дизайн

- **Шрифти:** Alumni Sans (заголовки, вузький гротеск з характером пивних етикеток і крейдових дощок) + Bitter (основний текст, слеб-серіф). Обидва з кирилицею, змінна вага, `font-display: swap`.
- **Палітра:** темний дуб `#1b130d` / `#261a11`, стаут `#120c08`, латунь `#c79a55`, бурштинове пиво `#eba63a`, піна `#f3eadb`, крейдова дошка `#1e2521` з крейдою `#ece7da`.
- **Фішка:** крейдова дошка «На кранах сьогодні» в дерев’яній рамі. Коли дошка з’являється на екрані, всі келихи по черзі наливаються кольором свого сорту з піною. Торкніться сорту, і великий келих наллє саме його та покаже опис і міцність. Друга фішка — **афіша тижня**: 7 колонок із фільтром (музика / квізи / спорт / інше), сьогоднішній день підсвічено за київським часом, а кнопка «Стіл на цей вечір» підставляє в форму бронювання найближчу дату, час і назву події.
- Також є статус «Зараз відчинено / зачинено» за київським часом (у шапці та в контактах), арка-фото в героблоці з плашкою «Сьогодні в пабі», підставки під келихи як картки відгуків і мобільна панель дій «Подзвонити / Стіл / Маршрут».

## Плейсхолдери

Видимі дані клієнта — у `<span class="ph">[ТОКЕН]</span>` (бурштинове підкреслення). Замінюйте пошуком-заміною по всьому `index.html`.

| Токен / сентинел | Де трапляється |
|---|---|
| `[НАЗВА]` | title, meta, OG, JSON-LD, логотип, H1, «Про паб», підпис, title карти, футер |
| `[МІСТО]` | title, description, JSON-LD, H1 (кікер), контакти, футер (пишеться в називному відмінку: «у місті [МІСТО]», «[АДРЕСА], [МІСТО]») |
| `[АДРЕСА]` | meta description, JSON-LD, факти в героблоці, контакти, футер |
| `[ТЕЛЕФОН]` | JSON-LD, героблок, бронювання, FAQ, кнопка «Подзвонити» |
| `[EMAIL]` | JSON-LD, кнопка Email у контактах |
| `[ГОДИНИ]` | JSON-LD (`openingHours`, напр. `Mo-Th 16:00-24:00`), героблок, текст статусу до запуску JS |
| `[ІНСТАГРАМ]` | під дошкою меню, кнопка Instagram |
| `[ФОП]` | футер (ФОП / ЄДРПОУ) |
| `[РІК]` | «Про паб» — рік відкриття |
| `[ЦІНА]` | усі ціни: крани, бар, кухня, дегустаційний сет, пакети свят, JSON-LD `priceRange` (формат `від [ЦІНА] грн`) |
| `[ІМ'Я]` | засновник у «Про паб», автори відгуків |
| `tel:+380000000000` | героблок, бронювання, FAQ, контакти, мобільна панель |
| `viber://chat?number=%2B380000000000` | контакти, `data-viber` форми |
| `https://t.me/username` | контакти, FAQ, `data-tg` форми |
| `https://wa.me/380000000000` | контакти |
| `https://www.instagram.com/username/` | меню, контакти, JSON-LD `sameAs` |
| `https://www.facebook.com/username` | контакти, JSON-LD `sameAs` |
| `mailto:hello@example.com` | контакти, `data-mail` форми |
| `https://www.google.com/maps?q=%D0%86...` (Івано-Франківськ) | iframe карти, «Прокласти маршрут», мобільна панель — замініть `q=` на закодовану адресу закладу |

**Години роботи** для статусу «відчинено/зачинено» задаються атрибутами `data-open` / `data-close` у списку `[data-hours]` у блоці контактів (закриття після півночі, напр. `02:00`, підтримується). Видимий текст рядків теж оновіть.

**Відгуки** — це приклади (картки `.ph-card` з позначкою «Приклад відгуку — замініть на реальний»). Підставте справжні відгуки, приберіть клас `ph-card` і `<span class="ph-card__label">`.

**Афіша** — події в `<ol class="week">`: кожен `<article class="ev" data-type="music|quiz|sport|other">`. Змініть назви, час і дні під реальний розклад закладу.

**Сорти на кранах** — кожен `<button class="tap">` має `style="--beer:#колір;--head:#колір піни"`, `data-note` (опис для великого келиха) і `data-meta` (міцність / IBU).

## Фото (Unsplash, замінити на фото клієнта)

Фото лежать у `img/photos/` і підключені абсолютними URL raw.githubusercontent.com, закріпленими на коміті (так вони коректно вантажаться в iPhone Safari через githack).

| Слот | Що на фото | Чим замінити |
|---|---|---|
| `hero` | пивні крани й келих | крани / барна стійка закладу |
| `woodbar` | дерев’яна барна стійка | інтер’єр закладу |
| `pour` | наливання пива | бармен закладу за роботою |
| `music` | музикант на сцені | сцена / концерт у закладі |
| `friends` | гості в залі | повний зал у вечір п’ятниці |
| `bar` | підсвічені полиці з пляшками | бар закладу |
| `snacks`, `fish`, `mugs` | крильця, фіш-енд-чіпс, келихи | страви й пиво закладу |

Слоти `taps`, `interior`, `music2`, `food`, `cocktail` завантажені, але не використовуються (запасні).

## Як адаптувати під клієнта (5 кроків)

1. Пошуком-заміною замініть усі токени `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ІНСТАГРАМ]`, `[ФОП]`, `[РІК]`, `[ГОДИНИ]`, `[ІМ'Я]` і сентинели посилань (телефон, Viber, Telegram, WhatsApp, Instagram, Facebook, email, `q=` карти).
2. Оновіть меню: сорти на кранах (назви, кольори `--beer`, описи), бар і кухню, ціни замість `[ЦІНА]`. Для статусу «відчинено» відредагуйте `data-open`/`data-close`.
3. Перепишіть афішу тижня під реальні події закладу (квізи, концерти, трансляції).
4. Замініть фото на справжні: додайте файли в `img/photos/` і оновіть URL у `index.html` (або залиште абсолютні raw-URL на новий коміт). Стежте, щоб `width`/`height` відповідали пропорціям.
5. Вставте реальні відгуки (приберіть `ph-card`), перевірте сайт на телефоні й надішліть клієнтові посилання.
