# IPeople — демо-сайт

Шаблон: **remont-telefoniv** (ремонт телефонів і техніки).

## Заповнено з OpenStreetMap

- назва
- місто
- адреса
- телефон
- графік роботи
- точка на карті

Viber, Telegram і WhatsApp невідомі — кнопки прибрано. Невідомі канали теж прибрано.

## Що ще заповнити

- `[ІМ'Я]` — імена майстра й авторів відгуків
- `[РІК]` — рік заснування («Про нас»)
- `[ФОП]` — ФОП / ЄДРПОУ у футері
- `[ЦІНА]` — ціни в прайсі, «рентгені», калькуляторі й hero (`від [ЦІНА] грн`)
- Приклади відгуків (картки з міткою «Приклад відгуку») — замінити на реальні.
- Фото з Unsplash — бажано замінити на фото майстерні.
