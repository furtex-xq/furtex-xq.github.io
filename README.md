# Clubhouse — демо нового сайту (бета)

Мотоготель Clubhouse, Івано-Франківськ, вул. Тисменицька 220а/2. Статичний односторінковий сайт (HTML/CSS/JS), мова українська.

- `index.html`, `css/style.css`, `js/main.js`
- `js/vendor/` — GSAP 3.12.5 + ScrollTrigger, Lenis (локально, без CDN)
- `fonts/` — Oswald, Manrope (кирилиця + латиниця)
- `img/photos/` — фото самого готелю з публічного лістингу (hotelmix/Booking), до запуску замінити на оригінали від власника
- `tools/` + `.github/workflows/clubhouse-photos.yml` — завантаження фото через GitHub Actions

Фішка: дошка з ключами на шкіряних брелоках — «оберіть свій ключ», кожен ключ відкриває тип номера. Плюс пунктирна «дорожня розмітка» як індикатор прокрутки, горизонтальна стрічка «гараж» і спідометри рейтингів.

Заглушки (позначені жовтим): ціни, Viber, ФОП/ЄДРПОУ, відгуки (переклад з Booking), відправка заявки (зараз SMS/дзвінок).
