# Burger — демо-сайт

Шаблон: **fastfud** (піца / бургери / фастфуд) від Ansaro. Акцент: бургери.

Заповнено з OpenStreetMap: назва, місто, адреса, телефон, Instagram, години роботи (з живим статусом «відчинено/зачинено»), карта й маршрут.
Viber, Telegram і WhatsApp прибрано (невідомі). Форма замовлення надсилає заявку через: SMS, Instagram Direct.

Ще треба заповнити (позначені бурштиновим підкресленням): [ІМ'Я], [РІК], [ФОП], [ЦІНА].
Відгуки — приклади (картки з позначкою «Приклад відгуку»), замініть на реальні. Меню, умови доставки й фото — типові, уточніть у закладу.
