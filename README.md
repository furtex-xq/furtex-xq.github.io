# Nail art studio Легкун Вікторія — демо-сайт

Шаблон: **salon-krasy** (салон краси, ар-деко; Poiret One + Didact Gothic).

Заповнено з OpenStreetMap (https://www.openstreetmap.org/node/5256742090): назва, місто, адреса, телефон, карта й маршрут.

Видалено кнопки й варіанти зв'язку, яких немає в даних (Viber, Telegram, WhatsApp, email, Instagram, Facebook).

## Залишилось заповнити

- `[ІМ'Я]`
- `[ГОДИНИ]`
- `[РІК]`
- `[ФОП]`
- `[ЦІНА]`
- реальні відгуки (картки з позначкою «Приклад відгуку»)
- фото клієнта, зокрема пари «до / після»
- ціни й перелік послуг під салон
