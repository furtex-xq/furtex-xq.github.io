# FineLine — демо-сайт

Косметологічний центр, Івано-Франківськ. Основа: template/salon-krasy, перефарбовано в синій колір їхнього логотипу.

Усі дані взято з їхнього чинного сайту fineline.ua (13.11.2026): адреса, телефон, email, графік, соцмережі, ліцензія, ЄДРПОУ, команда, ціни (лазер, обличчя, ін'єкції, кріоліполіз, масаж), акційні пакети, Beauty Pass, гарантія 120 днів, кешбек 10%, FAQ, 3 відгуки.

Фото — їхні власні з fineline.ua: `tools/site_photos.json` → workflow `.github/workflows/site-photos.yml` завантажує їх у `img/site/`. На сторінці вони підключені абсолютними URL raw.githubusercontent.com з SHA коміту.

Уточнити в клієнта: ціни подології й трихології (на сайті їх немає), фото команди та інтер'єру, OSM-адреса «Грушевського 22а» vs сайт «Страчених націоналістів 7а».
