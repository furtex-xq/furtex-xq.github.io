# Лофт — демо-сайт

Шаблон: «Фотостудія / фотограф» (`template/fotostudiia`).

Заповнено з OpenStreetMap: назва, місто, адреса, Facebook.
Джерело: https://www.openstreetmap.org/node/5310657209

Ще треба заповнити (позначені бурштиновим підкресленням): `[ІМ'Я]`, `[ГОДИНИ]`, `[РІК]`, `[ФОП]`, `[ЦІНА]`.
Відгуки — приклади (`ph-card`), замініть на реальні. Фото — зі стоку Unsplash, замініть на портфоліо і фото залу студії.
