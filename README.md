# Шаблон «Ресторан» (`template/restoran`)

Універсальний односторінковий демо-сайт для ресторану (Івано-Франківськ і не тільки). Чистий HTML/CSS/JS без бібліотек і без збірки: `index.html`, `css/style.css`, `js/main.js`, шрифти локально у `fonts/`.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/restoran/index.html

## Дизайн

- **Шрифти:** Oranienbaum (дідона з високим контрастом, заголовки й назви страв) + Mulish (variable, основний текст). Кирилиця + латиниця, `font-display: swap`.
  Gloock із брифу не має базової кирилиці (лише cyrillic-ext), тому замінено на Oranienbaum — найближчий за характером.
- **Палітра:** майже чорний з винним відтінком `#120c0d`, бордо `#4a121c`, кларет `#7a2232`, золото свічки `#d6a75c` / `#f0cf8e`, «папір меню» `#efe4d2`, приглушений `#ab9a8c`.
- **Фішка:** інтерактивна карта страв із вкладками (Закуски / Гаряче / Риба / Десерти / Вино та бар). Під час прокручування страва навпроти «лінії свічки» підсвічується золотом, решта притухає, а ліворуч (на телефоні — зверху, закріплено) у рамці меню змінюється фото й назва страви. Типографіка меню — з крапковими лідерами до ціни.
- Інше: рамка-паспарту на першому екрані, статус «Зараз відчинено / зачинено» за київським часом, форма бронювання як «квиток» (дата → доступні слоти часу, кількість гостей), липка нижня панель на телефоні (Дзвінок / Забронювати / Маршрут). Анімації вимикаються при `prefers-reduced-motion`.

## Токени (текст у `<span class="ph">…</span>`)

Замінюйте пошуком і заміною в `index.html` (у `<head>` і JSON-LD ті самі токени). Після заміни можна прибрати клас `ph` (або просто видалити правило `.ph` у CSS).

| Токен | Що це | Де трапляється |
|---|---|---|
| `[НАЗВА]` | назва ресторану | title, description, OG, JSON-LD, логотип у шапці, H1, футер (×2); також підставляється в текст заявки з форми |
| `[МІСТО]` | місто | title, description, OG, JSON-LD, надзаголовок першого екрана, контакти, футер |
| `[АДРЕСА]` | вулиця, будинок | description, JSON-LD, низ першого екрана, контакти, футер |
| `[ТЕЛЕФОН]` | телефон для показу | description, JSON-LD, мобільне меню, блок бронювання, контакти, футер |
| `[EMAIL]` | пошта для показу | JSON-LD, контакти, футер |
| `[ГОДИНИ]` | короткий підсумок годин («щодня 12:00–23:00») | JSON-LD `openingHours`, перший екран (до запуску JS), блок годин, контакти, футер |
| `[ІНСТАГРАМ]` | @нікнейм | кнопка Instagram у контактах |
| `[ФОП]` | ФОП / ТОВ, ЄДРПОУ | футер |
| `[РІК]` | рік відкриття | «Про нас», JSON-LD `foundingDate` |
| `[ЦІНА]` | будь-яка ціна | кожна позиція меню, «середній чек від», банкет «від … грн на гостя» (у меню та FAQ) |
| `[ІМ'Я]` | імена людей | шеф у «Про нас», автори 3 відгуків |

Відгуки — приклади: картки мають клас `ph-card` і мітку «Приклад відгуку — замініть на реальний». Замініть тексти на справжні й видаліть `<span class="ph-label">`.

### Розклад для статусу «відчинено»

Атрибут `data-schedule` на `<div id="hours">`: `{"1":"12:00-23:00", … ,"7":"12:00-22:00"}` (1 = понеділок). Закриття після півночі пишіть як `"18:00-02:00"`, вихідний — `""`. З нього ж будуються таблиця годин і слоти часу у формі (останній запис за 1,5 год до закриття).

## Фото (Unsplash, ілюстративні — замінити на фото клієнта)

Лежать у `img/photos/`, на сторінці підключені абсолютними URL raw.githubusercontent, закріпленими за SHA коміту (щоб працювало в iPhone Safari через raw.githack). Нові фото: покладіть у `img/photos/`, закомітьте й оновіть SHA в `index.html`.

| Файл | Де | Що попросити в клієнта |
|---|---|---|
| `hero.jpg` | перший екран, og:image | вечірня зала з теплим світлом, горизонтально |
| `chef.jpg` | «Про нас» | шеф або кухар за подачею страви |
| `hall.jpg` | «Про нас» | інтер’єр зали, вертикально |
| `salad.jpg`, `plate.jpg` | меню: закуски, риба | фото фірмових закусок |
| `steak.jpg`, `meat.jpg` | меню: гаряче | фото гарячих страв |
| `fish.jpg` | меню: риба | рибна страва |
| `dessert.jpg` | меню: десерти | фірмовий десерт |
| `wine.jpg` | меню: вино та бар | вино / бар / коктейль |
| `candles.jpg` | «Для якого вечора» | сервірований стіл, банкет |

Щоб додати позицію меню, скопіюйте `<li class="dish" data-spot="…">`; `data-spot` — ключ фото з `.spot__img[data-key]`.

## Як адаптувати під клієнта (5 кроків)

1. Замініть токени `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ГОДИНИ]`, `[ІНСТАГРАМ]`, `[ФОП]`, `[РІК]`, `[ІМ'Я]` і всі посилання-заглушки (телефон у форматі `380…`, нікнейми, адреса в карті й маршруті).
2. Перепишіть меню: назви, склад і `[ЦІНА]` для кожної позиції; приберіть зайві вкладки або додайте нові.
3. Виставте справжній розклад у `data-schedule` і перевірте статус «відчинено/зачинено».
4. Замініть фото на фото клієнта (таблиця вище) й оновіть URL; вставте 3 реальні відгуки замість прикладів.
5. Оновіть `og:url` / JSON-LD під домен, приберіть підсвічування `.ph`, перевірте сайт на телефоні та відправку заявки в Telegram/Viber/WhatsApp/пошту.
