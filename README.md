# Адвокат Перець Наталія Володимирівна — демо-сайт

Шаблон: **advokat** (адвокат / юридичні послуги).

Заповнено з OpenStreetMap: назва, місто, адреса, телефон, графік роботи.

Залишилося заповнити (позначені жовтим пунктиром на сторінці):

- `[ІМ'Я]` — імена авторів відгуків
- `[РІК]` — рік початку практики (блок «Про практику»)
- `[ФОП]` — ФОП / РНОКПП або назва юрособи й ЄДРПОУ у футері
- `[ЦІНА]` — ціни послуг (прайс, головний екран, FAQ)
- три відгуки з міткою «Приклад відгуку» — замінити на реальні
- фото (зараз стокові з Unsplash) — замінити на фото адвоката й кабінету
- напрями практики в навігаторі справи та прайсі — звірити з реальними
