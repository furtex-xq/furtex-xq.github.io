# The Hustle Gym Zone — демо нового сайту (бета)

Тренажерний зал, вул. Гетьмана Мазепи, 35, Івано-Франківськ. Односторінковий статичний сайт (HTML/CSS/JS), мова українська.

- `index.html`, `css/style.css`, `js/main.js`
- `js/vendor/` — GSAP 3.12.5 + ScrollTrigger, Lenis (локально, без CDN)
- `fonts/` — Dela Gothic One, Rubik, PT Mono (кирилиця + латиниця)
- `img/photos/` — тимчасові фото з Unsplash, список у `credits.json`
- `tools/` + `.github/workflows/hustle-photos.yml` — завантаження фото через GitHub Actions

Стиль: «постер на бетоні» — сигнальний жовтий, графіт, бетон, квадратні кнопки з тінню, кольори змагальних дисків (червоний/синій/жовтий/зелений).

Фішки: жовтий перший екран-постер з нахиленим фото й наліпкою «999 грн» (вирівнюються при скролі); «штанга-калькулятор» абонементів (диски додаються зі строком, рахує ціну за місяць і економію); живий статус «Відкрито / Зачинено» за київським часом; нижня панель дій на телефоні.

Заглушки (жовта крапка): графік роботи (джерела розходяться), ціни (з каталогів), відгуки, ФОП/ЄДРПОУ, усі фото, форма (зараз SMS, після запуску Telegram).
