# Шаблон «Автомийка / детейлінг» (`template/avtomyika`)

Односторінковий сайт для автомийки, детейлінг-студії чи мийки самообслуговування з постами. Статичний HTML/CSS/JS без збірки й CDN, мобільний насамперед.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/avtomyika/index.html

## Дизайн

- **Шрифти:** Geist (заголовки й текст, variable) + Martian Mono (ціни, час, підписи). Локально в `fonts/`, лише cyrillic + latin.
- **Палітра:** мокрий асфальт `#101417` / `#181E22`, біла піна `#EDF2F4`, яскравий ціан `#16C8EA` (на світлому фоні — `#00708A`), сталь `#8D989F`.
- **Фішка:** фото в hero спершу вкрите піною (canvas), склоочисник змиває її при завантаженні; рештки піни можна стерти пальцем чи курсором. Друга фішка — «квитанція мийки»: клас авто × пакет → ціна з прайсу, час і що входить, кнопка відразу заповнює форму запису. Лінія води в блоці «Як миємо» наповнюється під час прокручування.
- Відкритий/зачинений статус рахується за київським часом із таблиці графіка.

Тривалості пакетів і що входить у кожен — у `js/main.js` (`PACKS`), узгодьте з власником.

## Фото (Unsplash, замінити на власні)

`hero` — авто в піні (головне, бажано своє), `rinse` — ручна мийка, `interior` — салон, `polish` — полірування, `wheel2` — диски, `foam2` — пост мийки, `cloth`, `wheel` — «Про нас». Файли в `img/photos/`, на сторінці — абсолютні URL raw.githubusercontent, закріплені на коміті.

## Як адаптувати під клієнта

1. Знайти й замінити токени `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ГОДИНИ]` (у «у [МІСТО]» — місцевий відмінок) і прибрати обгортку `<span class="ph">`.
2. Підставити посилання замість сентинелів; канали, яких немає, видалити з кнопок і з `fieldset#via` форми.
3. Заповнити прайс (`[ЦІНА]` у таблиці `#pt`) і графік (`data-open/close` + текст), перевірити `PACKS` у `js/main.js`.
4. Замінити фото на реальні фото мийки, відгуки — на реальні (і зняти клас `ph-card` та мітку).
5. Оновити карту/маршрут на точну адресу, `[ФОП]` у футері, перевірити на телефоні.

Автоматично: `python3 tools/personalize.py <lead.json> <outdir>`.
