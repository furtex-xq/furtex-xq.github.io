# Ivanka IF — демо-сайт

Шаблон: «Масажний кабінет / SPA» (`template/masazh`).

Заповнено з OpenStreetMap: назва, місто, адреса, телефон, Instagram.
Джерело: https://www.openstreetmap.org/node/11677447205

Ще треба заповнити (позначені бурштиновим підкресленням): `[ІМ'Я]`, `[ГОДИНИ]`, `[РІК]`, `[ФОП]`, `[ЦІНА]`.
Відгуки — приклади (`ph-card`), замініть на реальні. Фото — зі стоку Unsplash, бажано замінити на фото кабінету.
