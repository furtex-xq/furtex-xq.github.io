# ADS (Andrusyshyn Dental Service) — демо нового сайту (бета)

Стоматологія, Івано-Франківськ. Статичний односторінковий сайт (HTML/CSS/JS), мова українська.

- `index.html`, `css/style.css`, `js/main.js`
- `js/vendor/` — GSAP 3.12.5 + ScrollTrigger, Lenis (локально, без CDN)
- `fonts/` — Commissioner, Golos Text, IBM Plex Mono (кирилиця + латиниця)
- `img/photos/` — тимчасові фото з Unsplash (Unsplash License), список у `credits.json`
- `tools/` + `.github/workflows/ads-photos.yml` — завантаження фото через GitHub Actions

Фішка: навігатор «Що вас турбує?» — SVG-схема верхнього зубного ряду (нумерація FDI), симптоми підсвічують зуби й ведуть до потрібної послуги з записом. Живий статус «відчинено/зачинено» за київським часом.

Заглушки (жовті позначки або «демо»): адреса (каталоги: Набережна ім. Стефаника, 16а; OSM: вул. Пулюя), графік, Viber, ФОП/ліцензія МОЗ, ціни, відгуки, усі фото.
