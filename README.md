# Шаблон «yuveliry» — ювелірний магазин і майстерня

Універсальний односторінковий демо-сайт для ювелірного салону з власною майстернею (продаж прикрас + ремонт, зміна розміру, гравіювання, виготовлення на замовлення). Чистий HTML/CSS/JS, без бібліотек і збірки.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/yuveliry/index.html

## Дизайн
- **Шрифти:** Brygada 1918 (заголовки, ціни, цифри розміру) + Scada (текст, інтерфейс). Локально в `fonts/`, кирилиця + латиниця, `font-display: swap`.
- **Палітра:** чорний оксамит `#121010` / `#1a1615`, тепле золото `#c9a45f` / `#e8cf98`, срібло `#b9bdc3`, слонова кістка `#f2ece1` (світлі секції «Майстерня» та FAQ), чорнило `#1b1715`.
- **Фішка:** розмірник каблучки — коло на екрані в реальному масштабі (калібрування банківською карткою), режим «виміряти ниткою», переведення UA ↔ діаметр ↔ обхват ↔ EU ↔ US, таблиця розмірів і кнопка «Додати розмір у заявку», що заповнює форму. Супровідні мотиви: «ригель» (ювелірна лінійка розмірів) у hero та пробірні клейма 585 / 925 як маркери.
- Блоки: hero → вітрина (5 категорій, на телефоні — горизонтальна карусель) → майстерня й прайс (вкладки) → розмірник → виготовлення на замовлення (5 кроків) → про нас / чому ми → відгуки → FAQ → контакти, графік зі статусом «відчинено» за київським часом, форма, карта → футер. Мобільна панель: Подзвонити / Записатися / Маршрут.

## Плейсхолдери
Видимі токени обгорнуті в `<span class="ph">…</span>` (жовтий пунктир). Приклади відгуків — картки `.ph-card` з міткою «Приклад відгуку — замініть на реальний».

| Токен / сентинел | Де |
|---|---|
| `[НАЗВА]` | `<title>`, meta, OG, JSON-LD, логотип, «Про нас», футер, JS `BIZ` (текст заявки) |
| `[МІСТО]` | `<title>`, meta description («у [МІСТО]»), JSON-LD, hero-рубрика, адреса в контактах і футері |
| `[АДРЕСА]` | meta description, JSON-LD, контакти, футер |
| `[ТЕЛЕФОН]` | meta description, JSON-LD, шапка, контакти |
| `[EMAIL]` | JSON-LD, кнопка email у контактах |
| `[ІНСТАГРАМ]` | кнопка Instagram у контактах |
| `[ГОДИНИ]` | підсумок графіка в контактах |

## Фото (Unsplash, замінити на фото клієнта)
Усі фото — абсолютні URL на `raw.githubusercontent.com`, закріплені за комітом (див. `tools/chosen.json`, `img/photos/credits.json`).
- `hero` — золоті сережки на оксамиті → найкращий макрознімок прикраси клієнта
- `rings`, `bands`, `earrings`, `chains`, `alt1` (підвіски) — категорії вітрини → реальні вироби з вітрини
- `workshop` — майстер за верстатом (прайс) → фото майстерні клієнта
- `sawing` — ескіз і інструменти (процес виготовлення) → ескізи / воскові моделі клієнта
- `bench` — майстриня за роботою («Про нас») → фото майстра

## Як адаптувати під клієнта
1. Замініть токени `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ІНСТАГРАМ]` і сентинели посилань (або запустіть `python3 tools/personalize.py lead.json out/`).
2. Оновіть `CONTACT` у `js/main.js`, приберіть кнопки й варіанти форми для каналів, яких у клієнта немає (`data-ch="…"`).
3. Впишіть графік у `data-hours`, `[ГОДИНИ]` і JSON-LD `openingHours`; карту й маршрут — на точну адресу.
4. Заповніть ціни `[ЦІНА]`, `[РІК]`, `[ІМ'Я]`, `[ФОП]`; звірте перелік послуг і категорій з реальним асортиментом; замініть приклади відгуків реальними.
5. Замініть фото на фото клієнта, перевірте сайт на телефоні (меню, розмірник, форма, кнопка дзвінка).
