# Юлія Когут — демо-сайт

Шаблон: «Психолог / психотерапевт» (`template/psykholoh`).

Заповнено з OpenStreetMap: ім'я / назва, місто, адреса, телефон.
Джерело: https://www.openstreetmap.org/node/11427358503

Ще треба заповнити (позначені бурштиновим підкресленням): `[ІМ'Я]`, `[ГОДИНИ]`, `[ОСВІТА]`, `[ПІДХІД]`, `[РІК]`, `[ФОП]`, `[ЦІНА]`.
Освіту, підхід і рік початку практики вписувати лише зі слів психолога. Відгуки — приклади (`ph-card`), замініть на реальні. Фото — зі стоку Unsplash, бажано замінити на фото кабінету і портрет.
