# OSTWINPRO — демо нового сайту (бета)

Адвокат Остяк Валентин Васильович (OSTWINPRO), Івано-Франківськ, вул. Бельведерська, 27а. Статичний односторінковий сайт (HTML/CSS/JS), мова українська.

- `index.html`, `css/style.css`, `js/main.js`
- `js/vendor/` — GSAP 3.12.5 + ScrollTrigger, Lenis (локально, без CDN)
- `fonts/` — Manrope (кирилиця + латиниця)
- `img/photos/` — тимчасові фото з Unsplash (Unsplash License), список у `credits.json`
- `tools/` + `.github/workflows/ostwinpro-photos.yml` — завантаження фото через GitHub Actions

Стиль: «швейцарський» корпоративний — графіт, білий, ультрамарин, жирний гротеск Manrope, дуотон-фото. Навмисно інший, ніж у демо адвоката Дороніна (папір/антиква/печатка).

Фішки: експрес-перевірка «Наскільки ваш бізнес захищений юридично?» (6 питань так/ні, матриця з 6 плиток «захищено/ризик» і рівень ризику, результат іде у заявку); напрями практики гортаються горизонтально під час скролу (на ПК закріплений блок, на телефоні свайп); біжучий рядок послуг; живий статус «зараз відчинено/зачинено». Анімації: заголовки з’являються по словах, лічильники цифр, біжучий рядок реагує на швидкість і напрям скролу, плитки ризику каскадом, лінії малюються, магнітні кнопки на ПК, паралакс фото. Анімації лише transform/opacity, вимикаються при `prefers-reduced-motion`.

Заглушки (позначені жовтим): тексти відгуків з Google, номер свідоцтва адвоката, стаж, WhatsApp/Viber на номері, ціна консультації, усі фото (замінити на портрет адвоката).
