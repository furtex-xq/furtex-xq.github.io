# Ратуша — демо-сайт поліграфії

Шаблон: `polihrafiia` (поліграфія / друк): калькулятор друку з розкладкою на аркуші SRA3, прайс-лист, заявка на друк.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/beta/ratusha/index.html

## Заповнено з OpenStreetMap

- назва
- місто
- адреса
- телефон
- графік роботи (таблиця по днях і живий статус «відчинено/зачинено»)
- карта Google і «Маршрут» за запитом «вулиця Олеся Гончара, Івано-Франківськ»

## Ще треба заповнити (позначені пунктиром на сайті)

- `[ІМ'Я]`
- `[РІК]`
- `[ФОП]`
- `[ЦІНА]`
- ціни для калькулятора — `CONFIG.prices` у `js/main.js`
- приклади відгуків (картки «Приклад відгуку») — замінити на реальні
- фото — зараз стокові з Unsplash, бажано фото цеху та продукції

Viber / Telegram / WhatsApp у джерелі не вказані — кнопки прибрано. Форма надсилає заявку через: SMS.
