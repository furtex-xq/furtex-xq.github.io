# White Story — демо нового сайту (бета)

Стоматологія White Story, вул. Гетьмана Мазепи, 58, Івано-Франківськ. Статичний односторінковий сайт (HTML/CSS/JS), мова українська.

- `index.html`, `css/style.css`, `js/main.js`
- `js/vendor/lenis.min.js` — плавний скрол (локально, без CDN)
- `fonts/` — Prata (заголовки) + Nunito Sans (текст), кирилиця + латиниця
- `img/photos/` — тимчасові фото з Unsplash (Unsplash License), список у `credits.json`
- `tools/` + `.github/workflows/whitestory-photos.yml` — завантаження фото через GitHub Actions

Фішка: «Історія усмішки» — шкала відтінків VITA (A3.5 → BL1), зуб світлішає під час скролу, 4 розділи лікування. Також підбір напрямку «Що вас турбує?» з автозаповненням форми, статус «відчинено/зачинено» за київським часом.

Заглушки (жовті позначки): основний телефон (два номери з різних каталогів), Viber, ФОП/ЄДРПОУ, ліцензія МОЗ, лікарі, дитячі послуги, усі фото. Не публікувати до згоди клієнта.
