# Автомийка — демо-сайт автомийки

Персоналізована копія шаблону **«Автомийка / детейлінг»** (`template/avtomyika`).

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/beta/avtomyika/index.html

## Заповнено з OpenStreetMap

- назва
- місто
- адреса
- телефон
- графік роботи
- точка на карті

Канали, яких немає в OSM (Viber, Telegram, WhatsApp, email, Instagram, Facebook), прибрані з кнопок і форми. Заявка з форми йде: SMS.

## Що ще заповнити

- `[ІМ'Я]` (позначено жовтим пунктиром)
- `[РІК]` (позначено жовтим пунктиром)
- `[ФОП]` (позначено жовтим пунктиром)
- `[ЦІНА]` (позначено жовтим пунктиром)
- 3 відгуки-приклади (картки `ph-card`) — замінити на реальні
- фото — зараз стокові з Unsplash, краще замінити на фото мийки
- тривалості й склад пакетів (`PACKS` у `js/main.js`) — узгодити з власником
