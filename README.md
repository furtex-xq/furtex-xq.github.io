# Шаблон «Дитячий розвивальний центр» (`dytiachyi-tsentr`)

Односторінковий демо-сайт для дитячого розвивального центру, студії раннього розвитку чи центру підготовки до школи. Чистий HTML/CSS/JS, без збирання й без сторонніх бібліотек: файли можна одразу залити на будь-який хостинг.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/dytiachyi-tsentr/index.html

## Дизайн

- **Шрифти:** Comfortaa (заголовки, округлий геометричний) + Andika (текст; шрифт створено для дітей, які вчаться читати). Обидва лежать у `fonts/` (кирилиця + латиниця, woff2).
- **Палітра:** вершковий `#FBF3E3`, папір `#FFFBF3`, томатний `#D9432A`, небесний `#78BDE6`, гірчичний `#E9B23A`, персиковий `#F4B39B`, чорнильний `#283142`.
- **Фішка:** дошка розкладу на тиждень із фільтром за віком (1–3, 3–5, 5–7, 7+). Після вибору віку картки занять перешиковуються з анімацією, а лічильник показує, скільки занять підходить. Кнопки віку є і в головному екрані. Кнопка «Записатися» на картці сама підставляє напрям і вік у форму. Ще одна деталь: паперові фігури, що повільно плавають із паралаксом.
- Стиль «вирізано з паперу»: картки з «скотчем», хвилясті краї секцій, арка для фото. Анімації вимикаються, якщо в системі ввімкнено `prefers-reduced-motion`.

## Блоки

Шапка з меню → головний екран (H1, CTA, вибір віку) → напрями й ціни + абонементи → дошка розкладу → про центр + команда → «що хвилює батьків» → як проходить перший візит → галерея → відгуки → FAQ → контакти, години роботи (статус «зараз відчинено/зачинено» за київським часом), форма запису, мапа → футер. На телефоні знизу закріплена панель «Подзвонити / Записатися / Маршрут».

## Плейсхолдери

Видимі дані клієнта позначено так: `<span class="ph">[ТОКЕН]</span>`. Їх видно завдяки жовтому пунктиру. Коли всі дані замінено, клас `ph` можна прибрати (або видалити правило `.ph` у CSS).

| Токен / посилання | Де трапляється |
|---|---|
| `[НАЗВА]` | `<title>`, OG, JSON-LD, логотип у шапці й футері, H1, «Про центр», копірайт |
| `[МІСТО]` | `<title>`, description, keywords, OG, JSON-LD, «Про центр», адреса в контактах і футері |
| `[АДРЕСА]` | JSON-LD, контакти, футер |
| `[ТЕЛЕФОН]` | JSON-LD, меню, великий номер у контактах, футер |
| `[EMAIL]` | JSON-LD, кнопка email у контактах, футер |
| `[ГОДИНИ]` | JSON-LD `openingHours`, футер, бейдж статусу (поки JS не підставить «відчинено/зачинено») |
| `[ІНСТАГРАМ]` | кнопка Instagram у контактах, футер |
| `[ФОП]` | футер (ПІБ ФОП + ЄДРПОУ/ІПН) |
| `[РІК]` | JSON-LD `foundingDate`, кружечок «з [РІК] року» в «Про центр» |
| `[ЦІНА]` | 11 рядків прайсу (`від [ЦІНА] грн`), 4 абонементи, JSON-LD `priceRange` |
| `[ІМ'Я]` | 3 педагоги в «Про центр», 3 автори відгуків |
| `.ph-card` + «Приклад відгуку — замініть на реальний» | 3 картки відгуків |
| `tel:+380000000000` | шапка, кнопка «Зателефонувати», контакти, футер, мобільна панель |
| `viber://chat?number=%2B380000000000` | контакти + `js/main.js` (`CONTACT.viber`) |
| `https://t.me/username` | контакти, FAQ + `js/main.js` (`CONTACT.telegram`) |
| `https://wa.me/380000000000` | контакти |
| `https://www.instagram.com/username/` | контакти, футер, JSON-LD `sameAs` |
| `https://www.facebook.com/username` | контакти, JSON-LD `sameAs` |
| `mailto:hello@example.com` | контакти, футер + `js/main.js` (`CONTACT.email` = `hello@example.com`) |
| Мапа `https://www.google.com/maps?q=%D0%86%D0%B2%D0%B0%D0%BD%D0%BE-%D0%A4%D1%80%D0%B0%D0%BD%D0%BA%D1%96%D0%B2%D1%81%D1%8C%D0%BA&output=embed` | iframe мапи; той самий `destination=` у кнопках «Прокласти маршрут» і «Маршрут» |

Що ще варто відредагувати (це звичайний текст, не токени): назви й описи напрямів, вікові групи й тривалість у прайсі, **картки розкладу** (день, час, назва, `data-ages="1-3 3-5"`), **години роботи** в таблиці (`data-open` / `data-close` — з них рахується статус «відчинено»), відповіді FAQ, текст «Про центр».

## Фото (замінити на фото клієнта)

Зараз стоять фото з Unsplash (ліцензія Unsplash), список — у `img/photos/credits.json`. Вони закріплені абсолютними посиланнями на коміт (`raw.githubusercontent.com/.../<SHA>/img/photos/...`), щоб відкривалися в Safari на iPhone.

| Слот | Де | Чим замінити |
|---|---|---|
| `hero` | арка на головному екрані, og:image | найкраще фото заняття (вертикальне) |
| `art`, `letters`, `music` | колаж біля прайсу | заняття з творчості, мовлення, музики |
| `room`, `toys` | «Про центр» | інтер’єр класу, полиці з матеріалами |
| `toddler`, `paints`, `reading`, `shapes`, `crayons` | галерея | реальні моменти з занять (зі згодою батьків) |

Педагоги показані як паперові аватари — замініть на фото (`.avatar` → `<img>`).

## Як адаптувати під клієнта — 5 кроків

1. Знайдіть і замініть усі токени (`[НАЗВА]`, `[ТЕЛЕФОН]`, `[ЦІНА]`…) і посилання-заглушки з таблиці вище, зокрема в `js/main.js` (об’єкт `CONTACT`) і в JSON-LD у `<head>`.
2. Перепишіть прайс і розклад під реальні напрями: на кожній картці розкладу виставте `data-ages`, а лічильник і фільтр оновляться самі.
3. Вкажіть реальні години в таблиці (`data-open`/`data-close`) і замініть місто в URL мапи та маршрутів (URL-кодований `q=` / `destination=`).
4. Замініть фото на фото клієнта (покладіть у `img/photos/` і оновіть `src` та `og:image`). Відгуки замініть на реальні й зніміть клас `ph-card` та мітку.
5. Приберіть клас `ph` (або правило `.ph` у CSS), перевірте сайт на телефоні й надішліть клієнту посилання.
