# OSTWINPRO — демо нового сайту (бета)

Адвокат Остяк Валентин Васильович (OSTWINPRO), Івано-Франківськ, вул. Бельведерська, 27а. Статичний односторінковий сайт (HTML/CSS/JS), мова українська.

- `index.html`, `css/style.css`, `js/main.js`
- `js/vendor/` — GSAP 3.12.5 + ScrollTrigger, Lenis (локально, без CDN)
- `fonts/` — Commissioner (український шрифт, кирилиця + латиниця)
- `img/photos/` — тимчасові фото з Unsplash (Unsplash License), список у `credits.json`
- `tools/` + `.github/workflows/ostwinpro-photos.yml` — завантаження фото через GitHub Actions

Стиль: «швейцарський» корпоративний — графіт, білий, ультрамарин, жирна гротескна типографіка, дуотон-фото. Навмисно інший, ніж у демо адвоката Дороніна (папір/антиква/печатка).

Фішки: експрес-перевірка «Наскільки ваш бізнес захищений юридично?» (6 питань так/ні, спідометр і висновок, результат іде у заявку); напрями практики гортаються горизонтально під час скролу (на ПК закріплений блок, на телефоні свайп); біжучий рядок послуг; живий статус «зараз відчинено/зачинено». Анімації лише transform/opacity, вимикаються при `prefers-reduced-motion`.

Заглушки (позначені жовтим): тексти відгуків з Google, номер свідоцтва адвоката, стаж, WhatsApp/Viber на номері, ціна консультації, усі фото (замінити на портрет адвоката).
