# ЗооВетСвіт — демо-сайт

Шаблон: `zoomahazyn` (зоомагазин, калькулятор корму).

З OpenStreetMap підставлено: назва, місто, адреса, телефон, Instagram, Facebook, графік роботи, точка на карті.

Прибрано кнопки й канали, яких у магазину немає: Viber, Telegram, WhatsApp, пошта.

Ще треба заповнити (позначені жовтим пунктиром):

- `[ІМ'Я]`
- `[РІК]`
- `[ФОП]`
- `[ЦІНА]`
- відгуки-приклади (картки з позначкою «Приклад відгуку»)
- фото: зараз стокові з Unsplash — краще замінити на фото магазину й полиць
