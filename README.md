# Шаблон «Ательє» — пошиття і ремонт одягу

Універсальний односторінковий демо-сайт для ательє (ремонт, підгонка та індивідуальне пошиття одягу). Чистий HTML/CSS/JS без бібліотек і збірки: `index.html`, `css/style.css`, `js/main.js`, шрифти локально в `fonts/`.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/atelie/index.html

## Дизайн

- **Шрифти:** EB Garamond (заголовки, курсив для акцентів) + PT Sans Narrow (текст, підписи, кнопки). Кирилиця + латиниця, `font-display: swap`.
- **Палітра:** темно-синій костюмний `#121c33` / `#1d2b4c`, крейдяний білий `#f0efea`, жовтий сантиметрової стрічки `#e8b62c`, сіро-блакитний «у смужку» `#8c97ad`, червоний кравецької нитки `#b8432f` (лише точково).
- **Фактура:** тонка вертикальна смужка (pinstripe) на темних секціях, пунктирні «стібки» замість звичайних ліній.
- **Фішка:** сантиметрова стрічка, що розмотується під час прокручування сторінки: на ПК — вертикально зліва, на телефоні — під шапкою. Котушка обертається, а металевий наконечник показує «скільки сантиметрів» сторінки пройдено (0–150 см). Додатково: «картка замовлення» з мірками в hero та прайс-лист із вкладками (штани, сукні, верхній одяг, дрібний ремонт, пошиття).
- Анімації вимикаються при `prefers-reduced-motion`.

## Плейсхолдери

Видимі дані клієнта позначені як `<span class="ph">[ТОКЕН]</span>` (жовте пунктирне підкреслення). Після заміни даних приберіть обгортку `<span class="ph">…</span>`, щоб зник жовтий фон.

| Токен / посилання | Що це | Де трапляється |
|---|---|---|
| `[НАЗВА]` | назва ательє | title, meta, OG, JSON-LD, шапка, hero, про нас, карта (title iframe), футер |
| `[МІСТО]` | місто | hero (eyebrow), адреса в контактах і футері, JSON-LD |
| `[АДРЕСА]` | вулиця, будинок | контакти, футер, JSON-LD |
| `[ТЕЛЕФОН]` | телефон для показу | meta description, меню (моб.), кнопка в контактах, успіх форми, футер, JSON-LD |
| `[EMAIL]` | пошта | кнопка в контактах, футер, JSON-LD |
| `[ГОДИНИ]` | короткий графік текстом | блок «Графік роботи», JSON-LD `openingHours` |
| `[ІНСТАГРАМ]` | нікнейм Instagram | кнопка в контактах |
| `[ФОП]` | ФОП / ЄДРПОУ | футер |
| `[РІК]` | рік заснування | hero (факти), про нас, JSON-LD `foundingDate` |
| `[ЦІНА]` | ціна (`від [ЦІНА] грн`) | усі рядки прайсу, meta description, JSON-LD `priceRange` |
| `[ІМ'Я]` | імена людей | цитата майстрині, 3 відгуки |
| `.ph-card` | приклад відгуку | 3 картки відгуків з міткою «Приклад відгуку — замініть на реальний» (видалити мітку `.ph-card__label` і клас) |

| `https://wa.me/380000000000` | WhatsApp | контакти |

**Графік для статусу «зараз відчинено/зачинено»** (за київським часом) задається в атрибуті `data-hours` елемента `#hours` в `index.html`: ключі — дні тижня (0 = неділя), значення — `["09:00","19:00"]` або `null` (вихідний). Таблиця днів будується автоматично.

**Прайс:** назви послуг і терміни — редагований текст типовий для ательє; суми — лише через `[ЦІНА]`.

## Фото (Unsplash, ліцензія Unsplash)

Фото лежать у `img/photos/` і підключені абсолютними посиланнями на raw.githubusercontent.com, закріпленими на коміті `5d2de1ecae8bdb8c4f9fa624375de930eeb400f3` (так вони стабільно вантажаться в iPhone Safari через raw.githack). Список і джерела — `img/photos/credits.json`, вибір — `tools/chosen.json`.

| Слот | Де на сайті | Замінити на фото клієнта? |
|---|---|---|
| `hero.jpg` | головний екран, og:image | **так** — майстер за роботою / інтер'єр ательє |
| `sewing.jpg` | послуга «Ремонт і підгонка» | бажано — реальна швейна машина / процес |
| `cutting.jpg` | послуга «Індивідуальне пошиття» | бажано — розкрій у майстерні |
| `suit.jpg` | послуга «Перешивання і реставрація» | бажано — готові роботи |
| `tape.jpg` | прайс-лист | можна залишити |
| `pattern.jpg` | «Про ательє», велике фото | **так** — фото майстрині / власниці |
| `threads.jpg` | «Про ательє», мале фото | бажано — полиця з нитками в ательє |
| `fabric.jpg` | «Чому несуть до нас» | можна залишити |

`machine.jpg`, `repair.jpg` — запасні, на сторінці не використані.

Щоб замінити фото: покласти нові файли з тими самими іменами в `img/photos/`, закомітити й оновити SHA в URL (`git rev-parse HEAD` після коміту з фото) — пошук-заміна `5d2de1ecae8bdb8c4f9fa624375de930eeb400f3`.

## Як адаптувати під клієнта (5 кроків)

1. **Дані:** пошук-заміна всіх токенів із таблиці (`[НАЗВА]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`…) у `index.html`; прибрати обгортки `<span class="ph">`.
2. **Контакти:** замінити посилання-заглушки (`380000000000`, `username`, `hello@example.com`) в `index.html` **і** в `js/main.js` (об'єкт `LINKS`); оновити адресу в iframe карти та кнопці «Маршрут».
3. **Прайс і графік:** вписати реальні ціни замість `[ЦІНА]`, прибрати зайві послуги, виправити `data-hours` і текст `[ГОДИНИ]`.
4. **Фото й відгуки:** замінити фото з позначкою «так», вставити 2–3 справжні відгуки (з Google-карт або Instagram) та прибрати мітки `.ph-card__label`.
5. **SEO і перевірка:** перевірити title/description, JSON-LD (`telephone`, `address`, `openingHours` у форматі `Mo-Fr 09:00-19:00`), відкрити сайт на телефоні, відправити тестову заявку з форми.
