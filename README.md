# Медуза — демо-сайт

Шаблон: **bar** (бар / паб) від Ansaro.

Заповнено з OpenStreetMap: назва, місто, адреса, телефон, email, години роботи (з живим статусом «відчинено/зачинено»), карта й маршрут.
Viber, Telegram і WhatsApp прибрано (невідомі); форма бронювання надсилає заявку через: Email, SMS.

Ще треба заповнити (позначені бурштиновим підкресленням): [ІМ'Я], [РІК], [ФОП], [ЦІНА].
Відгуки — приклади (картки з позначкою «Приклад відгуку»), замініть на реальні. Меню, афіша й фото — типові для пабу, уточніть у закладу.
