# Floriya — демо-сайт квіткового магазину

Шаблон: `kvity` (квітковий магазин / доставка квітів), конструктор букета й слоти доставки за київським часом.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/beta/floriya/index.html

## Заповнено з OpenStreetMap

- назва
- місто
- адреса
- телефон
- Instagram
- графік роботи (живий статус «відчинено/зачинено» і слоти доставки)
- карта Google за запитом «вулиця Василя Симоненка, Івано-Франківськ»

## Ще треба заповнити (позначені пунктиром на сайті)

- `[ІМ'Я]`
- `[РІК]`
- `[ФОП]`
- `[ЦІНА]`
- приклади відгуків (картки з позначкою «Приклад відгуку») — замінити на реальні
- фото — зараз стокові з Unsplash, бажано фото магазину й букетів

Viber / Telegram / WhatsApp не вказані в джерелі — кнопки прибрано; форма надсилає замовлення через: SMS або Instagram.
