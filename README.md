# Шаблон «Стоматологія» (stomatolohiia)

Універсальний односторінковий демо-сайт для стоматологічної клініки чи кабінету. Чистий HTML/CSS/JS без збірки й без бібліотек, мобільна версія в пріоритеті.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/stomatolohiia/index.html

## Дизайн
- **Шрифти:** Philosopher (заголовки) + PT Sans (текст), локально в `fonts/` (кирилиця + латиниця).
- **Палітра:** теплий пісок `#E8DDCD` / `#DCCBB4`, графіт `#262624`, м'ятний лід `#CDEDE3` (акцент), м'ятний для тексту `#2C6E5F`, папір `#F4EEE4`. Свідомо без біло-рожевих і бірюзових стоматологічних кліше.
- **Фішка — «Таймлайн посмішки»:** пацієнт обирає лікування (лікування, гігієна, імпланти, вініри, брекети), і на дузі-«посмішці» з'являються візити по черзі: що робимо, через скільки після попереднього, скільки триває, а над ними — кількість візитів, загальна тривалість і ціна «від». Кнопка під планом підставляє послугу у форму запису.
- Мотив «усмішки» (U-дуга) повторюється в кікерах, рамці головного фото і підкресленні меню.
- Статус «Зараз відчинено / зачинено» за київським часом (з графіка в контактах), липка мобільна панель «Подзвонити / Записатися / Маршрут».

## Плейсхолдери
Видимі дані клієнта — у `<span class="ph">[ТОКЕН]</span>` (жовте пунктирне підкреслення). Приклади відгуків — картки `ph-card` з міткою «Приклад відгуку — замініть на реальний».

| Токен / сентинел | Де |
|---|---|
| `[НАЗВА]` | `<title>`, OG, JSON-LD, логотип у шапці й футері, «Про нас», копірайт |
| `[МІСТО]` | `<title>`, description, OG, JSON-LD, рядок над H1 («Стоматологія у …»), адреса в контактах і футері |
| `[АДРЕСА]` | контакти, футер, JSON-LD |
| `[ТЕЛЕФОН]` | шапка, великий номер у контактах, футер, description, JSON-LD |
| `[EMAIL]` | контакти, JSON-LD |
| `[ІНСТАГРАМ]` | контакти (handle) |
| `[ГОДИНИ]` | заголовок графіка, футер, JSON-LD `openingHours`; таблиця графіка — атрибути `data-hours` у `<ul data-hours-list>` |
| `[ЦІНА]` | головний екран (консультація), підсумок кожного плану в таймлайні, весь прайс, JSON-LD `priceRange` |
| `[ІМ'Я]` | головний лікар у «Про нас», підписи відгуків |
| `[РІК]` | «Про нас» |
| `[ФОП]` | футер (ФОП/ТОВ, ЄДРПОУ) |
| `tel:+380000000000` | шапка, кнопка на головному, контакти, футер, мобільна панель |
| `viber://chat?number=%2B380000000000`, `https://wa.me/380000000000`, `https://t.me/username` | кнопки в контактах |
| `https://www.instagram.com/username/`, `https://www.facebook.com/username` | контакти, JSON-LD `sameAs` |
| `mailto:hello@example.com` | контакти |
| `https://www.google.com/maps?q=…&output=embed` та `…/maps/dir/?api=1&destination=…` | карта, кнопка «Прокласти маршрут», мобільна панель |
| `var CONTACT = {…}` у `js/main.js` | куди форма надсилає заявку (телефон, SMS, Viber, WhatsApp, Telegram, Instagram, email) |

Кожна кнопка/опція каналу має `data-ch="phone|viber|telegram|whatsapp|sms|instagram|facebook|email"` — невідомий канал видаляється разом з елементом.

## Фото (Unsplash, замінити на фото клініки)
`img/photos/` — завантажено GitHub Actions з `tools/chosen.json`; на сторінці підключені абсолютними URL, закріпленими на коміт.
- `consult` — головний екран (лікар і пацієнтка) → **замінити першим** на фото лікаря клініки;
- `cabinet`, `mirror` — «Про нас» → фото кабінету;
- `xray` — «Перший візит» → лікар зі знімками;
- `implant` — під прайсом;
- `smile` — у відгуках;
- `hero` — og:image і JSON-LD → фото фасаду/кабінету.
- Запасні: `room`, `tools`, `hygiene`.

## Як адаптувати під клієнта (5 кроків)
1. Запустити `python3 tools/personalize.py lead.json out/` або вручну замінити токени `[НАЗВА]`, `[ТЕЛЕФОН]`, `[АДРЕСА]`, `[МІСТО]` (після «у» — місцевий відмінок) і сентинели посилань.
2. Оновити графік у `<ul data-hours-list>` (`data-hours="09:00-19:00"`, порожньо — вихідний) і текст `[ГОДИНИ]`; у `js/main.js` залишити в `CONTACT` лише реальні канали, зайві кнопки з `data-ch` видалити.
3. Заповнити прайс і ціни в таймлайні (`[ЦІНА]`), звірити кроки й тривалості планів з лікарем.
4. Замінити фото на реальні (лікар, кабінет, фасад), вставити справжні відгуки замість `ph-card`, ім'я лікаря, рік, ФОП/ЄДРПОУ.
5. Перевірити на телефоні: дзвінок, форму (SMS/месенджер), маршрут, статус «відчинено».
