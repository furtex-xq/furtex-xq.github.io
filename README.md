# GRAND-GRANIT — демо нового сайту (бета)

Статичний сайт (HTML/CSS/JS) для GRAND-GRANIT, Калуш: пам'ятники та вироби з граніту й мармуру. Мова: українська.

- `index.html` — односторінковий сайт
- `css/style.css`, `js/main.js`
- `js/vendor/` — GSAP 3.12.5 (+ ScrollTrigger, Flip) і Lenis 1.1.13, локально, без CDN
- `img/` — текстури каменю (SVG), favicon, OG-зображення

Анімації: гравірування заголовка по літерах, полірування плити, паралакс, горизонтальний каталог з фіксацією (desktop), лінії процесу й історії, Flip-фільтр галереї, стрічка міст, що прискорюється від скролу. Повага до `prefers-reduced-motion`.

Заглушки (замінити даними клієнта): фото в каталозі й на плитці «Камінь в інтер'єрі» — ілюстративні з Unsplash; галерея робіт, відгуки, години роботи, ФОП/ЄДРПОУ.
