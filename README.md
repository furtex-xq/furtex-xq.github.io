# Шаблон «Зоомагазин» (`zoomahazyn`)

Односторінковий демо-сайт для зоомагазину: корм і товари для собак, котів, гризунів, птахів і рибок. Чистий HTML/CSS/JS без бібліотек і збірки, шрифти локально, фото — абсолютні URL на raw.githubusercontent.com (закріплені за комітом).

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/zoomahazyn/index.html

## Дизайн
- **Шрифти:** Marmelad (заголовки) + Ysabeau Infant 400/600/700 (текст), кирилиця + латиниця, `fonts/`.
- **Палітра:** вівсяний `#EFE6D2`, папір `#FBF7EE`, листяний зелений `#2F6B3A`, мандарин `#F07B1F`, графіт-зелений `#22281F`.
- **Фішка:** калькулятор корму — собака/кіт, вага, вік, спосіб життя, тип годування → добова порція (миска наповнюється гранулами), корм на місяць і яку упаковку брати (мішок заповнюється). Кнопка «Замовити корм на місяць» переносить розрахунок у форму замовлення.
- Другорядне: слід лап у блоці «Як замовити» (лапки «ступають» по черзі при прокручуванні), «вітринна» арка в героблоці, бенто-сітка категорій, цінники-ярлики.
- Статус «зараз відчинено/зачинено» за київським часом з таблиці графіка (`data-open` / `data-close`).
- Форма без бекенду: формує текст і відкриває Telegram / Viber / WhatsApp / Instagram Direct / SMS / пошту (для месенджерів без підстановки тексту — копіює його в буфер).

## Плейсхолдери
Видимі токени обгорнуті в `<span class="ph">…</span>` (жовтий пунктир). Після заміни приберіть клас `ph`.

| Токен / сентинел | Де |
|---|---|
| `[НАЗВА]` | title, og, JSON-LD, лого, «Про магазин», футер (+ підпис у тексті заявки береться з лого) |
| `[МІСТО]` | title («Зоомагазин [МІСТО]» — називний), meta/og/JSON-LD, герой «у [МІСТО]», адреса, футер |
| `[АДРЕСА]` | контакти, футер, JSON-LD |
| `[ТЕЛЕФОН]` | шапка, кнопка «Подзвонити», футер, JSON-LD |
| `[EMAIL]` | контакти, футер, JSON-LD |
| `[ГОДИНИ]` | статус у героблоці та контактах (замінюється JS-статусом), JSON-LD |
| `[ІНСТАГРАМ]` | не показується текстом — тільки посилання `https://www.instagram.com/username/` та `https://ig.me/m/username` у формі |
| `[ФОП]` | футер |
| `[РІК]` | «Про магазин», JSON-LD |
| `[ЦІНА]` | 15 рядків цінників «від [ЦІНА] грн», JSON-LD priceRange |
| `[ІМ'Я]` | автори відгуків |
| `.ph-card` | 3 приклади відгуків з позначкою «Приклад відгуку — замініть на реальний» |
| `.ph-note` | «Графік-приклад» під таблицею годин — прибрати після внесення реального графіка |
| `tel:+380000000000` | шапка, герой, калькулятор, контакти, футер, нижня панель |
| `viber://chat?number=%2B380000000000` | контакти, форма |
| `https://t.me/username` | контакти, форма |
| `https://wa.me/380000000000` | контакти, форма |
| `https://www.instagram.com/username/`, `https://ig.me/m/username` | контакти, JSON-LD / форма |
| `https://www.facebook.com/username` | контакти, JSON-LD |
| `mailto:hello@example.com` | контакти, форма, футер |
| `maps?q=Івано-Франківськ` (URL-encoded) | iframe карти, «Прокласти маршрут», «Маршрут» у нижній панелі |

## Фото (Unsplash, замінити на фото магазину)
`img/photos/`: `hero` (пес з іграшкою), `dog-bowl`, `cat-eating`, `kittens`, `treats`, `fish`, `hamster`, `budgie`, `leash`, `shop-cat`. Найважливіше замінити: `hero`, `shop-cat` (фото залу/вітрини), а також категорії — на фото реальних полиць.

## Як адаптувати під клієнта
1. Знайти-замінити всі токени з таблиці (або `python3 tools/personalize.py lead.json out/`).
2. Замінити посилання-сентинели; прибрати кнопки й варіанти форми для каналів, яких у клієнта немає.
3. Внести графік у `tr[data-day]` (`data-open`/`data-close`, порожні — вихідний) і прибрати `.ph-note`.
4. Вписати ціни, рік, ФОП; замінити приклади відгуків реальними (прибрати `ph-card` і мітку).
5. Замінити фото на фото магазину й оновити `og:image`, перевірити сайт на телефоні.
