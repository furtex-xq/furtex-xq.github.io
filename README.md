# Шаблон «Кульки й декор свят» (`kulky-dekor`)

Односторінковий сайт для студії повітряних кульок / декору свят: гелієві кульки, фольговані цифри, фотозони, арки, оформлення виписок, весіль і гендер-паті. Статичний HTML/CSS/JS без збірки й без CDN.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/template/kulky-dekor/index.html

## Дизайн

- **Шрифти:** Kurale (заголовки, каліграфічна антиква з кирилицею) + Noto Serif (текст), локально в `fonts/` (cyrillic + latin).
- **Палітра:** пудра `#F4DCD7` / `#E9B7B0`, шампань `#F3E6D2`, небо `#E3EDF4` / `#BFD5E6`, фольга-золото `#B08640` / `#D9B97A` (градієнт «фольги» на заголовках), чорнило `#2E2530`, ягідний акцент для кнопок `#A8485E`.
- **Фішки:** (1) кульки на тлі секцій злітають угору під час прокрутки й ледь гойдаються; (2) «Що святкуємо?» — вибір події (день народження, виписка, весілля, гендер-паті) показує палітру й три готові сети, намальовані SVG у кольорах події; кнопка «Хочу цей сет» заповнює форму.
- Арочні рамки фото (як арка з кульок), кроки замовлення у вигляді золотих кульок, статус «зараз відчинено/зачинено» за київським часом.
- `prefers-reduced-motion` вимикає всі анімації.

## Плейсхолдери

Видимі дані клієнта — `<span class="ph">[ТОКЕН]</span>` (жовтий пунктир). Один пошук-заміна адаптує сайт.

| Токен / сентинел | Де |
|---|---|
| `[НАЗВА]` | title, meta, OG, JSON-LD, логотип, hero, «Про нас», футер, `CONFIG.brand` у `js/main.js` (текст заявки) |
| `[МІСТО]` | title, meta description, OG, JSON-LD, H1 («у [МІСТО]»), контакти, футер |
| `[АДРЕСА]` | JSON-LD, «Про нас», контакти, футер |
| `[ТЕЛЕФОН]` | JSON-LD, шапка, контакти, повідомлення після заявки |
| `[EMAIL]` | JSON-LD, контакти |
| `[ІНСТАГРАМ]` | контакти (handle) |
| `[ГОДИНИ]` | JSON-LD, «Про нас», графік роботи |
| `[ФОП]` | футер |
| `[РІК]` | «Про нас» |
| `[ЦІНА]` | сети подій, прайс, бейдж у hero (`від [ЦІНА] грн`) |
| `[ІМ'Я]` | «Про нас» (майстриня), автори відгуків |
| `tel:+380000000000` | шапка, hero, контакти, мобільна панель, успіх форми |
| `viber://chat?number=%2B380000000000`, `https://t.me/username`, `https://wa.me/380000000000`, `mailto:hello@example.com` | кнопки контактів і `CONFIG.channels` (куди форма надсилає заявку) |
| `https://www.instagram.com/username/`, `https://www.facebook.com/username` | кнопки контактів, JSON-LD `sameAs` |
| `https://example.com/` | canonical, og:url, JSON-LD url |
| `Івано-Франківськ` (URL-кодовано) | iframe карти й посилання «Маршрут» |

Графік: `CONFIG.hours` у `js/main.js` (`"0"` — неділя … `"6"` — субота, `null` — вихідний). Зараз там приклад (`demoHours: true` показує примітку). Відгуки — картки `.ph-card` з позначкою «Приклад відгуку».

Канали відправки форми задаються масивом `CONFIG.channels` (`telegram`, `viber`, `whatsapp`, `email`, `sms`, `instagram`): один канал — без вибору, нуль — форма показує текст заявки й номер.

## Фото (Unsplash, замінити на фото клієнта)

`img/photos/` (посилання в HTML — абсолютні raw.githubusercontent, закріплені на коміті): `hero` (арка з хромованих кульок), `birthday`, `baby`, `hero2` (весілля), `gender`, `studio` («Про нас» — бажано фото самої майстерні/команди), галерея `table`, `bunch`, `foil`, `arch`, `sky`, `pastel`. Найважливіше замінити: hero, studio і галерею — реальними роботами клієнта.

## Як адаптувати під клієнта (5 кроків)

1. Замініть токени `[НАЗВА]`, `[МІСТО]`, `[АДРЕСА]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[ІНСТАГРАМ]`, `[ГОДИНИ]`, `[ФОП]`, `[РІК]`, `[ІМ'Я]` і зніміть клас `ph`.
2. Замініть сентинели посилань (tel, Viber, Telegram, WhatsApp, Instagram, Facebook, mailto), запит карти й «Маршруту»; кнопки каналів, яких немає, видаліть.
3. У `js/main.js` оновіть `CONFIG.hours` (і `demoHours: false`), `CONFIG.channels`, `CONFIG.brand`; видаліть примітку `<!--demo-->`.
4. Впишіть ціни замість `[ЦІНА]` у сетах і прайсі, за потреби змініть назви сетів і палітри подій (`data-palette`).
5. Замініть фото й відгуки на реальні, оновіть og:image і canonical — і перевірте сайт на телефоні.

Автоматично для лідів: `python3 tools/personalize.py <lead.json> <outdir>`.
