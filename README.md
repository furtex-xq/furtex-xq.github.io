# Happy Day — демо-сайт студії кульок і декору

Шаблон: `kulky-dekor` (повітряні кульки / декор свят): вибір події з готовими сетами, прайс, заявка.

Демо: https://raw.githack.com/furtex-xq/furtex-xq.github.io/beta/happy-day/index.html

## Заповнено з OpenStreetMap

- назва
- місто
- адреса
- Instagram
- карта й «Маршрут» за запитом «Слобідська вулиця, Крихівці»

## Ще треба заповнити (позначені жовтим пунктиром)

- `[ІМ'Я]`
- `[ГОДИНИ]`
- `[РІК]`
- `[ФОП]`
- `[ЦІНА]`
- приклади відгуків (картки «Приклад відгуку») — замінити на реальні
- фото — зараз стокові з Unsplash; бажано реальні роботи студії

Viber / Telegram / WhatsApp у джерелі не вказані — кнопки прибрано. Форма надсилає заявку через: Instagram Direct.
