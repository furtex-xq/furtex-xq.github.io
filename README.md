# Фран Stop — демо-сайт

Шаблон: **fastfud** (піца / бургери / фастфуд) від Ansaro. Акцент: змішаний (піца та бургери).

Заповнено з OpenStreetMap: назва, місто, адреса, телефон, години роботи (з живим статусом «відчинено/зачинено»), карта й маршрут.
Viber, Telegram і WhatsApp прибрано (невідомі). Форма замовлення надсилає заявку через: SMS.

Ще треба заповнити (позначені бурштиновим підкресленням): [ІМ'Я], [РІК], [ФОП], [ЦІНА].
Відгуки — приклади (картки з позначкою «Приклад відгуку»), замініть на реальні. Меню, умови доставки й фото — типові, уточніть у закладу.
