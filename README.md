# Shamanka — демо нового сайту (бета)

Салон-перукарня Shamanka, вул. Бельведерська 23, Івано-Франківськ. Статичний односторінковий сайт (HTML/CSS/JS), мова українська.

- `index.html`, `css/style.css`, `js/main.js`; `js/vendor/lenis.min.js` (плавний скрол, локально)
- `fonts/` — Playfair Display + Commissioner (кирилиця + латиниця)
- `img/photos/` — тимчасові фото з Unsplash (Unsplash License), список у `credits.json`
- `tools/` + `.github/workflows/shamanka-photos.yml` — завантаження фото через GitHub Actions

Фішки: «пасмо» прогресу скролу (ПК), підбір відтінку (6 кольорів × 4 техніки) з живим пасмом волосся, акордеон послуг із фото за курсором, форма → WhatsApp/Viber.

Заглушки (жовті позначки): ціни, ФОП/ІПН, години (з довідників), склад майстрів, WhatsApp/Viber на номері, усі фото.
