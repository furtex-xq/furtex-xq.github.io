Вопросы

Не забанит ли TikTok за такие игры?

Игра просто показывает картинку поверх эфира и реагирует на реальные лайки, комментарии и подарки твоих зрителей, как обычные виджеты TikFinity. Она ничего не накручивает и не пишет в чат. Правила сообщества TikTok для самого эфира, конечно, никто не отменял.

Можно ли запустить игру с телефона?

Для эфира нужен компьютер с TikTok LIVE Studio или OBS, потому что игра добавляется как источник «Браузер». Посмотреть демо можно и с телефона.

Что нужно установить?

Только бесплатную программу TikFinity, она передаёт игре события эфира. Сами игры и лаунчер открываются в браузере.

Подключение

В эфир за 2 минуты

Все 14 игр подключаются одинаково. Нужна только бесплатная программа TikFinity, от нас ничего ставить не надо.

1

Запусти TikFinity

Скачай TikFinity с tikfinity.zerody.one, войди и подключи свой LIVE. Программа должна работать на том же компьютере, где идёт эфир.

2

Открой лаунчер StreamStorm

Выбери игру, впиши свой ник, при желании поменяй подарки и страны. Нажми «Скопировать ссылку для эфира».

⚡ Открыть лаунчер

3

Вставь ссылку в LIVE Studio

Добавь источник «Браузер» или «Ссылка», вставь ссылку и растяни на весь экран 1080 × 1920. Пульт ведущего в эфире не виден.

3

Вставь ссылку в OBS

«Источники» → «+» → «Браузер», ширина 1080, высота 1920. Фон у игры прозрачный, камеру можно оставить под ней.

Для продвинутых: ручные параметры и запуск без TikFinity

Ссылку можно собрать и без лаунчера: games/<игра>/index.html?src=tikfinity&user=ТВОЙ_НИК. Полезные параметры: teams=KZ,PL,DE,TR страны, round=120 длина раунда в секундах, likes=0 только подарки, map=5655:platform:3 свой подарок на действие, obs=1 прозрачный фон.

Без TikFinity можно использовать мост на Node.js из папки games/lava-rising/bridge: cd bridge && npm install && node bridge.js ТВОЙ_НИК. Не запускай его одновременно с TikFinity.
