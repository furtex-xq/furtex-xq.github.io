# 💣 Горячая бомба — TikTok LIVE мини-игра

4 команды: 🔥 Огонь, 💧 Вода, 🌿 Лес, ⚡ Молния. У одной из них горит бомба. Чтобы бросить её дальше, команда держателя должна набрать нужную силу подарками. Не успели — БАБАХ, минус жизнь. После каждого броска бомба тяжелее, а фитиль короче. Последняя выжившая команда побеждает.

Бомба всегда летит в команду с наибольшим числом жизней. Никакой случайности, всё решают подарки.

## Запуск
- Без эфира: открой `index.html` — демо-боты + пульт (G/S/M подарки держателю, L лайки, B боты, R рестарт, H пульт).
- Эфир (TikFinity): `index.html?src=tikfinity&user=ТВОЙ_НИК` → OBS «Браузер» 1080×1920.

## Правила для зрителей
- 💬 «огонь», «вода», «лес», «молния» (или 1–4, или эмодзи) — выбор команды.
- 🎁 1 монета = 1 сила броска (считаются только подарки команды, у которой бомба). Подарок 100+ — мгновенный бросок.
- ❤️ 60 лайков = 1 сила. ➕ подписка = 3 силы.

## Параметры ссылки
`src`, `user`, `lives` (жизней у команды, 1–9), `likes=0`, `ws`, `panel=1`, `obs=1`,
`map=giftId:действие:сила` — `power` (N силы), `cool` (заморозить фитиль на N сек), `none`. Баланс — `CONFIG` в начале файла.
