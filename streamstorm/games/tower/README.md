# 🗼 Башня до неба — TikTok LIVE мини-игра

4 страны строят башни. Каждые 3 монеты подарков = новый этаж. Каждые 45 с налетает буря и сносит 15% этажей у незащищённых башен. Через 3 минуты побеждает самая высокая башня.

## Запуск
- Без эфира: открой `index.html` — демо-боты + пульт (1–4 подарок команде, S средний, M мега, R рестарт, H пульт).
- Эфир (TikFinity): `index.html?src=tikfinity&user=ТВОЙ_НИК` → OBS «Браузер» 1080×1920.

## Правила для зрителей
- 💬 Пиши страну (название, флаг) или номер 1–4.
- 🎁 3 монеты = 1 этаж. 💎 Подарок 10–99 = якорь ⚓: башня целиком переживёт следующую бурю. 🚀 100+ = подъёмный кран: сразу +10 этажей (но не больше 30% высоты лидера).
- ❤️ 20 лайков = 1 монета. ➕ подписка = 5 монет.

## Параметры ссылки
`src`, `user`, `round`, `teams=UA,KZ,PL,TR` (2–4), `likes=0`, `ws`, `panel=1`, `obs=1`, `map=giftId:действие:сила` (`small`/`mid`/`big` с ценой в монетах, или `none`).
