# 🎈 Шары стран (balloon-race)

Воздушные шары стран (до 6) летят в стратосферу. Первый, кто поднимется на 3000 м, побеждает. Если за 150 с никто не долетел, побеждает самый высокий шар.

**Как играть зрителю:** напиши страну (название, флаг или номер) в чат, и дальше твои подарки поднимают её шар.

| Действие | Эффект |
|---|---|
| 🎁 1 монета | +6 м (плавно, через горелку) |
| 💎 10+ монет | горелка: подъём ×2 на 6 с |
| 🚀 100+ монет | купол: гроза не страшна 20 с |
| ❤️ лайки | 10 лайков = +1 м |
| ⛈ каждые 35 с | гроза над лидером: −8% высоты, если нет купола |

Всё детерминировано, без случайностей. Ни один подарок не теряется: подарки на экране победы засчитываются в следующий полёт.

**Параметры ссылки:** `teams=KZ,UZ,PL,DE,TR,BR`; `mode=countries|duel|colors`.

**Тест:** панель (селектор страны, 🌹1, 💎30, 🚀199, лайки, рестарт); клавиши 1–6, S, M, R.

FPS при потоке 11 подарков/с: 59.
