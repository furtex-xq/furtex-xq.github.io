# 👑 Трон королевства — TikTok LIVE мини-игра

Один трон, один король. Кто подарил подарок — бьёт короля. Сила трона кончилась — дарящий садится на трон сам.
Король может дарить подарки, чтобы укрепить трон. Трон со временем «ржавеет», поэтому король должен поддерживать его.
Побеждает тот, кто **дольше всех просидел на троне** за раунд (3 мин). Никакой случайности: всё решают подарки.

## Запуск
- Без эфира: открой `index.html` — демо-боты + пульт (G/S/M подарки, K король укрепляет, L лайки, R рестарт, H пульт).
- Эфир (TikFinity): `index.html?src=tikfinity&user=ТВОЙ_НИК` → OBS «Браузер» 1080×1920.
- Без TikFinity: мост из `../lava-rising/bridge`.

## Правила для зрителей
- 🎁 1 монета = 1 удар по королю. Если ты король — 1 монета = +1 к силе трона.
- ❤️ 50 лайков = 1 удар (или +1 к трону, если лайкает король).
- ➕ Подписка = удар силой 5.
- Свободный трон занимает первый, кто подарит подарок.

## Параметры ссылки
`src` (tikfinity/demo), `user`, `round` (сек), `likes=0`, `ws`, `panel=1`, `obs=1`,
`map=giftId:действие:сила` — действия `attack` (удар N), `fortify` (укрепить N, если ты король, иначе удар), `none`.
Подарки без `map` работают по цене в монетах. Настройки баланса — объект `CONFIG` в начале файла.
