# 🪢 Перетягивание над пропастью — TikTok LIVE мини-игра

Две команды тянут канат над пропастью. Кто дотянет метку до своего края — выигрывает раунд, а лучший игрок проигравших летит в пропасть 😱. Матч до 2 побед, потом автоматически новый.

## Запуск
- Без эфира: открой `index.html` — демо-боты + пульт (Q/W/E подарки левым, I/O/P правым, B боты, R рестарт, H пульт).
- Эфир (TikFinity): `index.html?src=tikfinity&user=ТВОЙ_НИК` → OBS «Браузер» 1080×1920.

## Правила для зрителей
- 💬 Пиши «красные» / «синие» (или 1 / 2) — выбор команды. Без выбора тебя посадят в меньшую команду.
- 🎁 1 монета = 1 шаг (до края 300 шагов, за 2.5 с канат сдвигается не больше чем на 30%, лишнее идёт в очередь). Подарок 100+ ставит ⚓ якорь: 5 с рывки соперников вдвое слабее.
- ❤️ 15 лайков = 1 шаг. ➕ подписка = 5 шагов.
- Канат сам понемногу возвращается к центру — тянуть надо всё время. Если время вышло, побеждает тот, на чьей стороне метка.

## Параметры ссылки
`src`, `user`, `round` (сек), `left=Украина`, `right=Казахстан` (свои названия команд), `likes=0`, `ws`, `panel=1`, `obs=1`,
`map=giftId:действие:сила` — `pull` (N рывков), `anchor` (якорь N сек: рывки соперника ×0.5), `none`. Баланс — объект `CONFIG` в начале файла.
