# 🎨 Цветная карта — TikTok LIVE мини-игра

Карта 9×9. 4 страны стартуют в углах своего цвета. Подарки дают краску, а краска сама закрашивает соседние клетки: сначала самую дешёвую, при равенстве — ближе к центру. Пустая клетка стоит 4, чужая — её стойкость + 2. Через 3 минуты побеждает цвет, которым закрашено больше всего карты.

## Запуск
- Без эфира: открой `index.html` — демо-боты + пульт (1–4 подарок команде, M мега, R рестарт, H пульт).
- Эфир (TikFinity): `index.html?src=tikfinity&user=ТВОЙ_НИК` → OBS «Браузер» 1080×1920.

## Правила для зрителей
- 💬 Пиши страну (название, флаг) или номер 1–4.
- 🎁 1 монета = 1 краска. 🚀 Подарок 100+ ещё и делает краску на краю стойче (+4).
- ❤️ 25 лайков = 1 краска. ➕ подписка = 5 краски.

## Параметры ссылки
`src`, `user`, `round`, `teams=UA,KZ,PL,TR` (2–4 страны), `likes=0`, `ws`, `panel=1`, `obs=1`,
`map=giftId:действие:сила` — `paint` (N краски; старое `army` тоже работает), `fortify` (стойкость +N), `none`.
