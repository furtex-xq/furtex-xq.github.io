# 🏁 Гонка стран — TikTok LIVE мини-игра

8 стран едут к финишу (2500 м). Все машины едут сами, но медленно. Подарки и лайки зрителей разгоняют их страну. Кто первый на финише (или дальше всех через 3 минуты) — побеждает. Потом сразу новая гонка.

## Запуск
- Без эфира: открой `index.html` — демо-боты + пульт (1–8 подарок за страну, S/M крупные, R рестарт, H пульт).
- Эфир (TikFinity): `index.html?src=tikfinity&user=ТВОЙ_НИК` → OBS «Браузер» 1080×1920.

## Правила для зрителей
- 💬 Пиши страну: название, флаг или номер 1–8. Без выбора — в самую маленькую команду.
- 🎁 1 монета = +4 м (один подарок — максимум 20% трассы; топливо расходуется не быстрее 50 м/с, лишнее ждёт в баке и не пропадает). 🚀 Подарок 100+ = турбо ×1.5 на 5 с.
- ❤️ 10 лайков = 1 м. ➕ подписка = 20 м.

## Параметры ссылки
`src`, `user`, `round` (сек), `teams=UA,KZ,PL,...` (до 8), `likes=0`, `ws`, `panel=1`, `obs=1`,
`map=giftId:действие:сила` — `boost` (N метров), `turbo` (турбо N сек), `none`. Баланс — `CONFIG` в начале файла.
