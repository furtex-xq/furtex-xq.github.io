# 💪 Девушки против парней (girls-vs-boys)

Две команды толкают кирпичную стену навстречу друг другу. Каждая сторона арены своего цвета (розовая и голубая), граница между ними проходит по стене.

**Зрителю:** напиши «девушки» / «парни» (или 1 / 2, д / м, girls / boys) и дари.

| Действие | Эффект |
|---|---|
| 🎁 1 монета | +10 силы толчка |
| 💎 10+ | второе дыхание: толчки ×2 на 6 с |
| 🚀 100+ | таран: подарок ×1.5, стена дёргается |
| ❤️ лайки | 20 лайков = 1 монета силы |

- Положение стены = (A−B)/(A+B+400). Если стена дожата до 82%, это досрочная победа («🧱 СТЕНА ДОЖАТА!»). Иначе через 90 с побеждает сторона с большей силой.
- **ТОП ТОЛКАЮЩИХ:** две панели с топ-5 зрителей каждой команды (аватар, 👑 у первого, очки).
- Последние 3 дарителя каждой стороны с аватарками толкают героя сзади.
- Крупный обратный отсчёт в последние 10 с.
- Персонажи оригинальные: девушка с хвостиком в розовом спорткостюме и парень в синем худи. Лица напрягаются, а при бонусе выступает пот.

Механика детерминированная. Ни один подарок не теряется: подарки с экрана победы переносятся в следующий раунд.

**Текстуры:** стена из кирпича в стальной раме с заклёпками и жёлто-чёрной полосой, пол спортзала из досок, прожекторы, толпа с плакатами, бархатный фон.

FPS 59. Режимов выбора нет: команды фиксированы, а `a=`/`b=` в ссылке задают другие пары (например, RED/BLU).
