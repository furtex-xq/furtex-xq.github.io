# ✨ Битва зодиаков — TikTok LIVE мини-игра

Зрители пишут свой знак зодиака. На арене дуэль двух знаков: подарки болельщиков бьют по сфере соперника. Победитель остаётся чемпионом, против него выходит знак с наибольшим числом болельщиков. Рекорд серии побед — на экране.

Подарки знаков, которые ждут очереди, не пропадают: они копят щит (доп. здоровье) на их следующую дуэль. Случайности нет.

## Запуск
- Без эфира: открой `index.html` — демо-боты + пульт (Q/W/E подарки левому, I/O/P правому, B боты, R рестарт, H пульт).
- Эфир (TikFinity): `index.html?src=tikfinity&user=ТВОЙ_НИК` → OBS «Браузер» 1080×1920.

## Правила для зрителей
- 💬 Напиши знак: «овен», «лев», «рыбы» (или символ ♈…♓).
- 🎁 1 монета = 1 урон сопернику. ❤️ 50 лайков = 1 урон. ➕ подписка = 5.
- Дуэль 75 с: если никто не упал, побеждает тот, у кого больше здоровья (в процентах).

## Параметры ссылки
`src`, `user`, `round` (длина дуэли), `likes=0`, `ws`, `panel=1`, `obs=1`,
`map=giftId:действие:сила` — `damage` (N урона), `heal` (лечение своему знаку N), `none`. Баланс — `CONFIG` в начале файла.
