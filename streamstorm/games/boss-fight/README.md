# 👹 Битва с боссом — TikTok LIVE мини-игра (кооператив)

Все зрители вместе бьют босса подарками. Каждые 20 с босс атакует: если зрители лайками набрали щит, атака отбита, а если нет, босс лечится на 10%. Победили босса — следующий уровень сильнее. Не успели за 2.5 мин — босс уходит, а следующий будет на уровень слабее. При запуске игра начинает не выше 3 уровня.

## Запуск
- Без эфира: открой `index.html` — демо-боты + пульт (G/S/M подарки, L лайки, R сброс уровня, H пульт).
- Эфир (TikFinity): `index.html?src=tikfinity&user=ТВОЙ_НИК` → OBS «Браузер» 1080×1920.

## Правила для зрителей
- 🎁 1 монета = 1 урон. 💎 10–99 = крит ×1.5. 🚀 100+ = ульта ×2 и босс оглушён на 6 с (не атакует).
- ❤️ 10 лайков = 1 щит. Нужно 150 × уровень щита к каждой атаке. ➕ подписка = 10 щита.
- В конце — топ-3 героев по урону.

## Параметры ссылки
`src`, `user`, `round`, `likes=0`, `ws`, `panel=1`, `obs=1`, `map=giftId:действие:сила` (`small`/`mid`/`big`/`shield` с ценой в монетах, или `none`).
