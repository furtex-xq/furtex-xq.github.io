# Режимы игр StreamStorm (`&mode=`)

Стример выбирает режим до эфира. Лаунчер добавляет к ссылке игры `&mode=<id>`.
Без `mode` игра работает в режиме по умолчанию (первый в списке). Явные `teams=`, `a=`, `b=` в ссылке важнее режима.
Машинный список — `games/modes.json`.

## Категории
| id | Название | Описание для страницы сайта |
|---|---|---|
| `countries` | 🌍 Страны | Зрители пишут страну в чат и играют за неё. Несколько стран сразу. |
| `duel` | ⚔️ Страна против страны | Только две страны — крупно, напряжённо, легко болеть. |
| `colors` | 🎨 Команды по цветам | Без стран: Красные, Синие, Зелёные, Жёлтые. Пиши цвет или номер. Подходит любому стриму. |
| `ffa` | 👑 Все против всех | Каждый зритель сам за себя: личный рейтинг, один победитель. |
| `coop` | 🤝 Все вместе | Весь чат — одна команда против игры. |
| `signs` | ✨ Знаки зодиака | Зрители играют за свой знак зодиака. |
| `elements` | 🔥 Стихии | Четыре стихии: огонь, вода, лес, молния. |

## Как это работает
- `<script id="modes">` в `<head>` каждой игры подставляет состав команд до старта игры (через `history.replaceState`), правила не меняются.
- В режиме `colors` подсказки «напиши страну» автоматически становятся «напиши цвет».
- Названия режимов без слов про войну и захват; UA и RU вместе нигде не стоят по умолчанию.
