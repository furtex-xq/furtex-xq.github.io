# ⚡ Энергошар (duel-energy)

Два оригинальных чиби-бойца в форме цветов своих стран держат между собой энергошар. Подарки заряжают свою сторону, и шар уходит к сопернику. Половины арены окрашены в цвета стран, граница между ними проходит по шару.

**Зрителю:** напиши «1» / «2» или страну и дари.

| Действие | Эффект |
|---|---|
| 🎁 1 монета | +10 В |
| 💎 10+ | заряд: ×2 на 6 с (вокруг бойца золотая аура) |
| 🚀 100+ | супер-удар: ×1.5 и ударная волна |
| ❤️ лайки | 20 лайков = 1 монета |

- Положение шара = (A−B)/(A+B+400). Если шар дожат до 80%, это досрочная победа «⚡ ШАР ДОЖАТ!». Иначе через 90 с побеждает больший заряд.
- Плашка «🏆 Больше всех: имя ×монеты» за раунд, шкала положения шара, крупный отсчёт в последние 10 с.
- По умолчанию BR против ES (`a=`, `b=` в ссылке), режимы `mode=duel|colors`.

**Текстуры:** плазменный шар с вихрями (спрайт), молнии от ладоней, искры, неоновые лучи, толпа с флагами стран, карбон на фоне, металлическая сцена, бархатная форма с флагом на груди, повязки, которые развеваются.

FPS 58. Ни один подарок не теряется: подарки с экрана победы переносятся в следующий раунд.
