# 🌋 Лава поднимается — TikTok LIVE мини-игра

Одна HTML-страница 9:16 (1080×1920). Ничего устанавливать не нужно.

## Быстрый старт
1. **Проверка без эфира:** открой `index.html` в браузере — запустится демо с ботами и пультом (кнопки подарков/лайков, клавиши 1–8, G, S, M, R, H).
2. **В эфире через TikFinity:** запусти TikFinity и подключи свой LIVE. Ссылка игры:
   `index.html?src=tikfinity&user=ТВОЙ_НИК`
   Игра слушает `ws://localhost:21213/` (WebSocket API TikFinity), при обрыве сама переподключается каждые 3 с.
3. **OBS / TikTok LIVE Studio:** Источник «Браузер», размер 1080×1920, ссылка как выше. Пульт в OBS скрыт автоматически.

## Правила для зрителей
- 💬 Пишешь страну в чат (название, флаг или номер 1–8) — вступаешь в команду. Можно `!join` — посадит в самую маленькую команду.
- ❤️ Лайки поднимают платформу твоей страны. Колонны сами плавятся, поэтому лайкать надо постоянно.
- 🎁 Подарки 1–9 монет: рывок вверх. 10–99: щит + заморозка лавы. 100+: метеорит сбивает лидера-соперника.
- Платформа в лаве — страна выбывает. Последняя выжившая (или самая высокая к концу таймера) побеждает. Раунд 2 мин, потом автоматически новый.

## Параметры ссылки
| Параметр | Пример | Что делает |
|---|---|---|
| `src` | `tikfinity` / `demo` | Откуда события (без параметра — демо) |
| `user` | `davyd` | Ник стримера в углу |
| `round` | `120` | Длина раунда, сек |
| `teams` | `UA,KZ,PL,DE` | Страны (до 8): UA RU KZ BY UZ PL DE TR US BR FR IT ES GE AM AZ MD KG TJ IN |
| `join` | `!join` | Команда авто-вступления |
| `likes` | `0` | Выключить лайки (только подарки) |
| `map` | `5655:platform:3,6267:meteor:30` | Свои подарки: `giftId:действие:сила` |
| `ws` | `ws://localhost:21213/` | Другой адрес WebSocket |
| `panel` | `1` | Показать пульт даже в эфирном режиме |
| `obs` | `1` | Скрыть пульт |

Действия для `map`: `platform` (поднять свою платформу на N м), `shield` (щит N сек), `cool` (заморозить лаву N сек), `meteor` (сбить лидера на N м), `none`.
Подарки без `map` работают по цене: см. правила выше. Тонкая настройка — объект `CONFIG` в начале `index.html`.

## Без TikFinity (TikTok-Live-Connector)
```
cd bridge && npm install && node bridge.js ТВОЙ_НИК
```
Мост поднимает тот же `ws://localhost:21213/`, игру запускай с `?src=tikfinity`.
